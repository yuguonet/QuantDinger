## 1. 系统全景

### 1.1 心智模型

系统 = **宏（规则）+ 引擎（读宏出结果）+ 数据层**。四视图（回测 / 调试 / 展示 / 实时）是同一判定主干的四种投影，差别只在**数据来源**与**收集器**：

| 层 | 载体 | 说明 |
|---|---|---|
| 数据层 | `core/data/`（hub 唯一 IO 出口） | bars / 快照 / 分钟；滑动窗口 + as-of 切片 |
| 宏层 | `strategies/<key>.yaml`（规则）+ `<key>.py`（feat 原语） | **规则唯一事实源** |
| 引擎层 | fold 折叠内核（`core/present/runner`）+ 回放（`core/replay`）+ 门表运行时（`core/runtime`） | 判定推进与收集 |
| 视图 | 回测 trades / 调试轨迹 / 展示 Record / 实时 progress | 各自投影，不各自判定 |

### 1.2 四视图现状

| 视图 | 入口 | 判定引擎 | 产出 |
|---|---|---|---|
| **回测** | `strategy_cli.py run` → `core/backtest.run_all` → `core.replay`（`backtest_stock` 薄壳） | 折叠 fold（stateful） | trades → 胜率/盈亏比 |
| **调试** | `tools/why·debug·replay·chat_why` | 门表 `evaluate_gates` / replay + TraceCollector | 逐门原因、逐笔明细 |
| **展示** | `present_daily.persist_days` → StateStore 切片 → `store` 投影 → `api.py` | 折叠 fold（stateless 补齐 ready） | 信号/持仓/事件序列 |
| **实时** | `monitor.run_monitor`（60s tick）+ `core/present/realtime.RealtimeBranch` | 当日切片 progress（可回退旧三决策） | 当日信号/盘中状态 |

### 1.3 一张图

```
物理源 (Postgres/上游): kline_1D · kline_1m · realtime_snapshot · dragon_tiger_store · stock_basic_info
        │
        ▼
core/data/hub.py ── 唯一数据出口（as_of 贯通，策略禁直连物理源）
        │
        ├────────────► strategies/<key>.py + <key>.yaml（宏：规则 + feat 原语）
        │                       │
        ▼                       ▼
┌─ 判定主干 ────────────────────────────────────────────┐
│ fold 折叠内核 (core/present/runner): init_state→evaluate→step │
│   ├─ 展示/实时: StateStore 切片 (Record: state/current/events) │
│   └─ 回测/调试: core/replay (DailyFeed/IntradayFeed + collectors) │
│ 门表运行时 (core/runtime): expr DSL → GateEvaluator → scan_day  │
└───────────────┬───────────────────────────────────────┘
                ▼
scan.py（盘后/盘中窗口）→ store.py: qd_dragon_signals（唯一事实表）
monitor.py（盘中状态机，60s）↗        │
                ├─ qd_watchlist 投影 + label 层
                ▼
api.py（只读 3 路由）→ 前端
```

**三处汇聚**：① hub（数据只在此出一次）；② fold/门表（判定只在此算一次）；③ store（落库只在此写一次）。

## 3. 策略规范：一个策略 = 宏（yaml + py）

### 3.1 两文件分工

| 文件 | 装什么 | 不装什么 |
|---|---|---|
| `<key>.yaml` | **规则**：meta（含开关）+ entry/exit + params + 门表 + signal 字段 | 计算代码 |
| `<key>.py` | **feat 原语**（门表引用的计算函数）+ 编排注册 + 折叠契约实现 | 规则判定本身（⚠ 现状仍含回测/调试残段，见问题清单 A-1） |

### 3.2 yaml schema（实测字段）

```yaml
meta:    name / market / version / enabled        # enabled = 策略开关唯一事实源
         enumeration(limit_up|day|intraday) / day_flow / day_start / day_end / day_min_n / ext
exit:    mode(combo|break_combo|g56_no_trail|d1_open)    # 只声明 mode，阈值一律在 params；见 3.6
         （⚠ 2026-10-10 起 entry: 块已从宏中移除——入场规则在策略代码折叠 step 内；
           这与目标态 §3.2 schema 不一致，方向待用户裁决，见《修复核对与偏离度_20261010.md》§3）
params:  可调参数（参数单一事实源；表达式中直接当变量引用）
gates:   [ {id, name, role: qualify|required|audit, needs_d0: 0|1, enabled: 0|1, expr} ]
signal:  fields: { 字段名: {expr, fmt: none|r1..r6|int} }   # 展示字段唯一事实源
```

### 3.3 门表 DSL 契约

- **允许**：`and/or/not`、四则与幂、比较、函数调用、变量、常量、字符串参数。
- **禁止**：任意语句 / import / IO / 循环；属性访问 / 下标 / 跨股票引用；关键字参数。
- **偏移纪律**：`chg(-1)` = 前一日；**正偏移 = 未来函数**，`expr.static_asof_check` 加载期拒绝 + `Ctx._check_k` 运行期拒绝（双重保险）。
- **偏移函数集**：`core/runtime/functions.py: OFFSET_FUNCS`。

### 3.4 feat 原语三层（引擎统一绑定）

| 层 | 落点 | 例子 |
|---|---|---|
| 内核原语（24 个，恒绑定） | `core/runtime/functions.py: Ctx` | `chg/k/vol_ratio/lu_close/pullback_days/monotonic_down/is_limit_up/count_limit_up/ma/rsi/macd_*/kdj_*/boll_*/atr` |
| 共享门函数（11 个） | `core/runtime/gate_stdlib.py` | `obv_rising/no_lu_last/macd_hist_lt/boll_bw_ok/board_height/ma_bull/is_bse/ret_n/d1_vol_ratio/is_approx_limit_up/pk` |
| 策略私有门 | `strategies/<key>.py` 模块级 `register_strategy_funcs("<yaml-stem>", {...})` | break: feat/turnover_sig/bkf/entry_*；dragon: gap_days/dragon/streak/…14 个；g56: feat/finite/warmup/pool_*；knife: feat/ok/hhmm/mkt_gain；tail: feat/hhmm/limit_hit/ok/nf/v2/pred_* |

- **key 隔离**：`STRATEGY_GATE_FUNCS` 按 YAML stem 组装（`build_funcs(ctx, key, names)`），同名互不可见。
- **D0 依赖**：`D0_DEPS/REGISTERED_D0` 声明门是否读决策日（⚠ 夜算管线已退役，声明当前无消费，见问题清单 D-5）。

### 3.5 策略插件契约（`strategies/base.py`）

**必选**：`key` / `name`；`scan_signals(bars, code, *, as_of, ctx, **params) -> list[Signal]`；折叠契约三件套 `init_state(code, bars)` / `step(state, bar)` / `evaluate(state, inp, prev) -> [Progress]`。

**可选**：`prefilter_anchor(signal|limit_up)`、`use_unified_prefilter`、`signal_state(watch_pending|buy_today)`、`entry_at_close`、`exit_exec_same_day`、`rolling_preview`、`data_needs`、`entry_style/family/family_version`、`scan_spec`（ScanSpec：kind/windows/interval_sec/entry_at/after_events/fire_at）、`default_params`、`stages`、`SEED_BARS(=200)`、`probe(state)`（除权锚）、`init_shared/shared_snapshot`（策略级持久态，g56 池台账）、`begin_day`（横截面）、`realtime_shortlist` / `intraday_shortlist`、`quality_key(row)`、`initial_stop`、三决策 `entry_decision/confirm_decision/exit_decision`、`intraday_replay`（1m 精修腿，仅 break）、`scan_days` 覆盖（仅 g56）、`t_leg_intents`。

**已死钩子（无调用方，勿用）**：`day_prefilter`、`intraday_exit`。

**三决策语义**（monitor 消费）：`entry_decision`（D1 开盘是否买，gap 判定）→ `confirm_decision`（15:00 收盘确认）→ `exit_decision`（出场：止损/追踪/到期，返回 `ExitDecision(action, reason, price, fill)`，`fill="open"`=次日开盘强平）。

**折叠契约语义**（runner/replay 消费）：
- `init_state` 播种（bars 不足抛 `InsufficientHistory` 后滑）；
- 逐日 **先 `evaluate` 后 `step`**（state 语义 = 截至昨日收盘）；
- `evaluate` 产出 `Progress(stage, date, payload, next_realtime, source)` 事件（ready → exec → exit 链）；
- `stateless` 模式（展示，prev=None，补 ready 不结算）/ `stateful` 模式（回测，prev=head，exec/exit 闭合）。

### 3.6 开关与参数（单源规则）

| 语义 | 事实源 | 回退 |
|---|---|---|
| **策略开关** | yaml `meta.enabled`（mtime 缓存热生效） | config `enabled` → **False**（缺省不进实盘） |
| **参数** | yaml `params` | config `params`（当前已清空）→ 代码 `default_params`/类默认 |
| 每日入库限额 | config `daily_limit`（0=不截断，默认 20） | — |

## 4. 判定主干

### 4.1 fold 折叠内核（`core/present/runner.py`）

- **Record**（唯一中间产物）：`{date, state(不透明 JSON), current(生命周期头 Progress|None), events(append-only), strategy_hash}`。
- **fold_range(strategy, code, bars, i0, i1, stages, ctx_provider, stateful)**：seed 一次 + 逐日 `_fold_one`（evaluate → step）。
- **StateStore**：单 (strategy, code) 单文件落盘（`_paths.PRESENT_STATE_DIR`），tmp+os.replace 原子写，进程内缓存 + 批量 flush。
- **四条件重建**（`_rebuild_reason`）：① reordered（日期错位）② date_gap（切片不在昨根）③ probe_mismatch（除权锚严格比对）④ strategy_changed（策略源 sha256）；同日 = noop 幂等。重建只重建 state，current/events 跨重建保留。
- `evaluate_day` 为补 stateless ready 会跑两遍 evaluate（stateful + stateless 各一）——已契约化的双跑口径。

### 4.2 回放引擎（`core/replay/`）

- **feeds**：`DailyFeed`（日线 fold，stateful）/ `IntradayFeed`（日线折叠 + 当日分钟快照注入，逐槽 `mkt_slots` as-of）。
- **collectors**：`TradesCollector`（事件链匹配：ready 开链 → exec（`is_self_closed` 两段直产）→ exit 三段配对；未平链 → 末日收盘平仓 `REASON_DATA_END`）；`TraceCollector`（门轨迹，经 `ctx["_trace"]`）；`GateDebugCollector`（全门布尔向量）。
- **trade_map.py**：事件载荷 → canonical trade（`code/strategy/d0_date/entry_date/entry_price/exit_date/exit_price/exit_day/exit_reason/return_pct/peak_return_pct/exec_basis`；别名 `reason→exit_reason`、`exit_ret→return_pct`）。
- `backtest_stock` = base 薄壳 → `core.replay`（策略不再自带回测引擎；1m 精修走 `core/backtest._refine_intraday`，逐笔标 `exec_basis=1m|daily`）。

### 4.3 门表运行时（`core/runtime/`）

- **expr.py**：AST 白名单解释器（三禁 + 正偏移静态拒）。
- **evaluate.py**：`load_strategy(key)` → `StrategySpec`（meta/entry/exit/params/gates/signal/market_spec）；`GateEvaluator.evaluate_prefilter/evaluate_decision/evaluate_all`；**`scan_day(spec, bars, code, target)`** = 生产单日判定入口（`scan_writer="scan_day"` 行源消费）。
- **flows.py**：`register_scan_one(enum, day_flow, fn)` 注册表——break/g56/dragon_callback 各注册单日判定；knife/tail（intraday）不进 scan_day。
- 求值异常降级为"门未过"（首条 WARNING 后 DEBUG）——安静但会吞信号，见问题清单 L-6。

### 4.4 出场与成交（现状生效路径）

### 5.1 hub 通道（真实表名）

| 通道 | 物理源 | 粒度/复权 | 时效 |
|---|---|---|---|

| `minute_1m` | `kline_1m_YYYY` | 1m / 不复权（转 qfq 显式走 `adjustment.unadj_to_qfq`） | **盘后回填**，保留 ~100 工作日 |
| `quote / market_snapshot / day_series / minute_live` | `realtime_snapshot_YYYY` | 60s/拍（可能丢拍） | **盘中唯一实时通道**，保留 5 工作日 |

| `stock_info / all_codes` | `stock_basic_info` | 股本/名称/状态 | U1~U4 依据 |

### 5.2 as-of 四道闸

① 数据层：`hub.daily(as_of)` + `kline.asof_bars`（**末根==target 唯一口径**）；② 表达式层：正偏移静态拒 + `Ctx._check_k` 运行期拒；③ 回放层：`frames.series(upto_pos)` 逐槽截断 + `mkt_slots` 逐槽市场门；④ 策略层：`bars[:i+1]` 切片义务。

### 5.3 分钟数据纪律

- **分层取数**：`minute_composite.hybrid_series`（近端 `DEFAULT_MINUTE_DAYS`≈100 交易日走 1m，远端 1D，互斥不丢日）；**禁止整窗 1m**。
- **两段拼接**：`minute_live_full` = `kline_1m`（历史基底）+ `realtime_snapshot`（当日尾部）；判据：`kline_1m` 有该日 → 用 1m，无 → 用快照。
- **质量分级**：`quality.grade_*`（ok/warning/error/suspend），只标注不阻断。

### 5.4 三大陷阱

1. **跨层复权混算**：daily 是 qfq、1m 是原始价 → 换算必须显式 `unadj_to_qfq`，hub 不静默换算。
2. **实盘盘中拿不到当天 1m**（盘后才有）；回测不该用快照（不完整）。
3. **快照按年分表且可能丢拍** → 跨年/对账显式处理；缺拍只标注（展示无回溯性）。

### 6.2 盘后扫描（`scan.run_scan`）

```
互斥 → wait_data(000001 末根==target) → _prefetch_bars(window_cache→batch→逐票)
→ _prewarm_pools(g56) → 逐票 asof_bars(末根==target) → 行源 writer
```

**行源三 writer**（`scan_writer` 开关，config 现值 `"scan_day"`）：

| writer | 判定 | 状态 |
|---|---|---|
| `scan_day` | 门表 `core.runtime.evaluate.scan_day` 单日判定 | **现役** |

| `scan` | `strat.scan_days` 直判 | 回滚位 |

### 6.3 盘中状态机（`monitor.run_monitor`，60s tick 8 步）

1. 滞留 `buy_today` 自愈 → holding；拉活跃快照（`VISIBLE_WINDOW_DAYS=30`）；stale 观察票过期 → expired
2. **开盘窗口 09:25–09:35**：禁用策略存量 pending 作废（`retire_unfilled`）→ 开盘判定（`_progress_map` 新源 或 `entry_decision` gap）→ `quality_key` 排序 + daily_limit 名额 → buy_today / expired
3. **盘中 09:35–15:00**：硬止损（px≤stop → exit_today，**永不迁新源**）+ 做T 意图 + `exit_decision(live)` 或 progress exit
4. **14:25–14:45 预确认**：`confirm_decision` → `pre_confirm` 档位
5. **14:58–15:06 收盘重放**：`_eval_exit_day_close` 或 progress exit
6. **≥15:01 确认**：`snapshot_day_done` 闸门 → holding / exit_today
7. **exit_today 平账 → closed**（隔日开盘价记账；`exit_exec_same_day` 策略当日保标记价）
8. `purge_stale_detail`（pre_confirm 等瞬时标记）→ `sync_watchlist_group`

**判定点双源**（`monitor_progress.enabled=true`）：`_progress_map` 读 `RealtimeBranch.tick` 当日切片 progress；拿不到判定 → 回退旧三决策；实时分支**不写回 fold**。

### 6.4 盘中窗口扫描（`scan.run_scan_knife`）

窗口首拍拉起 → 14:50–15:00 每分钟滚动预览（`intraday_shortlist` → `scan_signals(ctx=快照)` → U1~U4 → signal_row，state=buy_today）→ 15:00 终审（清未定价预览行）→ `upsert_scan_signals(purge_buy_today=本批)`。

### 6.5 存储与状态机（`store.py`）

| 表 | 角色 | 关键约束 |
|---|---|---|
| `qd_dragon_signals` | **唯一事实表**（状态机全量 + 历史） | `UNIQUE(trade_date, strategy, code, entry_style)` |
| `qd_watchlist` | "自动策略组"**投影**（活跃四态） | `sync_watchlist_group` 全量对账（幂等）；⚠ 唯一键不含 strategy ⇒ 同票多策略共享行 |
| `qd_data_events` / `qd_scheduler_done` | 事件/幂等 | — |

```
watch_pending →(entry_decision)→ buy_today →(confirm)→ holding
              →(exit_decision/收盘重放)→ exit_today → closed
特殊态: expired（弱确认/gap 放弃/超时）；entry_at_close 策略落库即 buy_today
```

- `upsert_scan_signals` 守卫：`entry_date` 非空或 expired 不回滚 state/extra；跨日同名 pending supersede；停用作废只动 `watch_pending` 且 `entry_date IS NULL`。

## 11. 常见任务手册

### 11.1 调参数/门阈值
1. 改 `strategies/<key>.yaml` 的 `params:`（唯一事实源）；门阈值进 `gates[].expr`。
2. `param_scan --strategy <key> --grid '{...}'` → 只认两段全正 + 邻域平台。
3. `pool_check` → 必须 MIGRATE（VETO 即回退）。
4. golden / 逐笔等价抽跑确认未动既有语义。

### 11.2 加一道门
1. `<key>.yaml` `gates:` 末尾加一行（id/name/role/needs_d0/enabled/expr）。
2. 需要新函数：仅本策略用 → `<key>.py` 模块级 `register_strategy_funcs("<yaml-stem>", {...})`；多策略共用 → `gate_stdlib.py` `register_function`。
3. 走 11.1 的 2–4 步（加门改选择集，必须两段 + pool_check）。

### 11.3 加一个策略
1. 写 `strategies/<key>.yaml`（meta 含 `market: A` + enumeration + entry/exit/params/gates/signal）。
2. 写 `strategies/<key>.py`：折叠契约三件套 + `scan_signals` + feat 原语注册 + `register_scan_one`（day/limit_up 族）。
3. `config.json:strategies.<key>` 声明 `label/daily_limit`（盘中类加 `schedule`）。
4. `doctor --static` → `path_parity` → 有参考实现就跑逐笔等价。

### 11.4 改出场逻辑（⚠ 高危）
先 `grep -rn "exit_decision\|_exit_event\|exit_engines\|replay_sell_intraday"` 列全副本，逐份核对语义（T+1：入场日不产生出场）；改完必跑 golden + `legacy_trade_diff --ref`。

### 11.5 排查"数不对"

| 症状 | 先查 |
|---|---|
| n=0 / codes_ok=0 | PowerShell `--codes` 引号（丢前导零） |
| 回测 ≠ 实盘 | `path_parity` + `projection_shadow` |
| 疑似未来函数 | 未来扰动法 + 检查偏移是否为负 |
| 展示对不上 | `qd_dragon_signals` ↔ `qd_watchlist` 投影（sync_watchlist_group）|
| 判定行为变了 | 切片四条件重建（strategy_hash？probe_mismatch？）|
| 盘中无动作 | 监控接线（问题清单 L-1）+ `monitor_progress` 开关态 |

## 12. 术语表

| 术语 | 含义 |
|---|---|
| 宏 | `<key>.yaml` + `<key>.py`，规则唯一事实源 |
| fold / 折叠 | 逐日 `init_state→evaluate→step` 推进；四视图共用内核 |
| Record | 折叠落盘切片 `{state, current, events}` |
| 事件流 | ready → exec → exit 链（每票每天状态事件） |
| 门 / 门表 | 布尔条件 / 按声明序求值的条件表 |
| qualify / required / audit | 资格门（可夜算）/ 判定门（依赖 D0/lu_idx）/ 只记录 |
| as-of | 只能看 ≤ 某时点的切片语义 |
| D0/T、D-1 | 买入日 / 前一交易日 |
| `lu_idx` | 涨停日索引（dragon 族枚举起点） |
| U1~U4 | 统一预过滤（非 ST/换手/市值/前期热度） |
| 投影 | `qd_watchlist` 上由事实表派生的行（非事实源） |
| 判定列/操作列 | 规则可再生列 / 人工与实盘写入列（不可重建） |
| 三决策 | entry_decision / confirm_decision / exit_decision |
| exec_basis | 逐笔成交口径标注 `1m` / `daily` |
| data_quality | 数据完整度四级 `ok/warning/error/suspend` |
