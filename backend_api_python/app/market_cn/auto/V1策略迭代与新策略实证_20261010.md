## 1. V1 首板辨识度改造

### 1.1 背景与定位
- V1 = 抓**首板后连板（1进2）**：D0 首板 → D1 竞价买 → D1 涨停(连板)则持有、否则 D2 清仓。
- 旧 V1 全市场 120 天：88 笔、胜率 29.5%、**均收 -1.86%**（净负）。
- 用户目标：**提高首板辨识度 → 提高 1进2 命中率 → 提高胜率**。

### 1.2 数据驱动的辨识度改造（旧 5 因子 → 新 7 门）
实证（`v1_board_buyable_study.py`，可买真首板 n=8285）发现旧因子反而是最差桶，重设为「可买真首板」口径：
- **旧因子（弃）**：D-1 回调[-10,-3)（连板仅 10.8% 全桶最低）、ret_20d>30（反伤）、OBV、D-1非放量、过热过滤。
- **新 7 门**：① D0 涨停 ② **非一字可买**（D0开盘<涨停，排除一字/秒板消息股）③ **真首板**（前10日无涨停，不与龙回头/断板重合）④ 小盘（流通市值≤200亿）⑤ D-1 横盘[-3,3)（替代深回调）⑥ 温和量比[1,5) ⑦ 弱趋势 ret20≥10。
- 用户两点修正：① 要求前期无涨停（真首板）；② 一字板是消息股、D1 买不进（剔除）。

### 1.3 入场改造（高开强势连板）
实证（`v1_d1_gap_study.py`）：D1 竞价 gap 越高连板/收益越高（≥8% 连板 61%、唯一正 EV），低平[-3,3)/中开(3,8) 负 EV。入场门改「gap≥8% 且<涨停价(可买)」。

### 1.4 出场改造（让利润奔跑）
旧「D1 未涨停→D2 开盘清仓」一刀切把大赢家砍在 D2。改 `let_profits_run=True`（去 D2 一刀切，用追踪止损 trail/stop/expiry 出场）。A/B（同 57 笔）：
- 均收 1.58%→**1.93%**、中位 0.90%→**1.60%**、top2 集中 57%→**46%**（更分散）。**有效，保留**。

### 1.5 V1 改造后最终结果（全年 250 天）
| 指标 | 旧 | **新** |
|---|---|---|
| 笔数 | 88(120d) | 57(全年) |
| 胜率 | 29.5% | **59.6%** |
| 均收 | -1.86% | **+1.93%** |
| 中位 | — | +1.60% |
| bootstrap 95% CI | — | **[-0.23%, +4.20%]（含 0，不显著）** |
| 连板率(持有>2d) | 4.5% | 3.5% |

**⚠ 关键**：胜率大涨（29.5→59.6%）**不是靠 1进2 连板**（连板率仍 3.5%），而是靠**高开强势买入→D2 卖**的隔夜延续。V1 从「抓连板持有」偏移成「高开动能隔夜」策略。优势边际、集中、未过显著性。

## 2. ⭐ 核心障碍：逆向选择天花板（贯穿所有研究）

**所有「追板买次日开盘」的尝试都撞同一堵墙**：高收益的延续几乎全**封死在 D1 一字（买不进）**，能买到的 D1 开盘都是被挑剩的柠檬。

| 尝试 | 连板/收益（D1一字=买不进）| 真实可买（D1开盘）|
|---|---|---|
| 高开可买 | 一字 D1 +8% | 边际 +1.93%（CI 含 0）|
| D0一字 + D1可买（并行规则）| D1一字 连板81%/+8.15% | **-1.59%**（逆向选择）|
| 封板×大盘非弱 | D1一字 D+5 +2.63% | **-0.47%**（假象破灭）|

⇒ **V1 的 +1.93% 已近此范式天花板**，不是参数问题，是范式受限。出路：① 分散靠现有策略组合 ② 改入场时点（盘中/封板前买，需分钟数据）③ 接受范式有限。

## 3. 新策略构想实证（4 个，全市场全年）

### 3.1 吸筹-趋势（用户构想）—— 太弱 ❌
- 构想：D-10~D-1 吸筹充分 → 后续持续；大盘子（40-100亿→现200-500亿）。
- 实证（`v1_acc_study.py`，n=105 万）：吸筹度（涨跌量比/OBV）→ D0 后收益边际**极小**：
  强吸筹 D+5~D+10 仅 +0.2~0.3%（胜<50%，近噪声）；<40亿略好（D+20 +0.93%），200-500亿仅 +0.16~0.34%。
- **判定**：不是强独立策略，最多组合微弱 tilt。用户「大盘子」设想弱支持。

### 3.2 炸板反包（弱转强，用户构想）—— 被否 ❌
- 构想：D0 因大盘差而炸板（触涨停没封住）= 隐藏强势 → 大盘企稳反包。
- 实证（`v1_zhaban_study.py`，n=39K）：**炸板是弱势信号非隐藏强势**——炸板+大盘弱 D+5 **-1.59%**（最差）、炸板+大盘非弱 -0.44%，皆负；大盘弱反而更差（与直觉相反）。D1 反包涨停仅 5-6.6%。
- **判定**：「炸板弱转强反包」不成立，勿做。

### 3.3 封板×大盘非弱 —— 假象 ❌
- 初探 D0收盘→D+1 +1.76% 是「D0 收盘买」（=涨停价，难成交）的理论值。
- 深挖（`v1_seal_mkt_study.py`）真实入场=D1开盘：可买封板×非弱 D+5 **-0.47%**（负）。又是逆向选择（好封板延续变 D1一字买不进，D+5 +2.63%）。
- **判定**：+1.76% 是假象，弃。

### 3.4 D1 低开回归（用户构想）—— 肉太薄 ⚠（不值得做）
- 构想（用户）：D0 封板后 D1 低开 → 有「低开度差值」→ 趋势向上 → 小肉。
- **用户假设成立且单调**（`v1_d1low_rebound_study.py`）：低开越深日内回升越大（-3~-5% +1.28%、<-5% +1.67%）。
- **⚠ T+1 修正（用户指出，对）**：A股 T+1，D1 买最早 D2 才能卖 ⇒ 「D1买D1卖(日内)」违规，+1.66% 是幽灵数字。
- **T+1 合规重测**（`v1_d1low_t1_study.py`）：甜区**低开-3~-5%**（不是越深越好，<-5% 反转亏）。
- **D0 不必涨停**（用户假设，成立；`v1_d1low_d0cond_study.py`）：深低开×大盘≥0 → D0封板+1.53%(n455)/D0涨+0.85%(n4503)/D0任意+0.75%(n9659)。修复靠「深低开+大盘非弱」，非 D0涨停。但 D0封板每笔最优。
- **最终可捕获**：低开-3~-5% × 主板 × 大盘≥0 → **净 +0.75~1.53%/笔、胜 53~55%、隔夜1晚**。
- **判定（用户结论，认同）**：**胜率和肉都太薄**，靠深低开窄带、性价比不高，**不值得做成策略**。

## 4. 关键教训（务必记住）

1. **逆向选择天花板**：「追板买次日开盘」范式锁死——好票封死买不到（D1一字），买得到是挑剩的。三度印证（高开可买/一字并行/封板×大盘）。
2. **T+1**：A股当日买不可当日卖。任何「D1买D1卖」日内分析都是违规幽灵，只能 D1买→D2+卖（隔夜）。
3. **单因子最佳 ≠ 组合最佳**：创业板 gap 抬到[12,16)（单因子示最佳）放全 V1 反而 57→32 笔/均收 1.93→-0.59%（D0门+出场会翻盘 gap→收益关系）。调参必须在**完整组合**里验。
4. **条件方向**：「连板多低开」是条数直觉（低开常见），交易要看 P(连板|gap)（高开才强）。区分 base-rate vs signal。
5. **买在涨停价的收益是镜花水月**：D0收盘买/一字买 = 理论值，成交不了。必须用**真实可成交入场**（D1开盘、剔一字）重测。

## 5. 现状与出路

- **V1**（改造后）：+1.93%/胜 59.6%/CI 含 0 = **边际正**，机制=高开隔夜（非连板）。唯一在跑。
- **4 个新构想**：吸筹弱 / 炸板被否 / 封板假象 / D1低开肉薄 ⇒ **均不做**。
- **出路**（未定）：
  ① **多策略组合**——用现有 dragon/knife/tail/g56（各有正期望）+ V1 分散降风险，靠组合夏普；
  ② **改入场时点**——盘中/封板前买（抓「未封→封」可买段，绕开逆向选择），需分钟数据；
  ③ **接受范式有限**——V1 边际正 + 分散，不再追单策略暴利。
