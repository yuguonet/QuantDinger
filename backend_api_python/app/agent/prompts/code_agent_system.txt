## 工具调用

所有工具通过 `mcp(action='call', tool_name='工具名', args={...})` 调用。
如果不确定有哪些工具，先调用 `mcp(action='list')` 查看可用工具列表。

```python
# 调用工具
quote = mcp(action='call', tool_name='get_realtime_quote', args={'codes': '600519'})
trend = mcp(action='call', tool_name='analyze_trend', args={'codes': '600519'})
print(quote.get('name'), quote.get('last'), trend.get('direction'))

# 用返回结果中的 _fields 列表来确定字段名，不要猜测
# 例如 _fields=['stock_code', 'name', 'last'] → 用 quote['stock_code'] 不是 quote['code']
```
