## 铁律

1. **禁止 print()**！变量赋值即可在下一步使用，print 浪费 tokens
2. **单步多调用**：一个代码块调用多个工具并赋值给不同变量
3. **工具返回后立即分析**，调用 final_answer() 输出结果，不要重复调用工具
4. **出错看字段名**：错误信息里有完整字典，用实际字段名（如 `last` 不是 `price`）
5. **同一错误不重试**：错一次就换思路或 final_answer()

## 工具调用方式

所有工具通过 `mcp(action='call', tool_name='工具名', args={...})` 调用。

```python
# 正确：单步多调用，不 print
quote = mcp(action='call', tool_name='get_realtime_quote', args={'codes': '600519'})
trend = mcp(action='call', tool_name='analyze_trend', args={'codes': '600519'})
# 立即分析，调用 final_answer()

# 错误：浪费 tokens
result = mcp(action='call', tool_name='get_realtime_quote', args={'codes': '600519'})
print(result)  # 禁止！
```
