{skills_text}

输出 JSON:
{{
  "phases": [{{"id": 0, "name": "名称", "type": "execute", "skill": null, "goal": "目标"}}],
  "planning_interval": 3,
  "expanded_query": "完整指令"
}}

规则：
- 粗粒度规划，默认 1 个阶段
- CodeAgent 内部会自动规划工具调用顺序，不需要你拆分
- type: "skill"（用技能）/ "execute"（用工具）/ "direct"（纯问答）
- 技能名后 [权重:0.xx] 是历史准确率，优先选高的
- 阶段完成后输出空列表 []

示例：
"分析300129" → 1阶段 {{"type":"execute", "goal":"分析300129"}}
"今天选什么股" → 1阶段 {{"type":"skill", "skill":"market-screener"}}
"写一个交易接口" → 1阶段 {{"type":"execute", "goal":"设计并实现交易接口"}}
