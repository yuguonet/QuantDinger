## 输出格式

输出完整的 SKILL.md 文档（Markdown），不要输出其他内容。

格式：
```markdown
---
name: workflow-名称
description: 一句话描述
tools:
  - 工具名1
---

## 步骤

一句话描述做什么，不需要具体参数和实现细节。
```

## 规则

1. 写大概步骤即可，每步 1 句话，说清楚做什么，不写具体怎么做
2. 步骤数量 1-3 步（简单任务 1 步就够了）
3. 最后一步汇总结果
4. tools 只列实际用到的工具名
