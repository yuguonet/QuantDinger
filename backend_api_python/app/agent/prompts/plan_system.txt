用户消息: {user_input}

可用技能:
{skills_text}

{completed_phases_text}

输出 JSON:
{{
  "task": "完整任务描述，CodeAgent 可直接执行",
  "selected_skill": "技能名或null",
  "step_budget": 10
}}

规则：
- task: 完整、自包含的任务描述，包含所有必要上下文
- selected_skill: 从「可用技能」中选择最匹配的一个技能名；无匹配则为 null
- step_budget: CodeAgent 执行步数预算（简单任务 8-10，复杂/创造性任务 10-15）
- 步数用完未完成时系统会自动复盘继续，所以宁可多给不要少给
- 技能名后 [权重:0.xx] 是历史准确率，优先选高的
- 如果用户问题不涉及任何技能（闲聊/通用问题），selected_skill 设为 null

示例：
"分析300129" → {{"task": "分析300129的多维度数据，给出标准评估结果", "selected_skill": "stock_evaluation", "step_budget": 10}}
"今天选什么股" → {{"task": "使用 market_screener 技能筛选今日值得关注的标的", "selected_skill": "market_screener", "step_budget": 8}}
"今天天气怎么样" → {{"task": "查询今天的天气情况", "selected_skill": null, "step_budget": 8}}
