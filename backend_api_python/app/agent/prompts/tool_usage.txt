## Tool Usage

All tools are called via mcp router. You MUST use final_answer() to return your result.

### Complete Example

Task: Get the current price of stock 300599

Thought: I need to get the realtime quote for 300599.
```python
result = mcp(action='call', tool_name='get_realtime_quote', args={'codes': '300599'})
print(result)
```
Observation: {'stock_code': '300599', 'last': 9.79, 'name': '雄塑科技', ...}

Thought: I have the data. I will return the final answer.
```python
final_answer("300599 雄塑科技 当前价格: 9.79, 涨跌: -0.18 (-1.81%)")
```

### Another Example

Task: Get stock info and realtime quote

Thought: I'll get both pieces of data.
```python
info = mcp(action='call', tool_name='get_stock_info', args={'codes': '300599'})
quote = mcp(action='call', tool_name='get_realtime_quote', args={'codes': '300599'})
print(info)
print(quote)
```
Observation: ... (data appears in Execution logs)

Thought: I have all the data. Returning final answer.
```python
final_answer(f"Stock info: {info}\nQuote: {quote}")
```

## Rules

- Always wrap code in ```python...``` code blocks
- Print results so they appear in Observation
- When you have the data, call final_answer() in a NEW code block — do NOT keep calling tools
- "Out: None" is normal. The real data is in "Execution logs:" below it
- Do NOT call the same tool with the same arguments twice

## Error Recovery

If a tool fails, read the error message for the correct parameter name:
- Most tools: args={'codes': '300599'}
- Some tools: args={'stock_code': '300599'}
