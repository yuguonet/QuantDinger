## Bug 修复：smolagents 沙箱进程不退出（2026-09-13 21:18）

### 现象
跑马灯任务完成后，smolagents 代码执行沙箱进程（`ThreadPoolExecutor(max_workers=1)` 的工作线程）未退出。

### 根因
smolagents 1.26.0 的 `LocalPythonExecutor` 每次 `__call__` 用 `with ThreadPoolExecutor(max_workers=1)` 包装：
- 正常完成：`with` 块退出 → 线程正常结束
- 超时：只对主线程抛 `TimeoutError`，**后台工作线程继续运行直到代码块执行完**，最长可达 `MAX_EXECUTION_TIME_SECONDS=30s`

而 `_run_phase_step` 结束后只关闭了 LLM adapter，没有清理 `CodeAgent.executor`（或 `python_executor`），导致：
- executor 实例持有 `state`（含 `_print_outputs` 等大对象）
- executor 持有的 `ThreadPoolExecutor` 工作线程未及时退出
- 整个进程在 SSE 流结束后仍等待线程池清空

### 修复
`nodes.py` 的 `_run_phase_step` 末尾（1107 行附近），在 adapter 关闭之后添加 executor 清理：
```python
for _attr in ("executor", "python_executor"):
    _exec = getattr(agent, _attr, None)
    if _exec is None: continue
    if hasattr(_exec, "custom_tools"): _exec.custom_tools.clear()
    if hasattr(_exec, "state") and isinstance(_exec.state, dict):
        for _k in list(_exec.state.keys()):
            if not _k.startswith("__"): _exec.state.pop(_k, None)
    if hasattr(_exec, "cleanup"): _exec.cleanup()
    elif hasattr(_exec, "shutdown"): _exec.shutdown(wait=False)
```
- smolagents 1.26.0 的 `LocalPythonExecutor` 没有 `cleanup()`/`shutdown()`，这段代码向后兼容
- 清理 `custom_tools` 断开工具持有的引用
- 清理 `state` 释放大对象（打印缓冲区等）

### 验证
- py_compile 通过
