## 三、关键决策（写代码前必须知道）

1. **节点 = 递归两类**：`judgment`（判断/边）+ `factor`（因子/节点），`parent_id` 递归。**不是** 4 类、**不是** 6-box。（§25.11）
2. **边界两层** = min(LLM 无法再细化, T+n 验得动)。**不是** 统计算出、**不是** 权重/三判据。（§25.12）
3. **判定口径** = 父锚基线 + Δ判定式（"相对锚=父条件的 base"）。不是绝对命中率。（§25.12）
4. **有效两层** = 可作锚（能用）≠ 实证有效（confirmed）。别混。（§25.13）
5. **relation** = `raises_likelihood`（方向词表 + direction）。最小核，勿扩。（§25.11）
6. **三方分工**：🟢LLM（拆解/提关系/语义）｜🔵代码（校验/DSL/硬过滤/去重）｜🔴T+n（判定五态）。谁干不能乱。（§26.2）
7. **shadow 先行**：候选→testing→shadow→active，active 前不进生产决策。（§24.8 / §35）
8. **六步**：①捕获→②结构化→③验证→④组织→⑤检索→⑥维护。（§26.1/§26.2）
9. **判定五态**：confirmed（正面）｜refuted（反面，**自动生效即避坑经验**，无人工确认）｜no_gain/inconclusive（中性，**不算有效经验**，只留档）｜pending（样本不够）。CI 含 0 ≠ 反证。（§33.5）
10. **反面经验 = 避坑警示 ≠ 反向信号**（逆命题守卫）：反着用必须另立假设走完整验证。（§34.3）
11. **门槛数字只住 `eval_policy.yaml`**：版本化、放宽不追溯；证实与反证**完全同一标准**（反证同过 FDR + 时间外反向验证 oos_refuted）；跨批次=预注册假设族（`fdr_mode: per_batch|online`）。（§33.3/§33.4/§33.6）
12. **判定结果落 `node_evaluations`（追加式）**，节点行证据列只是当前指针；relation_status=提案流程态、validity_status=验证结论态，两轴不混。（§30.2）
13. **自动分类 ≠ 自动阻断**：refuted 自动置顶警示可以，**生产阻断**只给已发布(active)+scope 匹配+显式 blocking 的 is_trap，且受回滚门槛约束；refuted 不得凭统计状态拦决策。**消费统一口径**：只有 confirmed 作正向决策证据；refuted 只进负向警示区，不加权、不单独阻断。（§17.3#3/§26.5）

## 五、别踩的坑（§35）

- **错误**：区分 no-match / infrastructure failure；保留 `error_code + correlation_id + retryable`，勿静默 catch。
- **幂等**：decision/exposure/outcome 有幂等键，重试不重复。
- **as-of / PIT**：因子用 as-of 快照，防前视；outcome 按 T+N 成熟度。
- **边界**：验得动就拆、验不动就停；**不是** 边界判定器/权重。
- **pending ≠ inconclusive ≠ refuted**：样本不够是 pending；CI 含 0 是 inconclusive（说不清），不是反证；中性（no_gain/inconclusive）不算有效经验。
- **反证同过 FDR + 时间外反向验证**（与 confirmed 完全同标准）；**反面经验禁当反向信号**（逆命题守卫）；重评只在预注册里程碑 look 进行（alpha-spending，防反复窥探），job 幂等（重跑不重复写 node_evaluations）。
