> 来源：2026-11-26 会话（"快速拉升如何判出货还是真拉升"讨论 → 承接位统一框架）/ OpenClaw assistant / 2026-11-26

## 0. 一句话总纲

**拉升图形是双方合画的，判断不了"意图"，但可以站在意图的必经之路上：找承接位（钱的真实成本位），在承接位挂单，看见承接证据才成交，承接位失守就走。**

三条定理（本方案的全部理论基础）：

1. **出货和换庄都有承接**——区别不在"有没有人接"，在"接完之后价格守不守得住"。所以不预判意图，只验证承接 + 用止损兜底后果。
2. **出货是单票行为，真启动是板块现象**——孤立拉升没有生态（跟风要真金白银），真龙头有梯队背书。所以拉升定性的主判据是**板块生态（前 3~5 天）**，不是当日图形。
3. **有支撑、在庄家成本附近，就是买点**——"回踩买/追击买"都是相对承接位的距离问题，统一到一个锚上：买点=承接位±带宽，止损=承接位外侧。

## 1. 问题与理论

### 1.1 要解决的问题

快速拉升的股票会进候选池，但候选池本身就是出货者的猎物地图（"最强"=最需要流动性的地方）：
拉升 → 进候选 → 被推荐 → 有人接盘 → 出货完成。需要在系统里区分**拉高出货**与**真启动**。

### 1.2 现有系统的缺口（已核对代码）

| 缺口 | 现状 |
|---|---|
| 量价背离（拉升段净额方向）**没有字段** | `price_direction` 口径按分钟涨跌方向累计，但没拆"上涨分钟净额 vs 下跌分钟净额" |
| 板块梯队/生态**没有结构化输出** | 只有当日 `limit_up_ref`/`dup_n`，没有 T-5~T-1 回看 |
| 涨停票的 seal 强度**躺在盲区** | `seal` 块（封单/开板次数）只在 deep 满卡里，而 deep 不含涨停票 |
| 综合定性（真拉 vs 拉出）**没有定案规则** | 只有 `_open_pump_risk` 等散提示，定性全靠 LLM 盘感 |
| 买点规则三分叉 | 回踩买/突破条件单/追击档三套说法，没有统一锚 |

### 1.3 旧规则处置表（重要：哪些退役、哪些保留）

| 旧规则 | 处置 |
|---|---|
| 「买点两种落法：回踩 X / 突破条件单」 | **统一为一种**：承接位挂单（"回踩"变成"价格回到锚位"的动作描述，不再是独立买法） |
| 「追击档：涨停概率大就现价追」 | **退役**，并入承接位框架（追高=远离锚位付溢价；锚位附近有承接证据=买点，与叫什么名字无关） |
| 「接力档：次日条件单」 | **改写**：接力买点=次日回落到承接位（封板价/zt起点/缺口），不在开盘溢价上接 |
| 止损三条（min(amp,8%) 封顶等） | **保留**，叠加新锚：止损=承接位外侧（详见 5.2） |
| 资金两档（否决/降权）、窗口权重（当日>3~5日>20日）、噪声带、amp雷区、T+1 次日冲高即走、止损棘轮 | **全部保留不动**（本方案不推翻任何一条） |

## 2. 架构总览（每一步是哪层在做）

```
L0 调度层  skill_run 两轮协议：run() 粗筛轮 → _run_fine() 细筛轮          [不动]
L1 选人层  _topdown.py：L1大盘闸 → L2板块闸 → L3板块内选股
           → flags 打标 → 【新】生态地图 _tier_context + 涨停票 seal 档
           → 去重截断 → analyzed_rank 骨架                                [改：4.1~4.3]
L2 证据层  _helpers.py / run.py：tech / 形态 / 资金卡 / mtf / rt / seal
           → 【新】承接位五锚 _anchor_levels + 承接证据 + 量价背离字段     [改：3.1~3.3]
L3 资格层  （空层，本方案不复活 entry_check——定性由 L4 做，L2 只出事实）   [不动]
L4 判定层  LLM + SKILL.md / report_guide 规则：
           强信号认定、资金两档、【新】拉升定性四问、【新】龙头/换龙头裁决
           【新】买点=承接位挂单、止损=承接位外侧                          [改：5.1~5.5]
L5 输出层  _compact_delivery 压缩 / 快照落盘 / OUTPUT_FORM                [改：5.5 表头]
```

职责铁律（各层不越权）：

- **L1/L2 只出事实与结构标签**（谁在场、钱在哪、锚在哪），不做"是不是出货"的定性结论
- **L4 只做裁量**（题材叙事、角色裁决、综合定性），不做算术（价位/宽度全部从字段取）
- **执行期只做纪律**（挂单、触发、止损），不临场改判

## 3. 字段层改造（L2，先做——后面所有层都依赖它）

### 3.1 承接位五锚 `anchor_levels`

**位置**：`_helpers.py`，新函数，包装现有 `_key_levels`（它已产出 `ma5|ma10|ma20|ma60 / lo10|lo20|lo60 / gap / poc / zt / hi20` 类型的位置）+ 补 `seal` 锚。

**输出 schema**（进 tech 卡 `support.anchor`）：

```json
"anchor": {
  "anchors": [
    {"k": "seal", "px": 10.53, "src": "封板价/涨停价", "evidence": "seal_tier=thick"},
    {"k": "zt",   "px": 9.31,  "src": "2026-11-23 涨停起点"},
    {"k": "poc",  "px": 9.85,  "src": "20日成交密集带中值"},
    {"k": "gap",  "px": 10.20, "src": "2026-11-24 跳空缺口上沿"},
    {"k": "lo20", "px": 9.30,  "src": "20日低点"}
  ],
  "primary": {"k": "zt", "px": 9.31, "rule": "R1"},
  "dist_pct": -2.1
}
```

- `anchors`：**全部五锚都给**（LLM/回测都可用），不删
- `primary`：合成主锚，**规则由 Phase 0 回测校准**（`QD_ANCHOR_PRIMARY_RULE` 指定 R1~R4，见 6.2），**不许手调**
- `dist_pct`：现价距 primary 的%

**伪代码**：

```python
def anchor_levels(bars, code, day, rt=None, seal=None):
    lv = _key_levels(bars, code, day)          # 现有函数，产出 supports/resists
    anchors = []
    if seal and seal.get("tag") not in (None, "none"):
        anchors.append({"k": "seal", "px": <涨停价或封板价>, "src": "封板价",
                        "evidence": f"seal_tier={seal.get('seal_tier')}"})
    for t in ("zt", "poc", "gap", "lo20", "lo10", "lo60"):
        hit = first level with level["k"] == t
        if hit: anchors.append({"k": t, "px": hit["px"], "src": <说明>})
    primary = apply_rule(os.getenv("QD_ANCHOR_PRIMARY_RULE", "R1"), anchors, price)
    return {"anchors": anchors, "primary": primary,
            "dist_pct": round((price - primary["px"]) / price * 100, 2)}
```

**验收**：单测给固定 K 线，断言五锚 px 值、primary 按规则选出、dist_pct 计算正确。

### 3.2 承接证据字段（"看见庄家还在"）

**位置**：`_helpers.py` 的 `attach_flow_strength` 旁，或 tech 卡新增 `anchor_evidence`：

```json
"anchor_evidence": {
  "seal_absorb": "thick",          // 封单档（seal_tier），仅封板票有
  "touched_today": true,           // 今日是否回踩过 primary±带宽
  "hold_minutes": 23,              // 今日停留在带宽内的分钟数（1m 聚合）
  "band_net_wan": +1200,           // 带宽内价格方向净额（承接是否真出钱）
  "level": "confirmed"             // confirmed / partial / none（合成档）
}
```

- `hold_minutes`/`band_net_wan`：用 1m 缓存按价格带聚合（带宽=±`QD_ANCHOR_BAND_PCT`，默认 1.5%）
- `level` 规则（v0）：`seal_absorb` 为 thick/vthick **或**（`touched_today` 且 `band_net_wan`>0）→ confirmed；只 touched 不带钱 → partial；都没 → none
- **验收**：单测造 1m 数据（带宽内停留/流入/流出三种情形）断言 level

### 3.3 量价背离字段（拉升段的钱）

**位置**：资金卡 `flow` 新增（数据源在按分钟涨跌方向累计时顺手拆两个和）：

```json
"flow": {"up_net_wan": +800, "down_net_wan": -350, "divergence": "none"}
```

- `divergence` 判定（代码直出，只描述形态）：
  - `"价升钱出"`：当日 chg>0 且 `up_net_wan`<0（上涨分钟里净额是负的=对倒/出货指纹）
  - `"脉冲背离"`：拉升段净额集中在开盘窗、其后转负（与 `_open_pump_risk` 合读）
  - `"none"`
- **验收**：单测造分钟序列，断言三类 divergence

## 4. 选人层改造（L1）

### 4.1 生态地图 `_tier_context`（**不认角色，只报生态**）

**位置**：`_topdown.py`，在 `flag_streak_surge` 之后、去重截断之前。

**核心设计（来自 2026-11-26 讨论）**：

- **不打"龙头/跟随"硬标签**——60s 颗粒度下分不清谁是龙头、是不是在换龙头，角色是**资金判断的输出**，不是选人层的输入
- 只出**生态事实**：同板块 T-5~T-1 谁在场（跳变/涨停/放量序列）、各自资金与支撑位、当日同伴数
- **跟随股看前三的资金质量，不看数量**（3 只跟风但资金全负=互倒造势，比孤板更毒）

**输出 schema**（每候选挂 `tier_ctx`）：

```json
"tier_ctx": {
  "board": "电机",
  "participants_5d": 4,                        // T-5~T-1 同板块在场者数
  "t1_participants": ["600xxx", "000yyy"],     // 昨日（T-1）在场者（最关键锚点）
  "today_peers": 3,                            // 当日同板块同伴数
  "funds_ok_n": 2,                             // 跟随前三中"5日资金正且支撑完好"的数量
  "lone_surge": false,                         // 孤立拉升标
  "note": "T-1 已有 2 只在场，今日 3 只同伴，2 只资金正"
}
```

**伪代码**：

```python
def _tier_context(items, board_members_fn, d, as_of):
    for x in items:
        board = x["board"]; members = board_members_fn(board)     # L2 同源的成分股查询
        hist = kline_batch(members, days=6, as_of=as_of)           # 含 T-5..T-1
        participants = [m for m in members if was_jump_or_zt_or_volume(hist[m], window=T-5..T-1)]
        t1 = [m for m in participants if was_active(hist[m], day=T-1)]
        peers_today = [y for y in items if y["board"] == board]    # 当日同板块候选
        funds_ok = count of top3 participants with net5d>0 and support_intact
        x["tier_ctx"] = {...}
        x["tier_ctx"]["lone_surge"] = (len(participants) == 0 and len(peers_today) <= 1)
    return items
```

**lone_surge 的处置（定死，不再留口子）**：

- `lone_surge=true` 的快速拉升**不进"买什么"**（与接刀/无确认接力同族——都是无信号下注）
- 但**留在 rank 带标**，不从名单删除（粗筛宁滥勿缺；LLM 可在"风险/证伪"里说明）
- 庄股/独立行情例外（与大盘恒反向、量能自锁）由 LLM 判，标 `note` 即可

**验收**：单测造"孤板板块"与"梯队板块"两个场景，断言 lone_surge 与 t1_participants。

### 4.2 涨停票补 seal 强度档（封板资金判强弱）

**位置**：`_topdown.py` 构造 `limit_up_ref` 的地方。

**改动**：每行加三个字段（数据从实时快照，封单=买一量×涨停价）：

```json
{"code": "600xxx", ..., "seal_ratio_pct": 23.5, "seal_tier": "thick", "open_count": 1}
```

- `seal_ratio_pct` = 封单额 ÷ 当日成交额 %（现有 seal 块同口径）
- 判读（写进 SKILL，见 5.4）：厚封+开板少=真强；薄封+反复开板=假板（出货/一日游嫌疑）
- **验收**：断言 limit_up_ref 行带齐三字段

### 4.3 flags 不动

`flag_streak_surge` / `_flag_early_accumulation` 保持现状（打标不放弃）。

## 5. 判定层改造（L4：SKILL.md + report_guide）

### 5.1 买点规则统一（三词退休，一锚上岗）

**新规则文本**（替换 SKILL.md「买点两种落法」段 + `report_guide.entry_exit` + OUTPUT_FORM 买点列说明）：

> **买点 = 承接位挂单**：从 rank `anchor.primary` 取锚位（写明类型：封板价/涨停起点/成交密集区/缺口/前低），挂单价 = 锚位 ± 带宽（带宽参考 `amp_avg5`，默认 ±1.5%）。
> **承接证据在位才成交**：`anchor_evidence.level` 为 confirmed（封单在/带宽内资金为正），partial 只给试仓，none 不买。
> 「回踩」「突破」「追价」不再是三种买法——回踩只是价格回到锚位的动作名；突破是价格离开锚位后的确认（此时买点上移到新锚）。

### 5.2 止损规则（承接位外侧 + 噪声带双锚）

> **止损 = 承接位外侧一档**（锚位下沿再退一个缓冲，缓冲 ≥ 1×噪声带）：主力建仓位失守 = 逻辑破，不是噪声。
> 双锚取宽：`stop_px = anchor_px − max(缓冲, min(amp_avg5, 8%))`——不得窄于噪声带，不得越过 -8% 深亏线（既有止损三条继续有效）。
> 触发口径照旧写明「盘中触价」/「收盘确认」；已持仓止损只紧不松（棘轮）。

### 5.3 拉升定性四问（定案表，替换"盘感"）

写进 SKILL.md 新段「拉升定性」（**四问全答，①一票否决**）：

| 问 | 真启动倾向 | 出货/孤立倾向 | 数据来源 |
|---|---|---|---|
| ① 钱：拉升段的钱在进还是在出？ | 分段持续流入（10:00 后）、`divergence=none` | **`divergence=价升钱出`/脉冲背离 → 一票否决** | `flow.up_net_wan/down_net_wan`、`flow.intraday`、`flow_risks` |
| ② 生态：前 5 天有人在场吗？ | `tier_ctx` 有 T-1 在场者、跟随前三资金正 | `lone_surge=true`、跟风资金全负 | `tier_ctx` |
| ③ 位置+承接：在哪、有人接吗？ | 锚位=建仓/成本位（zt/poc/seal），承接证据 confirmed | 高位锚远、`anchor_evidence=none`、`loc=hot` 无确认 | `anchor`、`anchor_evidence`、`loc` |
| ④ 盘口：涨得住吗？ | 回踩锚位不破、厚封少开板、`vol_up_down`>1 | 冲高回落（`strong_to_weak`）、`dd_from_peak` 扩大、薄封反复开板 | `shape`、`cross`、`seal` |

**定案**：①出货指纹 → 不进表；②③④ 同向 → 买点=锚位挂单；混合 → 试仓/写未知（"不判断"永远合法）。

### 5.4 龙头/换龙头裁决（L4，资金说了算）

> 「谁是龙头」是**结论不是输入**：持续承接 + 埋伏在身 + 封单厚 + 生态在场 = 龙头。
> **换龙头信号**：昨日在场者承接衰竭（封单变薄/资金转负）+ 新面孔资金初启（5 日转正+锚位承接）→ 按新面孔的锚位重排买点，旧龙回避。
> 涨停票强弱用封板资金：`seal_ratio_pct` 高 + `open_count` 少 = 真强；薄封+反复开板 = 假板（不接力）。

### 5.5 OUTPUT_FORM 表头与自查清单

- 买点列改格式：`承接位(类型) ±带宽，承接证据<confirmed/partial>`（例：「涨停起点 9.31±1.5%，承接 confirmed」）
- 自查清单第④条改为："买点/止损锚在 rank `anchor` 字段上，不许自创价位"
- **验收**：一次真实 `run()` 输出按新壳（人工核对一轮）

### 5.6 周期状态机（002242 型循环，2026-11-26 案例增补）

同一票会反复走完「跟随→拉升→变龙头→出货→换庄→再拉升」多个周期（活案例：002242
近 2 个月走完两个完整循环）。**角色是状态不是身份**——判定输出永远是「它现在处于哪个阶段」，
不是「它是什么股」。六态签名与 5.3 四问一一对应：跟随期（生态里非焦点）→拉升期（分段资金
流入+放量离开锚）→ 变龙头期（旧龙承接衰竭+它资金初启+生态重组）→ 出货期（价升钱出/上影
滞涨/锚距拉大）→ 换庄期（深回踩锚位+承接证据 confirmed+滞涨洗盘）→ 再拉升（新锚放量突破）。
**转换检测看「变化」不看「水平」**（承接证据 none→confirmed、资金对比翻转），必须带
T-5~T-1 前后文。

两补丁（活体回放暴露）：①**锚位滚动 + 失守即弃锚**——换庄后主力建仓位变了，旧锚失守后
primary 自动降级到下一锚，旧锚变压力；②**二进宫不带历史成见**——换龙头信号不能只看一次，
旧龙→出货→换庄→再来就重新算（002242 式的票会在板块内反复接棒）。

**时间基修正（2026-11-26 用户指正，日线透镜错了一个量级）**：换手 10-30%/日 ⇒ 换庄是
**1-2 天的换手率事件**（实测 002242 于 11/16-11/20 五天换手 100%+，一周内换庄两三次），
循环以天计、以十次计，不是以月计。三条硬结论：①状态机跑在 1m/60s，日线只是足迹；
②换庄检测 = 换手率事件（1-2 天换手 10-30%+ 且守关键位），新字段 = 当日换手率 +
**N 日换手覆盖率**（N 日累计换手÷流通盘 = 浮筹换了几遍，直接量化换庄次数）；
③锚位加**新鲜度权重**——浮筹一周换一遍的票，20 日 poc 是古代史，成本区 = 近期高换手日的
成交密集（进 Phase 0 网格作 R5），换庄后旧锚快速贬值。

**建仓日签名（2026-11-26 分时验证，002242 之 11-10/11-11/11-13）**：高换手（7-11%）+
价格横盘（<±1%）+ `above_ratio` 高（全天基本在 VWAP 上方，**下午 13:30 后仍在均价上 = 确认**）
= 承接换手/建仓日，下午即建仓窗口；反例 11-12（上午 4/4 好、下午 0/4 翻车、日线上影 85%）
= 试探/分歧日，不建仓。该签名与「早盘置信度低、10:00 后分段才算数」同构，直接用 shape 块的
`above_ratio`/`above_recent` 字段，无需新造。

### 6.1 `tmp/bt_anchor_20261126.py` 设计

## 8. 边界与不做什么（防矫枉过正）

1. **不预判意图**：不写"这是出货/这是换庄"的定性代码——只出事实（生态/承接/背离），定性是 L4 的裁量
2. **承接位是估计值**：主力成本不可直读，锚位是 zt/poc/seal 的合成——所以"证据在位才成交"不是可选项
3. **60s 颗粒度的角色噪声**：不硬认龙头；换龙头由资金裁决
4. **庄股/独立行情例外**保留（与大盘恒反向、量能自锁的票按独立行情读）
5. **不删除旧概念**：「回踩」「突破」保留为动作描述，只是不再是独立买法
6. **不新增硬编码阈值**：带宽、缓冲、优先级全走 env + 回测校准
7. **T+1 纪律**（次日冲高即走）、止损棘轮、噪声带、amp 雷区、资金两档、窗口权重——**一律不动**

## 9. 术语表

| 术语 | 定义 |
|---|---|
| **承接位（锚）** | 有真实资金驻守的价格位：封板价（封单托底）> 涨停起点 zt（建仓起点）> 成交密集区 poc（成本带）> 缺口/前低（结构位）。合成规则由回测校准 |
| **承接证据** | 锚位"有人还在"的实时证明：封单厚薄、锚位±带宽内停留分钟、带宽内价格方向净额 |
| **生态地图** | 同板块 T-5~T-1 在场者集合 + 各自资金/支撑，不认角色，只报事实 |
| **lone_surge** | 孤立拉升：板块前 5 天无人在场 + 当日无同伴——出货嫌疑，不进买什么 |
| **换龙头** | 旧龙承接衰竭 + 新面孔资金初启的板块内部换手，由资金判断裁决 |
| **量价背离** | `divergence=价升钱出`：上涨分钟净额为负——拉升段的钱在出，出货指纹，一票否决 |
