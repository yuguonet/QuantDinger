# 指标策略执行

当用户提到具体指标、指标策略、指标IDE时，用此技能。

## 评分规则

### 核心原则：有信号才评分

- **最近5天有买卖点** → 按信号方向评分（含衰减）
- **无近期信号** → 50分观望（附带历史胜率参考）

### 评分计算

1. 基础分：有信号 = 60分起步
2. 历史胜率加权（需 ≥5 笔交易）：
   - 胜率 ≥ 70% → 80分，置信度 0.9
   - 胜率 ≥ 60% → 70分，置信度 0.75
   - 胜率 ≥ 50% → 65分，置信度 0.6
   - 胜率 ≥ 40% → 55分，置信度 0.45
   - 胜率 < 40% → 45分，置信度 0.3
3. 收益加成：+20%→+10分，+10%→+5分，-10%→-10分
4. 盈亏比加成：≥2.0→置信+0.1，≥1.5→置信+0.05

### 延迟信号衰减

信号不在今天（前几天出现）→ 按天数衰减：
- 今天 = 1.0，昨天 = 0.95，前天 = 0.90，3天前 = 0.85，4天前 = 0.80

### 价格偏差衰减

信号价格 vs 当前价格偏差过大 → 信号可能已失效：
- 偏差 > 10% → ×0.6
- 偏差 > 5% → ×0.8

### 买卖冲突衰减

5天内同时出现买入和卖出信号 → 大幅衰减 ×0.5

### 买卖对称

买入和卖出使用完全相同的评分逻辑。

## 输出格式

标准 SkillReport + factors（每个指标一条，含胜率/收益/衰减原因）。
