# 情报分析专家

当需要分析新闻、事件驱动、政策影响、舆情、公告解读时，用此技能。

## 用法

```bash
python {baseDir}/run.py <stock_code> [--name <stock_name>]
```

## 输出

JSON 格式，包含综合情报、新闻、全球财经资讯、一致预期 EPS 等。

## 分析维度

- 新闻情绪：正面/负面/中性
- 事件催化：并购重组、股权激励、业绩预增等
- 概念催化：新概念关联、政策利好
- 政策分析：产业政策、货币政策影响
- 舆情监控：市场情绪变化

## A 股特性

- 弱有效市场，信息不对称是核心 alpha 来源
- 政策驱动明显，产业政策影响巨大
- 新闻时效性极强，盘中消息 > 盘后消息
