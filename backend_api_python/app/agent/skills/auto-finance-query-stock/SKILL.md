# A股个股实时行情与周期涨跌幅查询技能

## 使用场景

**适用**：
- 用户给出明确的 A 股股票代码或股票名称（如 目标代码、目标名称），要求"查询最新行情""最新价""当前股价""今日涨跌幅"。
- 用户指定一个观察周期（T+1 / T+3 / 1W / 1M），要求计算该周期内的累计涨跌幅（用周期起始日的收盘价与最新日收盘价对比）。
- 用户只问"涨跌幅"且未限定时间窗口，默认按"当日涨跌幅"输出。

**不适用**：
- 港股、美股、基金、债券、加密货币等非 A 股标的（本技能工具签名仅覆盖 A 股行情接口）。
- 需要深度技术分析（形态识别、筹码分布、资金流向、龙虎榜、估值对比等）——这些属于其他技能范畴，不在本技能覆盖范围内。
- 需要 Tick 级或盘后逐笔数据——工具层不提供 Tick/逐笔。
- 需要分钟 K 线请改用 `agent_get_kline(timeframe='1m'|'5m'|'15m'|'30m'|'1H'|'4H')`（已支持，见下文）；本技能默认演示日频/快照口径。
- `web_search` 在本沙箱**不可用**，不得作为数据兜底。

## 执行流程

### 第 1 步：实体解析与代码标准化
- 输入形如 `目标名称`、`目标代码`、`目标代码.SH`、`目标名称(目标代码)`。
- 抽取其中 6 位股票代码（如 `目标代码`）。若用户只给了名称，需先用 `get_stock_info(codes="目标代码", detail=False)` 反查代码与名称的对应关系（输出含 `name`、`symbol` 等字段）。
- 统一格式化为纯 6 位字符串（例如 `"目标代码"`）作为后续接口入参。**不要**把代码包成 list 传入——见注意事项。

### 第 2 步：拉取实时行情快照（主数据源）
调用：
```
get_realtime_quote(codes="<6位代码>")
```
- 参数 `codes` 类型为 **字符串**（多个代码用英文逗号分隔，例如 `"目标代码1,目标代码2"`），**绝对不能传 list**。
- 返回结构（典型字段名）：
  - `name`：股票中文名
  - `symbol` / `stock_code`：股票代码
  - `market`：市场（SH / SZ）
  - `last`：最新价（当前交易日收盘价或最新成交价）
  - `open`：今开
  - `high`：最高
  - `low`：最低
  - `previousClose`：昨收
  - `change`：涨跌额（元）
  - `changePercent`：当日涨跌幅（%）
  - `volume`：成交量
  - `time`：行情时间戳
- 若返回 `{'error': '...'}`：检查错误信息；若是 `AttributeError: 'list' object has no attribute 'split'`，说明 `codes` 误传为 list，必须改为字符串后重试。

### 第 3 步：按周期计算累计涨跌幅（可选）
仅当用户明确要求观察周期时，才计算周期涨跌幅。未指定周期时，只输出行情快照中的当日涨跌幅，不调用 K 线工具，也不额外添加 T+1/T+3 分析。

周期统一按交易日定义：
- `T+1` → 1 个交易日
- `T+3` → 3 个交易日
- `1W` → 5 个交易日
- `1M` → 21 个交易日

计算 N 个交易日周期需要 N+1 根日线收盘价（周期起点收盘价与最新收盘价各一根），不按自然日折算：

1. 调用：
   ```
   kline = agent_get_kline(codes="<6位代码>", timeframe="1D", days=<交易日数 + 1>)
   ```
   - `codes` 同样是**字符串**；`timeframe` 用 `"1D"`；`days` 是需要返回的日线根数，取 N+1。
2. 从 K 线结果的日线列表按时间升序取出最新收盘价及其前 N 个交易日的收盘价。
3. 周期涨跌幅 = `(最新收盘价 - N个交易日前收盘价) / N个交易日前收盘价 * 100`，单位 %。
4. 若返回数据不足 N+1 根或 K 线接口返回 `error`，不得改用自然日、编造或缩短周期；说明该周期无法计算。若实时快照可用，仍输出快照字段。

### 第 4 步：组装并输出结果
按以下结构返回给用户：

| 字段 | 数值 |
|---|---|
| 股票名称 | `<name>` |
| 股票代码 | `<symbol>` |
| 最新价 | `<last>` |
| 当日涨跌额 | `<change>` |
| 当日涨跌幅 | `<changePercent>%` |
| 周期涨跌幅（如有） | `<period_change_percent>%` |
| 今开 / 最高 / 最低 / 昨收 | `<open> / <high> / <low> / <previousClose>` |
| 成交量 | `<volume>` |
| 行情时间 | `<time>` |

- 数值保留 2 位小数；涨跌幅单位统一为 `%`。
- 若某字段缺失（值为 `None` / `N/A`），保持字段名但值写 `N/A`，并在末尾追加"原因说明"段落，不得伪造。

## 注意事项

1. **`codes` 必须是字符串，禁止传 list**：本沙箱多次出现 `AttributeError: 'list' object has no attribute 'split'` 报错。轨迹中已验证：传入 `codes="目标代码"`（字符串）可正常返回；传入 `codes=["目标代码"]`（列表）会触发异常。出现该异常时立即把参数改成字符串并**重试一次**（最多 1 次），不要无脑多次重试。

2. **仅调用本技能列出的工具**：`get_realtime_quote`、`agent_get_kline`、`get_stock_info` 是本技能的工具白名单。不得为查找这些已列出的工具而调用 `search_resources`、`list_resources` 或激活其他工具；若白名单工具不可用，直接说明，不扩展检索。

3. **严格遵守用户请求范围**：只把用户明确要求的周期当作查询条件；禁止把“不要查询/不要计算某周期”误读成用户要求该周期，也不要声称用户提出了未出现的周期。未要求周期时不查询 K 线、不计算周期涨跌幅，也不追加资金流、技术分析等内容。成交额等未由工具明确提供且注明单位的字段，不得用最新价乘成交量估算或引用来源不明的近似值；用户要求时说明数据缺失及原因。

4. **数据源可能未挂载**：轨迹实际跑过 agent 出现过 `get_realtime_quote` / `agent_get_kline` 返回 `{'error': '...'}` 的情况。处理策略：
   - 实时行情返回 `error`：直接放弃本步，输出"数据源未挂载"说明，**不要**尝试 web_search 兜底（沙箱中 `web_search` 不可用，已实测）。
   - K 线返回 `error`：跳过周期涨跌幅，仅输出实时行情快照中的当日涨跌幅，并在备注中说明"周期涨跌幅因 K 线接口不可用而未计算"。

5. **重试机制**：仅对"参数类型错误（list → str）"这一类**确定可恢复**的错误进行重试；对数据源不可用、行情不存在等**业务性错误**不要重试，直接降级输出并说明原因。

6. **代码标准化**：用户输入里常见的变体有 `目标代码`、`目标代码.SH`、`目标名称(目标代码)`。统一抽取 6 位纯数字代码作为 `codes` 入参，不要把后缀 `.SH` / `.SZ` 一并传入 `get_realtime_quote`（标准做法是只传 6 位数字）。

7. **涨跌幅单位**：接口返回的 `changePercent` 已带百分号数值（如 `1.23` 即 `1.23%`），输出时**不要**再乘 100。

8. **避免引用不在白名单的工具**：不要因贪图信息丰富度去调用 `get_order_book` / `technical_analysis` / `get_fund_flow` 等，扩展功能留给别的技能。

9. **故障列表**：当前 trace 未观察到链路胜率显著偏低的工具，不强制禁用项；若 `agent_get_kline` 返回数据不足或 `error`，不得把交易日周期缩短或改成自然日重试，应按"数据源不可用"降级处理。
