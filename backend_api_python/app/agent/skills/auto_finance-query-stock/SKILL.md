# A股个股实时行情与周期涨跌幅查询技能

## 使用场景

**适用**：
- 用户给出明确的 A 股股票代码或股票名称（如 600176、000001、中国巨石、平安银行），要求"查询最新行情""最新价""当前股价""今日涨跌幅"。
- 用户指定一个观察周期（T+1 / T+3 / 1W / 1M），要求计算该周期内的累计涨跌幅（用周期起始日的收盘价与最新日收盘价对比）。
- 用户只问"涨跌幅"且未限定时间窗口，默认按"当日涨跌幅"输出。

**不适用**：
- 港股、美股、基金、债券、加密货币等非 A 股标的（本技能工具签名仅覆盖 A 股行情接口）。
- 需要深度技术分析（形态识别、筹码分布、资金流向、龙虎榜、估值对比等）——这些属于其他技能范畴，不在本技能覆盖范围内。
- 需要分钟级、Tick 级或盘后逐笔数据——`get_realtime_quote` 与 `agent_get_kline` 默认输出日频/快照级数据。
- `web_search` 在本沙箱**不可用**，不得作为数据兜底。

## 执行流程

### 第 1 步：实体解析与代码标准化
- 输入形如 `中国巨石`、`600176`、`600176.SH`、`中国巨石(600176)`。
- 抽取其中 6 位股票代码（如 `600176`）。若用户只给了名称，需先用 `get_stock_info(codes="600176", detail=False)` 反查代码与名称的对应关系（输出含 `name`、`symbol` 等字段）。
- 统一格式化为纯 6 位字符串（例如 `"600176"`）作为后续接口入参。**不要**把代码包成 list 传入——见注意事项。

### 第 2 步：拉取实时行情快照（主数据源）
调用：
```
get_realtime_quote(codes="<6位代码>")
```
- 参数 `codes` 类型为 **字符串**（多个代码用英文逗号分隔，例如 `"600176,000001"`），**绝对不能传 list**。
- 返回结构（典型字段名）：
  - `name`：股票中文名
  - `symbol` / `stock_code`：股票代码
  - `market`：市场（SH / SZ）
  - `last`：最新价（当前交易日收盘价或最新成交价）
  - `open`：今开
  - `high`：最高
  - `low`：最低
  - `previousClose`：昨收
  - `change`：涨跌额（元）
  - `changePercent`：当日涨跌幅（%）
  - `volume`：成交量
  - `time`：行情时间戳
- 若返回 `{'error': '...'}`：检查错误信息；若是 `AttributeError: 'list' object has no attribute 'split'`，说明 `codes` 误传为 list，必须改为字符串后重试。

### 第 3 步：按周期计算累计涨跌幅（可选）
当用户在原始问题中显式给出了周期参数 `T+1` / `T+3` / `1W` / `1M`（默认 = `T+1`），需要计算周期涨跌幅：

1. 把周期映射成自然日数：
     - `T+1` → 1
     - `T+3` → 3
     - `1W` → 5（按交易日近似）或 7（按自然日，按用户语义选其一；推荐 5 个交易日）
     - `1M` → 20（按交易日近似）或 30（按自然日）
2. 调用：
   ```
   kline = agent_get_kline(codes="<6位代码>", timeframe="1d", days=<覆盖周期天数>)
   ```
   - `codes` 同样是**字符串**；`timeframe` 用 `"1d"`；`days` 取 ≥ 周期日数 + 5（预留节假日 buffer）。
3. 从 K 线结果中按时间升序取出：
   - `period_start_close`：周期起始日（含）的收盘价 `close`
   - `latest_close`：最近一日的收盘价 `close`
4. 周期涨跌幅 = `(latest_close - period_start_close) / period_start_close * 100`，单位 %。
5. 若 K 线接口返回 `{'error': '...'}`（数据源未挂载的情况），不得编造数值；按"无法计算周期涨跌幅"输出，并在响应中标明"标准/深度分析因数据源未挂载而跳过"。

### 第 4 步：组装并输出结果
按以下结构返回给用户：

| 字段 | 数值 |
|---|---|
| 股票名称 | `<name>` |
| 股票代码 | `<symbol>` |
| 最新价 | `<last>` |
| 当日涨跌额 | `<change>` |
| 当日涨跌幅 | `<changePercent>%` |
| 周期涨跌幅（如有） | `<period_change_percent>%` |
| 今开 / 最高 / 最低 / 昨收 | `<open> / <high> / <low> / <previousClose>` |
| 成交量 | `<volume>` |
| 行情时间 | `<time>` |

- 数值保留 2 位小数；涨跌幅单位统一为 `%`。
- 若某字段缺失（值为 `None` / `N/A`），保持字段名但值写 `N/A`，并在末尾追加"原因说明"段落，不得伪造。

## 注意事项

1. **`codes` 必须是字符串，禁止传 list**：本沙箱多次出现 `AttributeError: 'list' object has no attribute 'split'` 报错。轨迹中已验证：传入 `codes="600176"`（字符串）可正常返回；传入 `codes=["600176"]`（列表）会触发异常。出现该异常时立即把参数改成字符串并**重试一次**（最多 1 次），不要无脑多次重试。

2. **数据源可能未挂载**：轨迹实际跑过 agent 出现过 `get_realtime_quote` / `agent_get_kline` 返回 `{'error': '...'}` 的情况。处理策略：
   - 实时行情返回 `error`：直接放弃本步，输出"数据源未挂载"说明，**不要**尝试 web_search 兜底（沙箱中 `web_search` 不可用，已实测）。
   - K 线返回 `error`：跳过周期涨跌幅，仅输出实时行情快照中的当日涨跌幅，并在备注中说明"周期涨跌幅因 K 线接口不可用而未计算"。

3. **重试机制**：仅对"参数类型错误（list → str）"这一类**确定可恢复**的错误进行重试；对数据源不可用、行情不存在等**业务性错误**不要重试，直接降级输出并说明原因。

4. **代码标准化**：用户输入里常见的变体有 `600176`、`600176.SH`、`中国巨石(600176)`。统一抽取 6 位纯数字代码作为 `codes` 入参，不要把后缀 `.SH` / `.SZ` 一并传入 `get_realtime_quote`（标准做法是只传 6 位数字）。

5. **涨跌幅单位**：接口返回的 `changePercent` 已带百分号数值（如 `1.23` 即 `1.23%`），输出时**不要**再乘 100。

6. **避免引用不在白名单的工具**：本技能仅依赖 `get_realtime_quote`、`agent_get_kline`、`get_stock_info` 三个工具；不要因贪图信息丰富度去调用 `get_order_book` / `analyze_trend` / `get_fund_flow` 等，扩展功能留给别的技能。

8. **故障列表**：当前 trace 未观察到链路胜率显著偏低的工具，不强制禁用项；若后续链路中 `agent_get_kline` 持续返回 `error`，应优先尝试把 `days` 调小（如 10）再试一次，仍然失败则按"数据源不可用"降级处理。
