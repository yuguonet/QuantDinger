# 选股规则手册（rules live here, not in code）

> 本文件存放**候选来源 / 形态定义 / 指标口径 / 历史存档**等规则。
> `_facts.py` / `_helpers.py` / `run.py` 只提供客观事实，**不含任何取舍**。
> **交易判定真源**（支撑×强弱矩阵、涨跌停带、三时段）在 `trading-logic.md` §0；
> 六维读法与周期落笔在 `analysis-framework.md`。
> 分析周期 = **短中线，主看 T+1 / T+3 / T+5**（T+10 / T+20 可选，不强制）；`p_up` 只标定 T+1。
> 下面所有条目的性质不同，请注意区分三档：

| 标记 | 含义 | 你能不能推翻 |
| --- | --- | --- |
| 【定义】 | 某个形态/指标的几何定义，代码里实现就是照这个写的 | 可以通过 `detect_patterns(params=...)` 覆盖，但改了就等于换了另一种形态 |
| 【历史】 | 2026-09-29 前写在代码里的旧口径，**当你想看旧版为什么这么选时查阅** | 完全可以推翻，它们没有被标定验证过 |
| 【提示】 | 经验值 / 常见误区 | 应当结合当日证据判断 |

## 一、数据源硬事实（先记住，否则会踩空）

- **分钟源只有 `1m`。** 实测 `15m` / `5m` / `30m` / `60m` 查表恒返回 **0 行**（历史裁定：kline_15m 已回填进 kline_1m 并标 void）。
  `_facts.multitimeframe()` 因此统一取 1m 后本地聚合成 15m / 5m。
  后果：任何依赖「15m 单独成表」的旧结论都不成立。
- 【历史】旧 `intraday.analyze_code` 里的「15m 共振 +5」「5m+15m 共振 +5」「5m MACD 强弱 ±8/-5」在旧代码里**从未真正生效过**
  （因为 m15 / m5 永远取不到值）——这是旧版「分析深度不够」的一个实证来源。
- 日线 (`fetch_kline`) 正常；`search_stocks` 走东方财富，偶发失败，失败会进 `missing`。
- **bar vs rt 对账（2026-10-14）**：`deep_analyze` 的技术指标来自日线，但**可执行性字段
  （收盘 / 涨跌停）以 `rt` 为准**；本地日线滞后时标 `stale_bar=true`（详见
  `analysis-framework.md` 维度 6）。不要拿 bar 口径的涨停/收盘去推「今天能不能买」。

## 二、候选来源（仪器，`pre_screen(sources=...)` 自选）

**选股目标（2026-10-28 用户裁定）：短线最小风险、最大涨幅。**
连板 / 尾盘封板 / 龙回头 / 近期涨停 = 追高或接刀，**整源删除**，不再作可选仪器。
涨停池数据只用于 `market_state` / `zt_streak` 等客观事实，不进候选池。

| source | 取到什么 | 定义口径 |
| --- | --- | --- |
| `hot` | 当日热点题材股 | 热榜，带涨停原因（题材命中线索，**不是追高特权**） |
| `search` | 条件搜索 | `search_stocks`（东财智能选股）——**只是多源之一，不是唯一通道** |
| `flow` | 人气榜 | `get_hot_rank`：关注度/资金聚集线索 |
| `sector` | 板块成分 | 热门行业/概念板块成分股（主线内非涨停候选） |
| `scan` | 本地结构扫描 | 日线几何：站上/贴均线且非 20 日高位（**不依赖东财**） |

默认查询词围绕「有支撑 + 资金/趋势确认 + 未极端追高」（见 `_QUERY_DEFAULT`）：
涨幅区间+均线结构、主力资金、放量突破、缩量回调等**东财能命中**的过滤语句。

**池底补采（2026-10-28）**：hot 在涨停潮里几乎全是封板，若默认词命中偏少，
池子会被「封板+ST」吃光 → `candidate_pool` 在 pool&lt;40 时自动追加 `_QUERY_EXPAND`
更宽过滤词。`missing` 里「池底补采后仍偏少」= 结构性提示，不是数据故障。

【历史】旧版按时段写死的默认组合（含 zt / dragon / recent_zt，**已删除**）：

| 时段 | 旧默认 sources | 旧默认 queries |
| --- | --- | --- |
| intraday | zt, dragon, search | 放量突破 站上20日均线 / 缩量企稳 底部放量 |
| eod | eod_zt, search | 涨幅3%到8% 换手率大于3% 非ST |
| post_market | hot, search, recent_zt, dragon | 涨幅1%到8% 换手率大于2% 非ST / 近10日涨停 … |

【历史】旧版还会按情绪分换搜索词，这套映射**已从代码里删除**，留给按需自己判断：

| 旧情绪分 | 旧搜索词 |
| --- | --- |
| >= 60（偏强） | 板块龙头、放量突破、{最强板块} 涨幅靠前 |
| 40-59（中性） | 弱转强 站上5日均线、缩量企稳 底部放量 |
| < 40（偏弱） | 逆势上涨 放量、BB下轨 超卖反弹 |

## 三、候选池默认行为（现在 vs 从前）

> **范围**：本节说的是 `pre_screen` / `profile_candidates` 层的默认行为。
> `run()` 一键路径为**单漏斗**（2026-10-28）：客观预排除 → p_up 软门槛 +
> 回捞（贴支撑/题材、弱转强、缺分保送）→ deep。**没有** 8.1.0 基线保底，
> **没有** 连板/龙回头稀缺名额。

| 项目 | 旧版（写死） | 现在（pre_screen / profile 层） |
| --- | --- | --- |
| 候选源 | 连板/龙回头/尾盘封板/近期涨停优先 | **只有 hot + search**；追高源整源删除 |
| 换手率过滤 | < 2% 直接剔除（`turnover_pct` 缺失时不剔） | 默认**不过滤**，换手不足在画像的 `hard` 里标记，你决定是否排除；要过滤就传 `min_turnover=` |
| 排序 | 连板 > 龙回头 > 条件搜索 | **不排序**（我们能写的排序都是偏见）。你按自己口径排 |
| 截断 | intraday 20 只 / eod 15 只 / post_market 40 只 | **不截断**，`limit=` 才截 |
| 去重 | 按 code 保留最先来的 | 仍按 code 去重，但多个来源时用 `+` 合并（`热点题材+条件搜索`） |

## 四、形态：六种几何定义【定义】

`detect_patterns()` 用下面的参数识别。改它们 = 换一种形态，不是调松紧。

| 参数 | 默认 | 属于哪个形态 |
| --- | --- | --- |
| `platform_range_pct` | 8.0 | 平台突破：前 5 根高低区间的振幅上限 |
| `breakout_vol_ratio` | 1.3 | 平台突破 / 突破前高：当日量 / 前 5 根均量下限 |
| `surge_vol_ratio` | 1.8 | 底部放量启动：当日量 / 前 5 根均量下限 |
| `flat_change_pct` | 5.0 | 底部放量启动：区间涨跌幅绝对值上限（超过说明不是横盘） |
| `ma_touch_pct` | 1.5 | 均线支撑回踩：最低价距 MA10 的距离上限 |
| `min_pullback_pct` / `max_pullback_pct` | 3.0 / 12.0 | 缩量回调放量突破：回调幅度区间 |
| `shrink_ratio` | 0.7 | 缩量回调放量突破：回调段均量 / 前段均量上限 |
| `rebreak_vol_ratio` | 1.5 | 缩量回调放量突破：再突破当日 / 回调段均量下限 |

返回值**没有 score** —— 旧版每个形态自带一个 60~75 的分，那是没有标定依据的手拍值，
已在本次重构中全部删除。

【提示】形态只能解释「发生了什么」，不能直接加成胜率。
形态 + 题材 + 资金同向才值得写进结论；三者缺二，把它写进「数据缺口」。

## 五、多周期标签怎么读【提示】

`multitimeframe()` 返回**速记标签**，它们描述几何关系，不含方向评价：

**日线结构（不是盘中即时信号）**

- `weak_to_strong` = 最近 5 根有 ≥4 根站上 MA5，且之前 5 根有 ≥3 根未站稳 MA5（或 MACD 绿柱期仍站稳 MA5）
- `strong_to_weak` = 反向
- 盘中强弱用 `rt` + `m5`/1m 自行判断（见 `trading-logic.md` §0.3；判定优先级 §0 ≫ §1）

**量能与分钟强度**

- `volume_pattern` = {放量上涨, 缩量上涨, 放量下跌, 缩量下跌, 平量整理}
- `m5.macd_strength` = {sell_pressure_low, sell_pressure_high, even}
  看的是最近 20 根 5 分钟 K 线里：绿柱段的平均振幅 vs 红柱段的平均振幅。
  绿柱段振幅更小 = 卖压打不下去；更大 = 抛压重。
- `daily.ma5_slope_pct` / `ma60_slope_pct` = 均线斜率（%），比二进制的「金叉/死叉」更早给出强弱变化

工具会给出 `missing` —— 分钟线缺失时（例如长期停牌 / 1m 源无覆盖）这些标签会是空值，
**别把「拿不到」当成「中性」，也别当成有 alpha**。

## 六、仓位 / 入场 / 止损（旧代码里的公式，全盘移交给你）

【历史】旧 `post_market.analyze_code` 的介入点算法，现在不再自动算：

```
entry_low  = close * 0.995
entry_high = close * 1.005
stop_loss  = MA10（无 MA10 时用 close * 0.97）
target_1   = close + (close - stop_loss) * 1.5
target_2   = close + (close - stop_loss) * 2.5
```

这套「1:1.5 / 1:2.5」没有任何标定依据，别默认它是对的。
要给出入场/止损，请结合 `tech.dist_ma20_pct`（乖离大就别把止损设在贴身位置）和当日 `amplitude_pct`。

## 七、情绪分数是怎么算的【历史】

`market_state()` 的 `mood_score` 沿用旧口径（**描述性标签，非入场规则**）：

```
base 50
+ min(20, 上证净流入 // 1e7)        净流出则 max(-20, ...)
+ 10  若涨停家数 > 30；- 10 若 < 15
- 15  若跌停家数 > 20
- 10  若炸板率 > 40%；+ 5 若 < 20
mood: >=70 偏强 / >=50 中性 / >=30 偏弱 / 否则 弱势
```

`_helpers._mood_regime` 把它映射成 strong / neutral / weak，只用于给预测模型传上下文 + 生成 `hints` 建议门槛。

方向：>=60 看多，<45 看空；confidence = 0.4 + 命中信号数 × 0.05（上限 0.9）。

## 九、选股主轴（2026-10-28：短线最小风险、最大涨幅）

**目标拆解**

| 目标 | 操作含义 | 落点 |
| --- | --- | --- |
| 最小风险 | 有清晰支撑（贴 MA5/10/20）；非追高、非无支撑下跌；止损可写「跌破 X」 | `tech.support` / `near_support` / `hard`；`run()` 的 floor 回捞认「贴支撑」 |
| 最大涨幅 | 落在当日主线、资金确认（主力流入/弱转强）、量价结构健康、有上行空间 | `theme.hit` / `flow` / `p_up`（T+1 唯一标定分）/ w2s 回捞通道 |
| **现价优先入场** | 信号明确（突破/通道打开/弱转强）时**现价买优于等回踩**；回踩只是 Plan B | 买点写「现价 X」；风险收益比按现价算（见 `analysis-framework.md`） |

**不该再做的事**

- 从连板池 / 龙回头 / 近端涨停名单里「挑前几名」——那是追高与接刀
- 把「曾经涨停过」当加分项
- 用未标定的形态手拍分替代 `p_up`
- **把「等回踩」写成唯一买点**（回踩不一定成交）；也**不要把「现价买」说成追高**

**术语对照（防混）**

| 词 | 含义 | 不是什么 |
| --- | --- | --- |
| **追高** | 无信号 / 无支撑 / 连板接力式的高位上车 | ≠「信号明确时的现价买入」 |
| **现价买** | 买点写「现价 X」，按现价算风险收益比 | ≠ 涨停板上抢筹 |
| **回踩买** | Plan B：「回踩 MA/前高 X」，可能不成交 | ≠ 默认入场方式 |
| **个股流通市值** | `float_mcap_yi`，个股盘子大小 | ≠ 大盘指数强弱 |
| **龙虎榜** | inspect_stock 的席位数据 | ≠ 已删除的「龙回头」选股源 |

**弱转强（run() 的 w2s 通道）** 是「低风险位 + 资金确认」的标准样本：
回踩 MA5 滞跌 + 主力净流入 ≥2000 万 + 今日主力>昨日 + 日线结构仍好。

【历史】旧「已验证策略」存档（**不要照抄**，尤其 4IN1/龙回头买点）：

- BB 超卖：价格触 BB 下轨 + MA60 斜率 >= 0 + 振幅 > 8%；次日 9:50 左右确认再买
- 4IN1 涨停：V1 首板次日放量涨停 → D+1 开盘买；龙回头 A/B 回调企稳 → 买；断板 → 次日开盘买
- 选股不应只从涨停池 / 热榜取（本质追高）：先看大盘资金与板块强弱，再用 `search` 按条件搜

## 十、关键时间窗口

| 时间 | 意义 |
| --- | --- |
| 09:15-09:25 | 集合竞价 |
| 09:30-10:00 | 开盘半小时，判定板块强弱与资金流向；10:00 前基本定调（**早盘结论置信度低**） |
| 09:50 | BB 超卖策略的建议买入时点 |
| 14:30-15:00 | 尾盘：收盘位置、量能与是否封板的观察窗口 |
| 15:00+ | 盘后：静态技术形态扫描与次日计划（**勿写「目前涨跌」**） |

同一判定原则在三时段的落法（盘中/尾盘/盘后各自问什么）→ `trading-logic.md` §0.4。

## 十一、做敏感性检查的建议

规则写在 md 里的一个实际好处是可以做对照实验。建议至少验证这几项：

1. `detect_patterns` 的 params 上下浮动 20%，看入选名单是否剧烈变化 —— 剧烈 = 结论依赖阈值而非事实
2. `pre_screen(sources=...)` 单开某个来源，看结论是否只由单一来源支撑
3. `multitimeframe` 的 `minute_days` 调大，确认日内标签是否稳定
4. 把 `p_up` 单独排序 vs「p_up + 题材共振」排序，比较名单差异并记录为什么更信后者
