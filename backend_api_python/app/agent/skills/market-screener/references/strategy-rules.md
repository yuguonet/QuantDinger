# 选股规则手册（rules live here, not in code）

> 本文件存放**候选来源 / 形态定义 / 指标口径**等规则。
> `_facts.py` / `_helpers.py` / `run.py` 只提供客观事实，**不含任何取舍**。
> **交易判定真源**（支撑×强弱矩阵、涨跌停带、三时段）在 `trading-logic.md` §0；
> 六维读法与周期落笔在 `analysis-framework.md`。
> 分析周期 = **短中线，主看 T+1 / T+3 / T+5**（T+10 / T+20 可选，不强制）。
> 下面条目的性质不同，请注意区分两档：

| 标记 | 含义 | 你能不能推翻 |
| --- | --- | --- |
| 【定义】 | 某个形态/指标的几何定义，代码里实现就是照这个写的 | 可以通过 `detect_patterns(params=...)` 覆盖，但改了就等于换了另一种形态 |

## 一、数据源硬事实（先记住，否则会踩空）

- **分钟源只有 `1m`。** `15m` / `5m` / `30m` / `60m` 查表恒返回 **0 行**。
  `_facts.multitimeframe()` 统一取 1m 后本地聚合成 15m / 5m。
  任何依赖「15m 单独成表」的结论都不成立。
- 日线 (`fetch_kline`) 正常；`search_stocks` 走东方财富，偶发失败，失败会进 `missing`。
- **bar vs rt 对账**：`deep_analyze` 的技术指标来自日线，但**可执行性字段
  （收盘 / 涨跌停）以 `rt` 为准**；本地日线滞后时标 `stale_bar=true`（详见
  `analysis-framework.md` 维度 6）。不要拿 bar 口径的涨停/收盘去推「今天能不能买」。

## 二、选人链路（唯一：三层漏斗）

选人规则不在本文件——`run()` 内部唯一链路是 `_topdown.py` 的盘中三层漏斗：

```
L1 大盘闸（同刻量能 vs 前 N 日 + 指数同刻涨跌 → strong/weak/shrink/neutral 三档松紧）
  → L2 板块闸（行业/概念**分开**各取 N 个：弱 4 / 中性 6 / 强 8，按净占比排序、
    同族合并，无备选）
    → L3 板块内选股（有涨停走健康闸+涨停票、无涨停走跳变检测，
      跟随判定只作板块准入闸不出票，每板块 ≤10 只）
      → 连板放量/吸筹打标（连板高度 ≥2 且当日放量上涨、吸筹不足/已过度拉升 →
        挂 flags 保留，高波动档护栏，取舍归裁决层）（2026-11-23 小资金复利对齐）
        → 合并去重（dup_n = 重复板块数，重复越多 = 板块共识越强）
          → 按「板块内先跳优先（board_rank：同板块 t_first 升序序号，1=板块龙头）→ board_net_pct 板块强度 → dup_n 多板块共识 → 触板/跳变时刻」截断 35 送 deep（共识优先，2026-11-26 拍板；BOARD_RANK_FIRST=0 回退纯时间口径）；盘后收盘池回填封单额/连板数
            （deep 满卡尽量给非涨停票）
```

各层判据与阈值全部走 `QD_TOPDOWN_*` 环境变量；取数统一走 `data_sources.screen_query`
（本地量价方向净额，截至 as_of 同刻，零前视）。

**拉抬检测（第三类真拉升，未现跳变，2026-11-27 用户改进）**：跳变检测只抓「当前时刻跳变」
（两极端：冲高出货与真拉升），漏「拉升没在某个时刻突然跳变」的票——此类票判据（`detect_pullups`，
阈值走 env `QD_TOPDOWN_PULLUP_*`）：① 分时图绝大部分时间在日均线VWAP之上（1m 价格 ≥ 日 MA5 的
分钟占比 ≥ 默认 60%）+ 当日收盘在 MA5 之上；② 日均线趋势平缓向上（MA5 斜率 ≤ 默认 2%，近 5 日
未大幅下跌 > -10%）；③ 资金在吸筹（10:00 后分段持续净流入 或 近 5 日累计净流入为正且非单日脉冲，
净额 ≥ 默认 2000 万）。此类为**真拉升候选（非追高）**，进漏斗（`kind='pullup'`）参与去重/截断排序
（t_first 升序，跳变优先于未跳变拉升），deep 分析后按承接位/现价买规则入场；**拉抬候选走龙头优先规则**
（见 §六 仓位档下方）：`board_rank=1` 优先，非龙头只给试仓/条件单、不给标准档。


## 四、形态：六种几何定义【定义】

`detect_patterns()` 用下面的参数识别。改它们 = 换一种形态，不是调松紧。

| 参数 | 默认 | 属于哪个形态 |
| --- | --- | --- |
| `platform_range_pct` | 8.0 | 平台突破：前 5 根高低区间的振幅上限 |
| `breakout_vol_ratio` | 1.3 | 平台突破 / 突破前高：当日量 / 前 5 根均量下限 |
| `surge_vol_ratio` | 1.8 | 底部放量启动：当日量 / 前 5 根均量下限 |
| `flat_change_pct` | 5.0 | 底部放量启动：区间涨跌幅绝对值上限（超过说明不是横盘） |
| `ma_touch_pct` | 1.5 | 均线支撑回踩：最低价距 MA10 的距离上限 |
| `min_pullback_pct` / `max_pullback_pct` | 3.0 / 12.0 | 缩量回调放量突破：回调幅度区间 |
| `shrink_ratio` | 0.7 | 缩量回调放量突破：回调段均量 / 前段均量上限 |
| `rebreak_vol_ratio` | 1.5 | 缩量回调放量突破：再突破当日 / 回调段均量下限 |

返回值**没有 score**。

【提示】形态只能解释「发生了什么」，不能直接加成胜率。
形态 + 题材 + 资金同向才值得写进结论；三者缺二，把它写进「数据缺口」。

## 五、多周期标签怎么读【提示】

`multitimeframe()` 返回**速记标签**，它们描述几何关系，不含方向评价：

**日线结构（不是盘中即时信号）**

- `weak_to_strong` = 最近 5 根有 ≥4 根站上 MA5，且之前 5 根有 ≥3 根未站稳 MA5（或 MACD 绿柱期仍站稳 MA5）
- `strong_to_weak` = 反向
- 盘中强弱用 `rt` + `m5`/1m 自行判断（见 `trading-logic.md` §0.3；判定优先级 §0 ≫ §1）

**量能与分钟强度**

- `volume_pattern` = {放量上涨, 缩量上涨, 放量下跌, 缩量下跌, 平量整理}
- `m5.macd_strength` = {sell_pressure_low, sell_pressure_high, even}
  看的是最近 20 根 5 分钟 K 线里：绿柱段的平均振幅 vs 红柱段的平均振幅。
  绿柱段振幅更小 = 卖压打不下去；更大 = 抛压重。
- `daily.ma5_slope_pct` / `ma60_slope_pct` = 均线斜率（%），比二进制的「金叉/死叉」更早给出强弱变化

工具会给出 `missing` —— 分钟线缺失时（例如长期停牌 / 1m 源无覆盖）这些标签会是空值，
**别把「拿不到」当成「中性」，也别当成有 alpha**。

## 六、仓位 / 入场 / 止损（无默认公式；止损三条/止盈必填/仓位档是硬口径）

入场 / 止损 / 目标位没有默认算法，**不要套固定盈亏比公式**（无标定依据）。
要给出入场/止损，请结合 `tech.dist_ma20_pct`（乖离大就别把止损设在贴身位置）和当日 `amplitude_pct`。

（2026-11-23 小资金复利对齐增补）止损三条硬口径：
1. **宽度 = min(amp_avg5, 8%)**：不小于日均振幅量级防噪声（基准 rank `amp_avg5`；振幅 8% 的票给 1.3% 止损 = 白送），但**止损不得越过 -8% 深亏线**——amp≥8% 的高波动票封顶 8%、靠仓位控风险（§6.2 实测：止损深过深亏线会反噬，8~10% 档深亏 7.53%→11.25%；§8.2 封顶验证：8~10% 档 2.38%、断崖 3.18%、全市场 0.36%，反噬消除）；
2. **落点在结构位外侧 + 缓冲**：前低/关键位下方，**避开当日已被穿过的价位**（穿过的价位是噪声区，不是支撑）；
3. **写明触发口径**：「盘中触价」或「收盘确认」；动量/接力仓默认盘中触价，低吸仓可用收盘确认。

（2026-11-26 承接位选股框架增补）**承接位锚止损**（与上方三条叠加，双锚取宽）：有 rank
`anchor.primary` 时，止损 = 承接位外侧一档——`stop = 锚位 − max(缓冲, min(amp_avg5, 8%))`，
缓冲 ≥ 1×噪声带（amp_avg5 量级）；主力建仓位失守 = 逻辑破，不是噪声。**锚位滚动 + 失守即
弃锚**：换庄后旧锚失守自动降级到下一锚、旧锚变压力；不得窄于噪声带、不得越过 -8% 深亏线。
买点 = 承接位挂单（`anchor.primary` ± 带宽，默认 ±1.5%），**承接证据在位才成交**
（`anchor_evidence.level`=confirmed 才成交、partial 只给试仓、none 不买）；「回踩」「突破」
保留为动作描述，不再是独立买法。规则全量见 SKILL.md「拉升定性与承接位」章。

止盈必填（复利靠兑现滚出来）：目标价 = 上方压力位（`res`/`hi20`/缺口上沿）或明确止盈条件（触板/冲高滞涨/破均价）；只有止损没有目标的票不进「买什么」。

仓位档（对齐设计方案 v2 集中持仓）：空仓 / 试仓（≤1成） / 标准（2~3成） / 重仓（3~5成，仅 A+：主线龙头/弱转强确认/放量突破齐备且无证据冲突）。**B 级机会不进表**——小仓试错赚了没意义、亏了照样磨损。

**龙头优先（2026-11-27 用户定则，进表与仓位统一向龙头倾斜）**：「谁是龙头」是**结论不是输入**（持续承接 + 埋伏在身 + 封单厚 + 生态在场 = 龙头；`board_rank=1`=板块龙头）。进表与仓位优先级向龙头倾斜：龙头（`board_rank=1` 且强板块/主线龙头、承接证据在位）优先给标准档（满足 A+ 可直接重仓）；非龙头（`board_rank≥2` 或弱板块领涨）只给试仓/条件单，**不给标准档**。与进表资格、承接位框架、买点形态叠加。

**进表前空间/强度评估（2026-11-27 用户改进，读满卡 `position_assess`）**：进「买什么」前按 `position_assess` 判定——`space_ok=false`（操作空间过小，默认 <5%，如 600604 现价3.94/卖4.08/跌3.82 仅3~4%空间、风险收益比不合算）→ 不得进标准/重仓，只给试仓或不推；`intensity_ok=false`（支撑/压力位强度弱，如支撑位无承接证据或间距过窄）→ 不得直接给突破买点，须先确认承接/强度。支撑/压力位强度按 `support_strength`/`resistance_strength`（强/中/弱）读，操作空间按 `operating_space_pct` 读。

## 七、情绪分数怎么算【定义】

`market_state()` 输出**两档独立**的情绪分（**描述性标签，非入场规则**）。两档常背离——
资金强不等于钱好赚——所以不合并成一个数，也不可互相替代。

**大盘档 `market_mood_score`（指数与资金强不强）**

```
base 50
资金净流入（亿元，分段，不设早饱和）:
  >=200 → +20   >=50 → +16   >=20 → +14   >=5 → +10   >=1 → +6   >0 → +2
  <=-200 → -20  <=-50 → -16  <=-20 → -14  <=-5 → -10  <=-1 → -6   <0 → -2
指数日内: 三大指数全在开盘价上方 +10；2/3 及以上在上方 +4；1/3 及以下在上方 -10
近 5 日资金连续 3 日净流出 → -8
```

**个股档 `stock_mood_score`（钱好不好赚）**

```
base 50
涨跌停比 zt/dt: >=3 → +15   >=2 → +8   <1.2 → -8   <0.8 → -15   （dt=0 时按涨停数给 +15/+6）
涨停活跃度: >=60 家 → +10   >=30 家 → +5   <10 家 → -10
炸板率: >=45% → -15   >=30% → -8   <15% → +6
```

两档统一刻度：`>=70 偏强 / >=55 中性偏强 / >=45 中性 / >=30 偏弱 / 否则 弱势`。

`_helpers._mood_regime` **只取大盘档**映射成 strong / neutral / weak，用于给预测模型传上下文 +
生成 `hints` 建议门槛；个股档供判断「敢不敢追高」，不参与该分桶（否则背离时互相抵消）。

## 十、做敏感性检查的建议

规则写在 md 里的一个实际好处是可以做对照实验。建议至少验证这几项：

1. `detect_patterns` 的 params 上下浮动 20%，看入选名单是否剧烈变化 —— 剧烈 = 结论依赖阈值而非事实
2. 把 L2 板块闸的 `MIN_FUND_PCT` / 成分数区间上下浮动，看入选板块是否剧烈变化 —— 剧烈 = 结论依赖阈值而非事实
3. `multitimeframe` 的 `minute_days` 调大，确认日内标签是否稳定

## 十一、选人层交付字段读法与经验格【提示】

> 来源：选人层回测验证任务 / OpenClaw assistant / 2026-11-07（增量增补，不覆盖上文）。
> 证据：5m 独立验证回测 2026-10-21~10-29（deep n=42 + 涨停参考 n=23，口径与偏差见
> `tmp/OPTIMIZATION_plan_5m_20261107.md`）——**样本小、5m 代理口径，软提示**，
> 结合当日证据用，禁止当硬规则（例外：11.5 的接力分层是交易规则，其深亏数字才是软提示）。

### 11.1 选人层痕迹字段（analyzed_rank / picked_detail / limit_up_ref）

- `kind`：`limit_up`=当日触板票（不进 deep 满卡，走 limit_up_ref 接力分层）；
  `jump`=跳变票（deep 主力）。deep 名单 = 非涨停票（涨停票不占 deep 满卡，但可经接力分层进「买什么」）。
- `t_first`：首次跳变/触板时刻——选人层排序第一依据（先跳先选）。除排序外
  它还是**时段结构**的载体（11.2）。
- `dup_n`：被多少个板块同时选中 = 多板块资金共识。注意：概念轨接入后才会 ≥2，
  看到 `dup_n=1` 不是「无共识」，是「无交叉证据」，别反向解读。
- `funnel.*`：漏斗复盘键（verdict/picked/excluded_*），只用于判断取数完整性
  与各层弃票原因，**不进结论正文**。
- `monitor`：回测经验的内部软提示；融入对应六维分析，不作为独立分析项或输出标签（判据见 `analysis-framework.md`「回测经验如何融入六维分析」）。

### 11.2 时段结构（t_first 分层，回测逐笔重切两次一致）

| 时段 | 回测表现 | 落笔 |
| --- | --- | --- |
| 09:30-10:00 | 追涨（chg≥0）净 −3.2 / T+3 胜 17%；收跌（chg<0）净 +6.9 / T+3 胜 100% | 早盘票先看当日涨跌：追涨降权、收跌洗盘加权 |
| 10:00-11:30 | 净收益全天最差（−3.5%） | 重点监控承接，**别把「盘中启动」当加分** |
| 13:00-13:30 | 全天最强（T+3 胜 61% / 净 +1.85） | 优先观察 |
| 13:30+ | 触板率 0% / 净 −2.2% | 重点监控次日承接 |

### 11.3 当日涨幅（chg_pct）分层——比「禁止按涨跌幅排序」再细一层

- **2~5% 温和追高格**：回测深亏 2/2 全落此格。大涨票（>5%）有触板止盈兜底，
  温和追高没有——「涨幅不大所以安全」是错觉。
- **<0 收跌格**（跳变当日收跌 = 洗盘/试盘）：回测 T+3 胜 100% / 净 +7.5%，
  反包确认可加权。
- \>5%：触板/止盈结构主导，按常规证据读，不因涨幅直接加减分。

### 11.4 前 5 日涨幅（ret5_pct）——超跌格降级为位置背景

- `ret5<0`（超跌格）：5m 小样本回测 T+3 胜 73.7% / 触板 31.6%，但全样本（§11.7）
  前5日下跌组仅均值 +0.33%、深亏 1.7%——**「排序优先/回调充分加分」降级为位置背景**；
  超跌 ≠ 回调充分，更 ≠ 洗盘，**无弱转强确认（支撑企稳+资金回流+量能）的超跌反抽 =
  接刀，不进「买什么」**（2026-11-23 小资金复利对齐）。

### 11.5 涨停参考票（limit_up_ref）的接力分层

（2026-11-23 小资金复利对齐改写：接力从「一刀切禁止」改为「分层 + 仓位护栏」——押中连板/龙头
是本打法的主战场（尾部捕捉），深亏率统计作护栏（仓位/触发/止损）不做排除。）

- **前置闸：只在板块强周期接力**（2026-11-24 用户实盘定则：**弱周期接力就是坑**）——强周期
  判据（用 `limit_up_ref`/`boards`/`theme.hit` 可观测，至少满足两条）：① 同板块/题材当日涨停
  ≥2~3 只且有梯队（高标+首板跟风）或连续两日有涨停；② 板块资金净占比居前且非单日脉冲；
  ③ 题材命中当日主线。弱周期特征（任一即一律不接，强确认也不给）：孤板、反复开板/炸板、
  板块资金退潮、断板断层、杂毛题材。
- **窄通道（证据前置）**：接力候选给条件单之前**必须先 `inspect_stock(code, deep=True)`** 取满卡
  证据（`seal` 封单结构/龙虎榜席位/近5·20日资金/位置透支），证据齐了才有资格写接力档；
  涨停票不进批量 deep、接力候选走定点深挖，每天 ≤2~3 只（成本封顶，2026-11-24 定）。
- **接力档（高赔率高风险）**：板块强周期内的 **主线龙头 + 强确认**（连板/厚封/题材核心 + 次日弱转强或
  放量突破确认）可给次日接力条件单——仓位上限（≤2 成）、宽止损（≥日均振幅，基准 rank `amp_avg5`）、失败即走；
  **快进快出**：价值在买入后 1~2 日的冲板/冲高溢价（日线全样本：接力 T+1 兑现负期望），
  **买入日不卖（T+1 当日买入卖不出）、次日冲高即走**，不留恋 T+3/T+5（2026-11-24 回测增补，
  T+1 出场口径 2026-11-25 修正）。
- 早盘板（t_first<10:00）接力深亏 **62.5%**；连板票接力深亏 **80%**（5m 小样本）→
  **无强确认默认不接**；有强确认也只给接力档条件单，不给现价单。
- 午后/尾盘板（≥13:00）接力为正收益（净 +1.3~+5.4）→ 谨慎可给接力档；封板厚实
  （`seal_tier` thick/vthick）优先。
- 无确认接力一律不写入「买什么」（接刀的镜像：接刀是抄弱、无确认接力是追强，都是无信号下注）。
