# 市场情绪判断标准

涨跌停家数仅反映市场分歧程度,不能直接判断强弱。市场强弱应以资金流向为主要依据。

| 指标 | 强 | 中 | 弱 |
|------|----|----|----|
| 大盘资金流向 | 净流入 | 平衡 | 净流出 |
| 涨跌停比 | 涨停>跌停 | 持平 | 跌停>涨停 |
| 炸板率 | <20% | 20-40% | >40% |

注意:涨停100只跌停50只只代表分歧大,或某板块吸金能力太强,不代表整体强势。

当资金流向显示市场弱势时，仍可筛选与分析，但结论应**附带弱势警告**、
收紧你的置信度与仓位建议、提高入选门槛（见 `analysis-framework.md` 维度 5）。
代码不会因情绪弱自动砍候选——取舍由你决定。

## 早盘预判（10:00 前）

涨停/炸板计数在早盘未成熟（封板还在变），预判以两个先行信号为准：

| 信号 | 偏强 | 中 | 偏弱 |
|------|------|----|------|
| 指数相对开盘（`index_intraday.vs_open_pct`） | 全部高于开盘价 | 分化 | 全部低于开盘价 |
| 大盘资金近5日方向（`fund_flow_days.direction_seq`） | 连续流入 | 反复 | 连续流出 |

两者同时偏弱 → `market.cautious=True`：**下跌时选股更谨慎**——提高门槛、
减少只数、只做有清晰支撑的票、早盘勿抢反弹。
