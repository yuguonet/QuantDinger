# 六维分析框架（market-screener 参考）

> 用途：给 LLM 做交叉验证时用。工具只输出事实，本文件告诉你**每个事实该怎么读**、
> **什么样的组合是伪信号**。字段口径以 `profile_candidates()` / `deep_analyze()`
> 返回的字段名为准。
>
> **分析周期 = 短中线**：主窗口 **T+1 / T+3 / T+5**（当前逻辑下这三档更好分析），
> **T+10 / T+20 可选延伸**，证据不够就写「不适用」，不强制凑满五档。
> `p_up` 只标定 T+1；其余周期靠证据推断并写明依据，后两档置信度默认更低。
>
> **实时对账字段（2026-10-14/15）**：`deep_analyze` 每行带 `rt{price,change_pct,
> previous_close,limit_up,limit_up_price,limit_down_price,limit_band,time}`、
> `stale_bar`、`rt_risks`。`limit_band`: `price|no_limit|missing`（新股无涨跌幅为
> `no_limit`，两价为 None 且 `limit_up=false`，详见 `limit-rules.md`）。
> 本地日线滞后时 `stale_bar=true`，**收盘 / 涨跌停已按 rt 修正**（`tech.bar_close`
> 保留原 bar 值）；MA / RSI / 20 日位等历史指标仍基于 bar。**可执行性一律看 rt**。
>
> **判定优先级**：支撑与强弱转化（维度 0）≫ 相对强弱 / 涨跌幅。详见
> `trading-logic.md` §0（**支撑 × 强弱矩阵、涨跌停带归一、三时段落法的真源**）。

## 维度 0：盘中涨跌 vs 支撑（先于涨跌幅的判定）

**原则：盘中是红是绿不决定安全；有没有支撑才决定安全。可怕的不是跌，而是「没有支撑位的一直下跌」。**

完整矩阵 / 涨跌停带换算 / 三时段落法 / 字段对齐表 → **`trading-logic.md` §0**（勿在此复制）。

本维度只强调与后续维度的衔接：

- **禁止**用 `change_pct` 单独排序或决定方向；-8% 不必然是坏事，+8% 不必然是好事
- `weak_to_strong` / `strong_to_weak` 是**日线几何标签**，不是盘中即时信号（见维度 2）
- `stale_bar=true` 时不要用 `close_pos_in_day` 等 bar 几何下盘中结论
- 连板高度会截断周期上限（见维度 4）

失败模式：把 -8% 一律当坏事、把 +8% 一律当好事；只看涨幅榜；在无支撑阴跌票里「抄底」；
拿日线 `weak_to_strong` 冒充「此刻盘中弱转强」。

## 维度 1：题材与主线

**看什么**：`theme.hit` / `theme.tags`、`bundle.themes`（当日主线）、`source`、`reason`

怎么读：

- `theme.hit=true` 说明这只票的理由命中当日主线，属于「顺势」；命中但已经是同题材第 3、4 只 → 边际递减
- `source` 是线索来源不是质量评价：**热点题材**偏主线，**条件搜索**偏结构/资金筛选
  （旧连板/龙回头源已删；若历史数据里仍见这些字样，只当来源标签，不当加分项）
- `reason` 为空不等于没有逻辑，可能只是该来源没标注 → 查 `inspect_stock().theme`

失败模式：把「同一题材的几只票」当成分散配置；题材已经连续三天强势却在第四天重仓追赶。

## 维度 2：量价结构

**看什么**：`tech.vol_ratio`、`close_pos_in_day`、`amplitude_pct`、`is_20d_high`、`rsi14`；
盘中补充 `rt.change_pct` / `m5.*`（`multitimeframe`）

怎么读：

- 放量突破（vol_ratio > 1.5 且 `is_20d_high`）是正面；放量但 `close_pos_in_day` 低 = 冲高回落，负面
- **`close_pos_in_day` 口径**：现价（或收盘价）在**当日已实现高低**中的位置，不是天然的「尾盘承接」
  - 尾盘 / 盘后读：≥85% 可称尾盘承接强；≤30% 抛压重
  - 盘中读：只是「此刻位置」，且早盘区间未定型，置信度低
  - `stale_bar=true`：high/low 可能仍是旧 bar，**禁止用该字段下结论**，改引 `rt` + 1m
- RSI > 75 叠加 20 日新高 = 短期过热，胜率不一定差但回撤大，**已持仓减仓 / 新开仓勿现价追**——
  此时「等回踩」是纪律（见下方买点节），与「信号明确时现价优先」不矛盾：过热 = 信号已兑现
- 缩量新高（`vol_ratio` < 1 但创新高）多为趋势票，弹性弱于放量突破
- **日线 `weak_to_strong` / `strong_to_weak`**：多日 MA5 穿越结构标签，服务 T+1/T+3 趋势判断；
  **不是**盘中即时强弱（盘中用 m5/1m，见 `trading-logic.md` §0.3）
- 周期映射：放量突破 + 尾盘强承接 → T+1/T+3 偏多；放量滞涨/冲高回落 → 最多 T+1 博弈，T+5 不看多

失败模式：只看涨幅排序；把「放量滞涨」当成强势；把「当日绿盘」当成结构破坏（先看维度 0 支撑）；
盘中把 `close_pos_in_day` 说成「尾盘承接」。

## 维度 3：资金

**看什么**：`flow.main_net_wan`、`flow.net_pct_of_amount`；深挖看 `inspect_stock(deep=True).fund_hist`；
个股**流通市值**用 `get_realtime_quote` 的 `float_mcap_yi` / `get_stock_info` 的流通股本（勿与大盘指数混读）

怎么读：

- 主力净额为正且占成交额比 > 1% 才算有效流入；小额净流入在活跃票上属于噪音
- 形态好 + 资金净流出 = 拉抬出货嫌疑，明确降权
- `fund_hist` 看的是连续性：单日大额流入不如连续 3 日温和流入可靠
- **控盘能力（2026-10-28 补）**：主力净流入相对**流通市值/流通股本**的占比，比绝对金额更能看出「庄家控盘」——
  同额资金在**流通市值小**的个股上控制力远强于**流通市值大**的个股。读法：
  - `main_net_wan` 绝对额 + `float_mcap_yi`（**个股流通市值**，亿）并看；或主力成交占比高 + 流通市值小 → 控盘/拉升成本低
  - 连续温和控盘（缩量也能稳住价）> 单日脉冲大额流入（可能是对倒）
  - 数据缺口：拿不到流通市值就写「流通市值未知，控盘判断降置信」，不要编占比
- **个股流通市值 → 趋势持续性（2026-10-28 补；此处指个股流通市值，不是大盘指数）**：
  - **个股流通市值越大，趋势性越强**：资金进出是连续过程，机构无法在高位一天抽身
    （那会变成砸盘），因此**变盘慢、回撤相对可控、趋势更可延续**
  - **流通市值小的个股易一日变脸**：拉升/出货都快，信号失效也快；做 T+1~T+3 要接受更高的路径噪音
  - 操作含义：流通市值大的票「回踩/趋势破位」可多给一点观察窗口；流通市值小的票一旦资金转弱要更快降级，
    不要拿流通市值大的节奏去套小票
  - 与控盘读法互补：流通市值小+主力占比高=拉升快；流通市值大+连续流入=趋势稳。目标是「趋势票跟得住」，
    不是盲目偏好大市值股
  - **禁止与「大盘指数」混读**：本条说的是个股 `float_mcap_yi`，与上证/深成指强弱无关

失败模式：把「净额为正」直接当买入依据，忽略占比与连续性；盘中资金数据是时点快照，尾盘会变；
只看主力绝对金额不看个股流通市值，把大市值股的「大额流入」误读成强控盘；
把「流通市值大=趋势稳」误说成「大盘指数强」；拿小市值一日变盘节奏写 T+5，或拿大市值慢节奏扛小票破位。

## 维度 4：位置与空间

**看什么**：`tech.dist_ma20_pct`、`pos_in_20d_pct`、`zt_streak` / `prev_zt_streak`、`ret_5d_pct` / `ret_20d_pct`、
**`tech.resistance` / `tech.sr_gap_pct`**（支撑–压力间距）

怎么读：

- 乖离过大（> 15%）时赔率变差：止损位被迫下移，同样止损金额对应更大仓位损失
- `pos_in_20d_pct` 在 40~85% 是性价比区间；> 95% 属于追高区
- **`ret_5d_pct` / `ret_20d_pct` 是历史涨幅，不是结构质量**：涨得多 ≠ 涨得好，禁止用它们排序
- 连板高度是双刃剑：`zt_streak` ≥ 3 说明辨识度高，但次日分歧概率显著上升；
  **并截断周期上限**——3 板以上默认只写到 T+1，除非有额外证据
- `prev_zt_streak` 高、当日收阴 = 首阴，弱于「反包」，需要额外证据
- **支撑是否清晰**是空间判断的前提：MA5/MA10/前平台可回踩企稳 → T+3/T+5 可看；
  悬空无支撑、只能靠情绪顶 → 最长只配 T+1，T+3 以上不看
- **支撑–压力间距（操作性，2026-10-28 补）**：`sr_gap_pct` =（压力 − 最近支撑）/ 支撑 × 100
  - **间距过窄（约 < 3%~5%）操作性弱**：上下都易被扫，止损与止盈贴在一起，T+1 赔率差 → **排序应下调**
  - 间距过宽（> 20%）空间大但支撑遥远，止损距离大 → 仓位要更小；若信号仍明确可现价入但收紧仓位，
    若信号一般则等回踩（Plan B，见买点节）
  - 理想：贴支撑入场 + 上方压力有足够空间（`resistance.dist_pct` 不至于贴脸）
  - 压力位口径：近 20 日高点（已越过则取更前峰）；更细的前高/缺口/平台压力用 kline 自证

失败模式：用「涨得多」当「涨得好」；连板越高越追加；忽略支撑直接按 20 日位置下注；
给 3 板以上票硬写 T+3/T+5 看多；**在支撑压力夹缝里按满仓节奏操作**。

## 维度 5：市场状态

**看什么**：`market.mood` / `mood_score` / `zt_count` / `dt_count` / `broken_rate`、`mood_regime`

怎么读：

- `weak`：提高门槛、减少只数、优先低位启动票，避开高位连板接力
- `strong`：可放宽 p_up 门槛，允许题材内多配一只
- 炸板率高说明接力资金不足，此时「封板」反而是风险信号而不是买点
- `hints.p_up_floor_suggest` 是按上面规则算的经验值，可以偏离但要写理由

失败模式：无视情绪分桶，在炸板率 40% 的市场里推荐接力板。

## 维度 6：可执行性

**看什么**：`hard`、`rt.limit_up` / `rt.limit_up_price` / `rt.limit_down_price` / `rt.price`、`stale_bar`、`rt_risks`

`hard` 全集（代码 `hard_exclusions`）：

- ST / 退市风险、换手仅 X%（<2）、**低价 <2 元 / 高价 >300 元**、涨停封板-当日买不进、停牌

怎么读：

- **收盘价与涨跌停以 `rt` 为准**；`stale_bar=true` 说明本地日线滞后（`tech.bar_close`
  是旧 bar），此时 `tech` 里的收盘/涨跌停已被 rt 覆盖，历史指标仍可用
- `rt.limit_up=true`（或 `rt_risks` 含「涨停封板-当日买不进」）：当日买不进，
  不能作为当日买入标的，但可作为次日竞价候选
- `stale_bar=true` 时不要用 bar 口径的涨跌幅/连板数/`close_pos_in_day` 写结论，统一改引 `rt`
- 换手 < 2% 说明流动性不足，短线难进出（默认不剔除，你决定）
- 价格 < 2 元或 > 300 元的票，波动率与流动性结构不同，**不适用同一套短线/支撑假设**（维度 0 同步降置信）
- 距涨跌停价深度（`rt.limit_up_price` / `rt.limit_down_price`）比裸涨跌幅更有决策意义；
  近跌停/跌停封死 = 无流动性，**不是「有支撑的下跌」**（见 `trading-logic.md` §0.1）
- **ST / 新股以 rt 价为准**：ST 的 quote 涨跌停可能按板规则（10%/20%）而非公式 5%；
  `limit_band=no_limit`（新股）禁止用 `get_limit_pct` 回退（详见 `limit-rules.md`）

失败模式：推荐表里有「买不进」的票，方案等于不可执行；用滞后 bar 的收盘价
和实时涨跌停混写（同一行两个口径）；对 <2 / >300 元票硬套同一模板。

## 周期怎么落笔（主窗口 T+1/+3/+5，T+10/+20 可选）

**当前逻辑下 T+1/+3/+5 明显比 T+10/+20 容易分析准**：题材情绪、支撑、量价、资金都是短窗信号；

### 时段博弈差异（2026-10-28 补）

不同时段「在博什么」不同，周期落笔的重心也不同：

| 时段 | 在博什么 | 周期重心 | 纪律 |
| --- | --- | --- | --- |
| **早盘/盘中** | **今日行情**（当日情绪、板块强弱、分时承接） | 以 T+1 为主；早盘置信度低 | 10:00 前结论降置信；别把早盘冲高写成 T+5 逻辑 |
| **尾盘** | **隔夜行情** | **主考虑 T+1、T+3** | 看今日是否守住、隔夜溢价是否透支；`close_pos_in_day` 此时才有「尾盘承接」含义 |
| **盘后** | **T+1 买入后的持有路径** | 因 T+1 才能成交，**必须看得更远**：T+5 要纳入 | 写次日买点时同时写清 T+5 不成立的条件；勿写「目前涨跌」 |

### T+1 风险收益比（前瞻必写，2026-10-28 补）

A 股 **T+1 卖出**，至少要回答：**若明天走坏，我最多亏多少；若走好，T+1~T+5 空间有多少。**

- **风险端**：止损距离（拟成交价 −「跌破 X」）/ 拟成交价；**一律按拟成交的现价算**（见下方买点节）
- **收益端**：到上方压力/前高的空间（`resistance.dist_pct`、平台空间）；有主线 + 资金才给高空间
- **收益比**：目标空间 : 止损距离 尽量 **≥ 1.5~2:1** 才值得进「买什么」；达不到就写观察或降仓位
- **禁止**：无止损价硬推；止损贴在无意义位置（乖离大却设贴身止损）；把 `p_up` 当收益比（它只是 T+1 上涨概率）

### 买点：现价优先于等回踩（2026-10-28）

**现价买入 > 等回踩买入。** 回踩只是备选计划，**不一定给成交**；风险收益比也应按**现价**直接算。

| 情形 | 买点怎么写 | 为什么 |
| --- | --- | --- |
| 信号明确：放量突破 / 上升通道打开 / 弱转强+资金确认，回踩概率小 | **「现价 X」优先** | 通道打开时再等回踩常踏空；现价算止损/空间最直接，此时赔率往往最好 |
| 现价已 20 日高位 / 乖离偏大 / 无明确启动信号 | 「回踩 X」为主，或写观察 | 追高赔率差，等回踩是纪律不是目标 |
| 两者皆可 | 主写「现价 X」，括号补「若冲高回落再回踩 Y」 | 不让回踩条件卡死上车 |

- **回踩是 Plan B，不是入场前提**：只写回踩不写现价 = 可能永远买不进
- **现价买 ≠ 追高**：追高是无信号/无支撑/连板接力；现价买要求**信号 + 支撑仍在 + 资金/主线**
- 风险收益比、仓位一律以**拟成交的现价**为基准，不要用「若回踩到 Y」的假想价美化赔率
越往后越吃波段/基本面故事，不确定性越高。因此**不强制写满五档**。

| 周期 | 定位 | 核心问题 | 偏多证据 | 偏空证据（选股=回避/不入选；问持仓才写兑现） |
| --- | --- | --- | --- | --- |
| T+1 | **核心** | 明天谁来接 | 题材主线、弱转强、情绪不拖后腿、非买不进 | 强转弱、炸板率高、高开溢价透支 |
| T+3 | **核心** | 分歧能否转一致 | 回踩支撑缩量、资金未撤、量能连续 | 无支撑阴跌、资金连续流出 |
| T+5 | **核心** | 短线趋势是否成立 | MA5 向上、平台不破、题材仍在风口 | 反弹无量、热点切换 |
| T+10 | 可选 | 波段结构 | 有效突破前高/平台、缩量回踩不破 | 假突破后回落、乖离过大修复 |
| T+20 | 可选 | 短中线空间 | MA20 向上、20 日位置不极端、有基本面锚（仅作辅证） | 追高区、情绪退潮、无中线故事 |

纪律：

- **至少给 T+1 / T+3 / T+5**；不允许只写「看多」却不区分周期节奏
- **T+10 / T+20 不强制**：证据够才写，且置信度默认低一档；不够就写「不适用」——这比编一段更合格
- `p_up` **只**对应 T+1；禁止写成「T+5 胜率 68%」这类无标定数字（方向推断 ≠ 概率）
- 弱转强 + 有支撑：可写到 T+3 甚至 T+5；**`zt_streak`≥3 默认只写 T+1**
- 脉冲无支撑 / 强转弱无支撑：T+1 不当买点，直接回避（选股链路不写「兑现」）
- 与中长线技能（基本面尽调、月度持仓）边界：本技能不做那套，超出 T+20 的窗口就写「不适用」

## 证据冲突时的处理顺序

1. 先查是不是**数据缺口**：`missing` 非空 → 降低置信度，不要补脑
2. **支撑/强弱转化（维度 0）优先于涨跌幅与相对强弱**（相对强弱判断见 `trading-logic.md` §1，冲突时仍以 §0 为准）
3. 模型和事实冲突（p_up 高但资金流出 / 位置过高）→ 以「可执行性 + 位置」优先，模型分只作排序参考
4. 两个维度都支持但市场情绪反向 → 减仓到「可承受错误」的规模，而不是放弃或全仓
5. 证据不足时，宁可输出「今天没有符合条件的标的」，也不要凑数

## 一句话纪律

每只推荐都要能回答：**它今天为什么会被资金选中（支撑在哪、是弱转强还是转弱），明天谁会接我的货，T+3/T+5 打算怎么看（持有观可写兑现，选股写不入选/回避）。**
答不出「谁接货」的，就是投机不是选股；答不出支撑的，不要因为它「跌了」或「涨了」就下结论。
