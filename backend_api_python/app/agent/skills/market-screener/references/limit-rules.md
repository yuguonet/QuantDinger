## 口径来源

- 上表与代码 `common.get_limit_pct()` 同源（几何定义【定义】）。
- 个股是否封板以 **`rt.limit_up`**（实时价 vs 涨停价）为准；`stale_bar=true` 时
  `tech.limit_up` 已按 rt 修正。封板 = **当日买不进**，在 `rt_risks` 里标
  「涨停封板-当日买不进」——**是否排除由你决定**，代码不自动淘汰。

## 过滤规则在哪

**本文件不再存放过滤/排序/淘汰规则。** 旧文的「涨停自动排除 / 换手<2% 淘汰 /
Phase 2 低分淘汰 / 按评分排序」是 2026-09-29 前写死在代码里的口径，v7 起已全部
删除（代码不做取舍）。现行取舍规则见 `strategy-rules.md` §三（默认不过滤、
不排序、不截断；`hard` 只是客观障碍，由你处置）。
