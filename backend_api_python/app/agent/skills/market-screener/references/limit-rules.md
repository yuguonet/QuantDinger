| 板块 | 涨跌停幅度 | 代码特征 |
|------|-----------|----------|
| 主板/中小板 | ±10% | 60xxxx / 00xxxx |
| ST / 风险警示 | **跟随所在板**（主板 ±10%、创业/科创 ±20%），2026-10-15 实测 | 名称含 ST |

## 口径来源（2026-10-15 实测已回写 `common.get_limit_pct`）

- `get_limit_pct()`：**按板块定幅度，ST 不再单独 ±5%**；N/C 新股返回 `0.0`（无涨跌幅）。
  仅作 rt 缺失时的近似，**有 `rt.limit_*_price` 时以 rt 为准**。
- 个股是否封板以 **`rt.limit_up`**（现价 vs 涨停价）为准；`stale_bar=true` 时
  `tech.limit_up` 已按 rt 修正。封板 = **当日买不进**，在 `rt_risks` 里标
  「涨停封板-当日买不进」——**是否排除由你决定**，代码不自动淘汰。

### 实测样本（2026-10-15）

| 类型 | 样本 | quote 涨跌停价 | 与公式 |
| --- | --- | --- | --- |
| 普通主板/创业/科创 | 浦发、平银、宁德、中芯等 15 只 | ±10%/±20% | 一致 |
| 主板 ST | ST惠程、\*ST春天、\*ST皇庭… | **±10%**（\*ST皇庭当日 +6.13%） | 现行 `get_limit_pct` 一致 |
| 创业/科创 ST | ST嘉必优、\*ST香雪、ST合纵 | **±20%** | 一致 |
| 退市/极端低价 \*ST | \*ST天成、\*ST成城 | `-1/-1` 哨兵 | 无有效价 |
| **新股** | **N联亚(301569)、C粤芯** | `-1/-1` = 无涨跌幅 | `get_limit_pct`→0 |

### `rt.limit_band` 字段

`apply_rt_overlay` 会把 quote 价解析后写入：

| 取值 | 含义 | `limit_up_price` / `limit_down_price` | `limit_up` |
| --- | --- | --- | --- |
| `price` | 有有效涨跌停价 | >0 的价格 | 现价是否触涨停 |
| `no_limit` | quote 明确哨兵 ≤0（新股无限制等） | `None` | **False**（禁止回退公式） |
| `missing` | 源无此字段 | `None` | 才允许 `get_limit_pct` 近似 |

## 过滤规则在哪

**本文件不再存放过滤/排序/淘汰规则。** 旧文的「涨停自动排除 / 换手<2% 淘汰 /
Phase 2 低分淘汰 / 按评分排序」是 2026-09-29 前写死在代码里的口径，v7 起已全部
删除（代码不做取舍）。现行取舍规则见 `strategy-rules.md` §三（默认不过滤、
不排序、不截断；`hard` 只是客观障碍，由你处置）。
