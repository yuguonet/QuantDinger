# 核心交易逻辑

以下逻辑贯穿选股和评分全过程。分析周期为**短中线**：主看 **T+1 / T+3 / T+5**，T+10 / T+20 可选（证据不够不硬写）。

> **判定优先级**：§0 支撑与强弱转化 ≫ §1 相对强弱。两者冲突时以 §0 为准。

## 0. 盘中涨跌不决定安全，支撑才决定安全（真源在此）

**可怕的是「没有支撑位的一直下跌」，不是「跌了」本身。**

### 0.1 先按涨跌停带归一，再看红绿

裸的 -8% / +8% 跨板块含义完全不同，**先换算成「距涨跌停带的位置」**：

| 板块 | 涨跌停幅度 | -8% 的含义 | +8% 的含义 |
| --- | --- | --- | --- |
| 主板/中小板 | ±10% | 逼近跌停，极弱或利空 | 逼近涨停，看是否封死 |
| 创业板 / 科创板 | ±20% | 区间中下段，可观察 | 区间中上段，可观察 |
| ST | 名义 ±5%；**实测 quote/实盘多按所在板 ±10%/±20%** | 以 `rt.limit_*_price` 为准 | 同左 |
| 北交所 | ±30% | 中段 | 中段 |
| **新股无涨跌幅日** | **无限制**（`rt.limit_band=no_limit`） | 裸涨跌幅无「带」可归一 | 别按涨停深度读 |

- 例子一律理解为「主板口径」；创业板请把阈值放到 ±15~20% 量级再套同一结构
- 价格 <2 元或 >300 元：波动与流动性结构不同，**同一套支撑假设降置信**，不要硬套
- 封板（触涨/跌停价，用 `rt.limit_up_price` / `rt.limit_down_price` 对照现价）：
  跌停封死 = 无流动性，不是「有支撑的下跌」；涨停封死 = 当日买不进
- **带位与封板一律信 rt，不信公式**（ST/新股见 `limit-rules.md` 实测表）

### 0.2 支撑 × 强弱转化矩阵

| | **有支撑**（回踩 MA5/MA10/前平台/涨停启动价附近企稳，低点不再下移） | **无支撑**（阴跌、低点续降、无人接） |
| --- | --- | --- |
| **弱转强** | ✅ **更安全**：短中线更好的观察/介入点；主看 T+1/T+3，结构不坏可到 T+5（**若 `zt_streak`≥3 则只写 T+1**） | ⚠️ 反弹无锚，只配 T+1 博弈，T+3 以上不看 |
| **转分歧 / 强转弱** | ⚠️ 下方有承接则不必一刀切：选股 T+1 慎、T+3 写「等企稳（暂不入选）」；用户问持仓才写兑现 | ❌ **更危险**：不入选；已持仓写兑现 |

举例（主板，先换算带位）：

- **更安全**：某股目前 **-8%**（近跌停区），但明显是**弱转强**且**有支撑位**——回踩关键位后低点不再下移、能收复分时均线
- **更危险**：另一股 **+8%**（近涨停区），但已开始**转分歧 / 转弱**——冲高回落、放量滞涨、跌破分时均线收不回

结论：排序**不要按涨跌幅**，按「支撑是否有效 + 弱转强/强转弱」重排。

### 0.3 证据怎么对齐（字段 ≠ 盘口语，别混用）

| 你要判断的 | 该用什么 | **不要**怎么用 |
| --- | --- | --- |
| 多日结构是否弱转强 | `multitimeframe.weak_to_strong` / `strong_to_weak`（**日线** MA5 计数几何标签） | 不要把它当成「此刻盘中弱转强」 |
| 盘中/分时强弱 | `rt.change_pct`、`m5.above_ma5` / `macd_strength` / `volume_pattern`；复杂形态自己拉 1m 看 | 「分时均线 / 低点不移」**无现成字段**，需自算，算不出就写数据缺口 |
| 现价在当日的位置 | `close_pos_in_day`：仅完整 bar 或 rt 对账后可靠；含义是「现价在已实现高低中的位置」 | `stale_bar=true` 时**禁止**用它下结论；勿在盘中读成「尾盘承接」 |
| 支撑位在哪 | `tech.ma5/ma10/ma20`、`dist_ma20_pct`、`detect_patterns` 均线支撑回踩、前平台/涨停启动价（需 kline 自证） | 勿把 `weak_to_strong` 标签本身当成支撑位 |

### 0.4 同一原则，三时段落法不同

| 时段 | 你要回答的 | 要点 |
| --- | --- | --- |
| **盘中** (09:30-14:29) | 「此刻支撑还在吗？弱转强还在成立吗？能不能上车？」 | 用 rt + 1m/5m；早盘（~10:00）结论置信度低于尾盘（一可被砸、一接近定格） |
| **尾盘** (14:30-15:00) | 「今天守住了吗？收盘位/封板/量能是否定格？」 | `close_pos_in_day` 此时才有「尾盘承接」含义；封板看 `rt.limit_up` |
| **盘后** (15:00+) | 「今日是否守住支撑 / 尾盘是否修复？次日竞价怎么办？」 | **不要写「目前 -8%」**；写「今日曾回踩 X 企稳」并落到次日计划 |

## 1. 个股强弱的判断

大盘强或板块强、个股弱 → 真弱,回避。
大盘弱或板块弱、个股强 → 真强,重点关注。

**例外（以 §0 为准）**：弱市中的 +8% 若已转分歧/强转弱 → 不算「真强」，按 §0 危险象处理。

## 2. 弱转强(高赔率观察/介入点)

- 价格在日均线附近震荡一段时间后,转为站稳日均线之上
- 即使某一时间点跌破日均线,也能很快收复
- **确认后优先「现价 X」直接买**（见 `analysis-framework.md` 买点节：回踩不一定给成交）；
  尚未确认、仅「看起来要回踩」时才把回踩写成 Plan B
- MACD 日线绿柱阶段,价格仍能稳定在日均线上方
- 此阶段股票尚未大幅拉升,盈亏比最优
- **盘中绿盘不构成否决**：只要弱转强结构与支撑还在,当日下跌是观察买点而非风险信号
- 周期含义：弱转强 + 有支撑 → 至少看到 T+3；结构不坏可顺延到 T+5（T+10/T+20 视证据可选）
- **连板高度会截断周期**：`zt_streak` ≥ 3 时默认只写到 T+1，除非有额外证据证明分歧可控

> 标签 `weak_to_strong` 是日线几何定义（近 5 根站上 MA5 计数），与本节经典描述相近但阈值不同；以 `strategy-rules.md` §五为准。

## 3. 强转弱(最佳卖点)

- 价格从日均线上方跌破后无法收复
- 此阶段股票尚未大幅跳水
- **盘中红盘不构成加分**：+8% 若已强转弱/转分歧,可能比 -8% 弱转强有支撑更危险
- 周期含义见 §0.2 矩阵：无支撑 → 不入选（T+1 也不当买点）；有承接 → 选股写「T+1 慎、T+3 等企稳（暂不入选）」
- 本技能是**选股**链路：「兑现」仅当用户问持仓时才写，买入结论一律用「回避 / 不入选」

## 4. 一鼓作气再而衰三而竭

- 连续 3 次拉升,一次比一次低 → 上升无力
- 连续 3 次下跌,一次比一次低 → 下跌动能耗尽
- 用于判断盘中分时走势的转折点

## 5. 放量的意义

- 买卖都会放量,放量代表热度
- 连续放量代表个股热度在持续
- 缩量上涨 → 拉升(抛压轻,主力控盘)
- 放量下跌 → 抛盘(真实抛压)
- **个股流通市值与趋势（2026-10-28；是流通市值，不是大盘指数）**：个股流通市值越大趋势性越强——
  机构难以一天从高位抽资（那会砸盘），变盘比小流通市值票慢；流通市值小的拉升/出货都快，信号失效也快。
  持有与降级节奏按**个股流通市值**区分，勿与指数强弱混读。

## 6. MACD 红绿柱与价格波动(5m/15m 级别)

早盘 9:30-10:00 期间,5 分钟 MACD 能看出承压和拉升强度:

- **绿柱**:对比同期价格波动范围,判断卖压强度
- **红柱**:对比同期价格波动范围,判断拉升强度
- **强势判断**:红绿柱高度相近 + 绿柱价格波动 < 红柱价格波动 → 强势(绿柱时卖压打不下去)
- **强势股特征**:绿柱本身就小,说明抛压轻
- **例外**:大盘波动很大时此规则不适用

**日内 MACD 变化 = 上涨/下跌压力参考（2026-10-28 补）**

- 红柱**逐级放大** + 价格抬升 → 上涨压力小（买盘持续）
- 红柱**逐级缩短** + 价格仍冲 → 上涨压力在积（拉升衰竭，防冲高回落）
- 绿柱**逐级放大** + 价格走低 → 下跌压力大，别接
- 绿柱**逐级缩短** + 价格企稳 → 下跌压力衰减，配合支撑看弱转强
- `multitimeframe().m5.macd_strength`（sell_pressure_low/high）是几何速记，
  **方向仍以价格与支撑为准**；大盘异常波动时整体降置信
- 口径提醒：旧「5m MACD 强弱 ±8」打分**从未真正生效**（分钟源问题），不要当历史胜率用

## 7. 换手率

- 换手率 < 2% 的个股活跃度不够，通常持续性差（尤其消息催化的涨停）
- **默认不剔除**：换手不足在画像的 `hard` 里标记，是否排除由你结合当日证据决定
  （要硬过滤传 `min_turnover=`，见 `strategy-rules.md` §三）
- 盘中换手率需预估全天值(当前成交量 / 近5日平均全天成交量)

## 8. 盘中数据的局限性

- 换手率只能预估全天换手率
- 成交量呈锅底形态(早盘和尾盘大,中间小)
- 部分参数需对比前一天数据才有意义
- 早盘得出的「弱转强」置信度低于尾盘（详见 §0.4）
