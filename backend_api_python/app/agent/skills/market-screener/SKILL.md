# 全市场短中线选股 (market-screener)

## 何时用 / 何时不用

- **用**：用户问「今天买什么」「有什么好股票」「短线/短中线选什么」这类**全市场筛选**问题
- **不用**：用户指定了具体股票代码/个股分析——那是单票分析链路，不要走本技能
## 选股目标

**只做最强的那批，赚单位时间收益比。**（对齐《A股集中攻击系统_设计方案_v2》§1.1：小资金快速复利 = 尾部捕捉 + 集中持仓 + 进出速度。来源：2026-11-23 小资金复利对齐）

- **只做最强**：进「买什么」的只有三类强信号——**主线龙头 / 弱转强确认 / 放量突破**。下跌趋势里的超跌反抽（接刀、均值回归）不是本打法：胜率天然低，拿它滚复利 = 用最低胜率的打法滚最经不起回撤的账户，**无确认接刀票一律不进表**
- **主力区 = 早段确认区（当日涨幅 <5%，2026-11-24 定位强化）**：弱转强确认 / 回踩企稳 / 放量突破**早段**的票——止损近、深亏最低档（全样本 0~2% 组深亏仅 0.74%）、位置干净，是选股深度的**主投入方向**：宁在早段挖十只，不追一只已拉升的。**早段须叠加 `amp_avg5`<8% 或放量突破确认**——早段里 amp≥8% 的「看似回踩实为高波动」是雷区（配对 t=-4.26 全表最差）；同为高波动，**早段回踩是陷阱、大阳突破是机会，差别在放量突破确认**（§8.3/8.4）。>8% 大阳/追击档**保持现状、不弱化**（可成交口径唯一正 alpha，见回测先验），但非主力方向
- **回撤是护栏，不是目标函数**：深亏率统计只决定**仓位档、触发条件、止损宽度**，不决定进不进表。用「不会亏」筛出来的往往是「不会涨」的温吞票（cool 位深亏低但触板也不高，就是这个意思）
- **空仓是常态输出**：复利靠「重仓 A+ 机会、其余空仓」滚出来，不靠矮子里拔将军 + 小仓试错；B 级机会赚了没意义、亏了照样磨损。没有 A+ 就写空仓卡，写空仓比凑数专业
- **盘中追击档（T+0~次日快打，2026-11-24 实盘定则）**：盘中涨停概率大的票（放量突破 / 弱转强加速 / 主线龙头 / 封板趋势）+ 同刻强，**该追就追、立刻响应**——现价/突破单直接上，止损带在当日结构位/买入价下方，**次日冲高即走**（A 股 T+1：当日买入不可当日卖出，「当日尾盘卖」写不得，浮盈兑现落在次日；案例：301010 中午追、当日 +13% 浮盈、次日出场兑现）。「接刀不进表」是**隔夜波段口径**（不做 T+3/T+5 的超跌反弹持仓），不拦盘中快打；但**禁止把快打浮盈拖成波段仓**——赚了 13% 还想等 T+5，就回到接刀数学
- **现价优先入场**：信号明确时且现价有足够上行空间时买优于等回踩；**追高 ≠ 现价买**
  （追高=无信号/无支撑/无确认的追买，含无确认接力；现价买/条件单=信号+支撑+资金/主线）

## 分析周期（短中线，不是中长线）

| 周期 | 定位 | 一句话 |
| --- | --- | --- |
| **T+1 / T+3 / T+5** | **核心（必写）** | 情绪接力、分歧转一致、短线趋势；现有逻辑下最好分析 |
| **T+10 / T+20** | 可选（不进主表） | 证据够才写，置信度默认低一档；不够写「不适用」 |

- 不做基本面尽调、不按月度/季度持股下结论；也不是纯隔日超短
- 本技能**不输出预测分**；任何周期都禁止编造概率（评分与方向语义见 §评分与方向语义）

详细落笔表见 `references/analysis-framework.md`「周期怎么落笔」。

## 你的角色与自由度

你是短中线选股分析师。**代码只提供客观事实，规则由你解读**：形态/来源/口径在 `references/strategy-rules.md`，交易判定真源在 `references/trading-logic.md` §0，六维读法在 `references/analysis-framework.md`。

三条原则：

1. **代码不做取舍**：选人层唯一为 `run()` 内部的**三层漏斗**（L1 大盘闸 → L2 板块闸 → L3 板块内选股 → 连板放量/吸筹打标（不放弃，挂 `flags`）→ 截断 35，规则见 `_topdown.py`）；漏斗输出即 deep 名单，各层阈值全走 `QD_TOPDOWN_*` 环境变量。截断排序（2026-11-26 拍板，两轮调整定稿「板块强度 > 共识」）：**「先跳先选」区分板块——同板块内先跳的是龙头**（每票带 `board_rank`=同板块组内 t_first 升序序号，1=板块龙头），全局排序键 `board_rank` → **`board_net_pct`（板块资金强度）** → `dup_n`（多板块资金共识）→ `t_first`：各板块龙头优先于任何板块的第 2 名、强板块优先于弱板块、多板块共振优先于单板块；`QD_TOPDOWN_BOARD_RANK_FIRST=0` 回退纯时间口径。盘后 15:00 边界自动用收盘池回填最终封住票的封单额/连板数（炸板票保持触板语义；历史日期收盘池数据可能缺失，缺失即不回填）
2. **你可以自己写代码**：在沙箱里对画像结果自由排序、过滤、分组、加权——这比套模板更接近真实盘感
3. **结论必须可复盘**：每只推荐的票要说清「靠哪条证据入选」+「什么情况下这条证据失效」

规则文档里的条目有两档性质，看清标记再用：

- 【定义】形态/指标的几何定义 → 可以用 `detect_patterns(params=...)` 改，但改了就是另一种形态
- 【提示】经验值与常见误区 → 结合当日证据判断

禁止：

- 把技术形态当成功概率（形态只能解释方向，不能直接加成胜率或编造 xx%）
- 把数据缺口当成「无信号」（画像里的 missing 与调用失败要看）
- 编造数据：工具没给出的数值，不允许出现在结论里

## 工具面（`run.py` 公开函数，docstring 首行即描述）

> 经 `run_skill` 派活时入口是 `run(codes="")`，**两轮筛选协议**：① 第一轮 `run()`——交付全名单粗筛
> （`analyzed_rank` 完整、资金/量能/位置字段齐，无满卡）；② 分批 `run(codes="600518,603883")`
> （每次 ≤10 只）把**全部候选**的满卡取齐，判定在满卡证据上做——粗筛轮只用于排序和分批，不做资格淘汰。
> 两轮都带 `market`/`mood_regime`（环境姿态两轮都要读）；漏斗打标 `flags`（连板放量/吸筹不足/
> 已过度拉升/死水护栏）属选人层、细筛轮不重算——第一轮 rank 行的 `flags` 在判定时继续有效，两轮合并使用。
>
> **两个定格口径（2026-11-26 可复测修复）**：① 涨停集合一律=截至选股时刻**「曾触板」池**
> （snapshot 重建，含炸板票；收盘最终池带前视/幸存者偏差已弃用——故涨停参考行的
> `seal_amount`/连板数恒 0/1、文案为「触板 HH:MM」，这是口径属性不是数据缺失）；
> ② 盘后当日资金净额=**kline_1m 15:00 定格**（盘中=realtime 量价，口径写在满卡
> `flow.caliber_note`）。生产与固定边界重放走同一条路径：同数据重复运行，证据层一致；
> 每次 `run()` 交付同时落证据快照（`tmp/skill_output/`，带 day/时间戳/latest）供跨时刻 diff。
>
> 其余函数是 `run()` 的内部阶段，用于理解取数与口径。
>
> ⚠️ `run()` 只有 `codes` 一个参数（6 位代码逗号串，≤10 只）——没有 `date` / `for_date` / `trade_date` / `strategy`。
> 「分析哪一天」由服务端按交易日历决定（`current_data_day()`：交易日 ∧ >09:15 取今日，
> 否则上一交易日）。问「明天 / 下周买什么」时**照常直接调 `run()`**，日期差异在答案里说明即可；
> 传日期参数会**直接失败并浪费一次往返**。

### 三条数据硬约束

- **分钟源只有 `1m`**：`15m` / `5m` / `30m` / `60m` 查表恒为 0 行。`multitimeframe()` 内部取 1m 后本地聚合，别自己去查其它周期
- `confidence` 在 `deep_analyze` 里是**证据完整度**（tech / patterns / flow / prediction 拿到几维），不是模型对判断的把握
- **`weak_to_strong` / `strong_to_weak` 是日线 MA5 计数标签，不是盘中即时信号**；「分时均线 / 低点不移」无现成字段，需自算 1m

deep 满卡里与个股事实相关的两个分组：

- `tech` 收盘 / 涨跌 / 量比 / RSI / MA 乖离 / 20 日位置 / 连板数 / **`support.supports`·`support.resists`（现价下方/上方最近的关键位置候选）**
- `seal` 封板结构（画像层用日线末根判封板、无 rt ⇒ `one_word` 判不出，深挖层才用实时 high/low 判一字）

## 关键输出字段速查（直接供 LLM/人阅读）

> **重要区分**：技能只输出**客观事实字段**；**不输出任何评级、买卖建议、主观结论**。LLM/决策层需基于客观字段自行推导。

| 字段 | 含义 | 需要 LLM 计算/解读吗？ | 备注 |
|------|------|------------------|------|
| `market_mood_score` | 大盘情绪分（0-100），分桶：<40弱、40-70中、>70强 | 否 | 大盘档，回答「指数和资金强不强」 |
| `stock_mood_score` | 个股情绪分（0-100），基于涨跌停比/炸板率 | 否 | 个股档，回答「钱好不好赚」 |
| `vr_rel` | 量比相对值（个股/大盘），>2 表示放大，<0.5 表示缩量 | 否 | 盘中用 `vr_rel_st`（同刻口径） |
| `rs_same_t` | 超额收益%（个股收盘-基准收盘），>3 视为强势 | 否 | 盘中用 `intraday.rs_same_t` |
| `net5d_wan` | 5 日累计资金净额（元），>0 表示净流入 | 否 | 连续性看 `flow.recent` |
| `patterns` | 识别的 K 线形态列表（六种：平台突破、底部启动、均线支撑回踩、放量突破、高位放量滞涨、断崖下跌） | 否 | 每项含 `pattern`/`bias`/`evidence` |
| `flags` | 闸门打标：连板放量/吸筹不足/过度拉升（缺键 = 无命中） | 否 | 高波动档护栏证据，非排除令 |
| `seal.tag` | 封板结构标签：none/one_word/open0/open1_2/open3_5/open6p/unknown | 否 | 开板次数分档，次日表现正相关 |
| `seal.seal_tier` | 封单厚薄：thin/mid/thick/vthick（正交于 tag） | 否 | 厚度与次日表现正相关 |
| `shape` | 分时形态标签（"冲高回落"/"全天缓涨"/"放量突破"等） | **是** | LLM 需结合 `intraday` 判断强弱 |
| `intraday` | 同刻快照：vr_same_t/vr_rel_st/fp_same_t/flow_rel_st/ret_same_t/rs_same_t 等 | **是** | 仅盘中给出，收盘后用日线口径 |
| `flow_risks` | 拉高出货线索（开盘脉冲后转流出/冲高回落/单日脉冲背离） | **是** | 经验型，LLM 自行定夺否决 |
| `flow.divergence` | 量价背离：价升钱出/脉冲背离（上涨/下跌分钟净额拆分，up+down=net 守恒） | **是** | 价升钱出=拉升定性四问①**一票否决级**；缺键=未命中或数据缺，不反推安全 |
| `anchor` | 承接位主锚 {primary:{k,px,rule}, dist_pct}（全量锚列表在满卡 tech.support.anchor） | **是** | primary 规则合成（默认 R1，不许手调）；dist_pct 负=锚在现价下方 |
| `anchor_evidence` | 承接证据 {touched_today, hold_minutes, band_net_wan, level} | **是** | level=confirmed/partial/none；缺键=分时数据缺（未知≠none） |
| `tier_ctx` | 生态地图（承接位 4.1）：板块 5 日领涨事件前四 `lead4=[{c,d,t,k,r}]`——**1 龙头(r=L)+3 跟随(r=F)**，事件=涨停/跳变（1m 领涨时刻），按事件时刻升序；另含当日同伴/跟随资金质量/`lone_surge` | **是** | 不认角色只报生态；lone_surge=true 不进「买什么」但留在 rank 带标；跟随资金全负=互倒造势 |
| `confidence` | 证据完整度（拿到几维 / 共几维），**不是模型自信度** | 否 | 维度：tech/patterns/flow/prediction |
| `deliverability_note` | **新增**：给决策层的买入/观望提示（由技能内逻辑自动生成） | **是** | 基于位置/分时/强信号三维生成的**客观提示**，非主观评分 |

## deliverability_note 生成逻辑（技能内部自动生成，供参考）

> 生成时机在交付压缩**之前**（短键压缩/满卡裁剪不影响它）；patterns 与 seal 证据取自满卡。

| 维度 | 判定阈值 | 输出示例 |
|------|----------|----------|
| **位置** | `price` 距 `hi20` ≤ -3% | "位置清洁（距20日高点 -11.2%<=-3%）" |
| **分时** | `shape` 偏弱标签（strong_to_weak / strong_to_divergence / sustained_weak / limit_down_locked，与 cross 同一套强弱分类） | "分时走势偏弱（strong_to_weak）" |
| **强信号** | 满卡 `patterns` 含平台突破/底部启动/均线支撑回踩/放量突破 **且** `seal.tag`∈{one_word,open0} **且** `vr_rel`≥2；无满卡写「证据未交付」 | "强信号命中（平台突破/底部启动/均线支撑回踩/放量突破 + 封板结构清洁 + 放量）" |

> LLM/决策层应**直接阅读 `deliverability_note`**，不再自行重复计算上述三维；
> 粗筛轮无满卡的票只给位置/分时两维，强信号一维写「证据未交付」，**不读作「未命中」**。

`run()` / `deep_analyze` 的双档交付怎么读：

- `analyzed_rank` = **全部票**的横向可比字段（涨跌 / **`chg_prev_pct`（昨日涨跌%）** / **`cpos`（收盘位 0~100）** / **`ma5`/`ma10`/`ma20`/`hi20`/`lo20` 价位绝对值** / **`hi_today`=当日最高价（次日突破基准）** / **`sup`/`res`=`{k,px,d}`（关键位置的两侧：`sup`=现价**下方**最近、`res`=现价**上方**最近；`k` 是类型、`px` 是价位、`d` 是距离%）** / **强度四件套 `ret5_pct`（前5日涨幅%）`zt10`（近10日涨停次数）`zt_streak`（当前连板数）`vol_ratio`（今日量比）`dist_ma5_pct`** / **`amp_avg5`（近5日平均振幅%，止损宽度基准：止损距买点 ≥ 此量级）`sr_gap_pct`（支撑-压力间距%，过窄→操作性弱）** / **`vr_rel`（**全天**：量比÷大盘量比；★≥2=放量强于大盘的确认项（**重要评估条件、非准入闸**），`vr_rel`<2 不否决、须结合资金与支撑判读；绝对量比≥2 但 `vr_rel`<2=跟风放量（大盘同放）；<1=放量不及大盘）`flow_rel`（**全天**：净占比−大盘净占比，百分点，参考数据）`vr_rel_st`/`flow_rel_st`（**分时口径，仅盘中给**：截至 `intraday.t` 的同刻值，个股与大盘同源）** / `seal` 标签 / `seal_pct` / 近5·20日净额；**`pos20`（20 日位置，0=区间最低、100=最高，直接读）** / **`loc`（位置透支分档 `hot`/`cool`/`normal`，hot=三件套全高且非 1 板=高波动档（仓位/触发/止损收紧，非排除、非「只观察」），cool=三项全低=位置干净但弹性一般（触板率并不高），须弱转强/放量确认才当机会，详见 `location` 条）** / **`flags`（闸门打标命中原因：连板放量/吸筹不足/已过度拉升——高波动档护栏证据（仓位/触发/止损收紧），不是排除令）**），**不截断** —— 「谁更强」看这张表；**买点/止损/压力直接写 rank 里的价位，不需要再拉 K 线（禁止 `agent_get_kline`）**
- **强度是加减分项，不是准入闸**。**进「买什么」先过资格线**：三类强信号（**主线龙头 / 弱转强确认 / 放量突破**）至少命中一类，否则加分项再多也不进表；依据原始证据判断资格，关键证据缺失或相互矛盾时须说明，不得编造或把未知当作已确认；**资金是资格级证据**，两档处理：①**否决**——资金连续方向为负（多日逐日净流出）或单日脉冲后回吐 = 资格线过了也不进表；②**降权**——3~5 日累计为负（**归一后显著才算数**：噪声带内的小负不降权，按 `net_pct_of_amount`/`fund_circ_ratio` 判）但当日/近段资金回流（弱转强配套）= 只给试仓/深回踩/条件单，不给追价；③**20 日只作语境**（脉冲识别/拉高出货/持有周期），不作独立否决或降权；资金流入是确认项（不独立构成买入理由）。加分：`ret5_pct` 高**且 `zt_streak`=1**（1 板上攻=最好的一组）、D0 放量（`vol_ratio` 1.5+）、10 日涨停少（`zt10`≤2）、乖离温和、`ret5_pct` 偏低**且 `zt_streak`=0 且弱转强确认**（支撑企稳+资金回流+量能）——★ 无确认的超跌反抽**不加分、不进表**（接刀；全样本 §11.7：超跌不能单独称洗盘/买点）。**连板/动能不是减分项，是尾部捕捉对象**：`zt_streak`≥2、`ret5_pct` 高 = 动量确认，深亏风险改走「高波动档」护栏（仓位上限/宽止损/触发条件），不做排除；`ret5_pct` 高**且 `zt_streak`=0**（涨了不少却没板=上行乏力，别当强势加分）、`zt10`≥3（高位反复透支）、`vol_ratio`<1（缩量却给强度结论）作减分。**缩量回踩是减分不是加分**。★ 位置透支看三件套（`dist_ma20_pct`/`pos20`/`ret5_pct`），rank 已给合成档 `loc`：`hot`=三件套全高且非 1 板（透支=高波动档：仓位/触发/止损收紧，主线龙头确认仍可参与；`zt_streak`=1 时不算 hot）、`cool`=三件套全低（位置干净，不等于买点，触板率并不高）、`normal`=其余。**资金流入流出与位置同为核心证据**，且资金优先于量能条件；不得因加入位置、形态或回测提示而降低资金判断的重要性；量能是重要评估条件、不是闸，`vol_ratio`/`vr_rel`<2 不构成否决，资金持续净流出或脉冲后回吐才是降权/否决依据，资金流入是确认项而非独立买入信号。命中资格线后加分项不足 2 条 → 降仓档或给条件单，不硬推
- **`sup.k` 可能不是均线**（`ma5|ma10|ma20|ma60` 均线 / `lo10|lo20|lo60` 近端低点 / `gap` 跳空缺口下沿 / `poc` 成交密集区 / `zt` 涨停起点 / `hi20` 是压力侧），**不要一律写成「回踩 MA5」**——它给的就是「离现价最近的那个位置」。要更多候选看满卡的 `tech.support.supports`（下方 ≤3 条）/ `resists`（上方 ≤2 条），已按现价分成支撑与压力（同一价位在上方是压力，不是支撑）
- **买点禁止直接抄 `sup.px`**：`sup` 恒在现价下方，照抄的结果是全部「等回踩」、当天一只也买不到。强环境用 `res` 给「突破 X 追 / 不破 sup 持有」，弱环境才把买点压到 `sup` 下方一档
- **`analyzed_rank` 缺键即正常**：无 `limit_up`=未涨停、无 `buyable`=可买、无 `stale_bar`=日线未滞后、无 `risks`=无风险、无 `sup`/`res`=该侧无关键位置、无 `seal`=今日未封板、无 `zt_streak`=今日没连板、无 `flags`=无闸门打标命中、无 `regime`=低位蓄势（中性默认，不占字符）、无 `chg_prev_pct`/`cpos`=日线不足（参考字段缺省）、无 `vr_rel`/`flow_rel`=大盘基准缺失（未校准，按绝对值读）、无 `vr_rel_st`/`flow_rel_st`=非盘中（收盘后同刻≡全天，直接用全天的 `vr_rel`/`flow_rel`）、无 `anchor`=无锚（罕见；日线≥20 根则 lo20 必有）、无 `anchor_evidence`=分时数据缺（未知≠none）、无 `divergence`=背离未命中或资金数据缺（缺≠none）、无 `tier_ctx`=生态地图未算（板块成员/日线缺失或 QD_TOPDOWN_TIER_CTX_ENABLE=0）。（`confidence` 不进 rank 行——它是满卡的证据完整度字段，见下方评分语义）
- **`regime` 位置标签 = 只报位置与跨日方向，不判盘中动作**（一鼓作气/再而衰/三而竭是分时概念，日线不评，可买否看盘中形态）：**高位**（前5日>10% 且当日涨>2%，或跑输大盘大跌——只报位置）/**高位分歧**（高位横盘）/**跳水回踩**（高位大跌但 rs_d0≥-1.5=跌主要来自大盘带崩、非个股弱；关键位企稳即可按回踩接，当日反抽不追）/**弱转强**（前5日≤10% 且昨日跌今日涨>2%，真伪看量比与资金：**量比≥2 是重要评估条件、不是准入闸**，可给追价；<2 优先给回踩支撑并写明资金与位置理由，量比本身不否决；`vr_rel`≥2=放量强于大盘的确认项，`vr_rel`<2 且资金持续流出/脉冲后回吐时才降权（含跟风放量=绝对量比≥2 但 `vr_rel`<2）；★ 独立回测：≥2 组 T+3 超额系统性为负、峰值在 1.5~2.0，故不作加分硬门；同一量比档内资金强组明显优于资金弱组，冲突时以资金为准；加分项不写死：再看价效高（涨幅÷量比高=价升量稳/惜售）可上调置信，单看惜售不加分）/低位启动（昨未跌，看支撑）/低位走弱（按普通档读、量能只作评估条件）
- **分时形态 `shape`（独立维度：只强化/精细化/印证日线 `regime`，不改写日线判断）**：`weak_to_strong` 先破低→收复均价站稳且翻红 / `weak_to_divergence` 先破低→收复过但近端没站住 / `strong_to_weak` 先冲高→跌破均价压不回 / `strong_to_divergence` 先冲高→回撤卡在均价附近 / `sustained_strong`·`sustained_weak` 单边 / `limit_up_locked`·`limit_down_locked` 封板 / `flat` 无转折。配套 `first_extreme`（先见低还是先见高）、`vwap_dist`（距均价%）、`above_ratio`/`above_recent`（在均价上方的时间占比）、`cur_ret`/`peak_ret`/`trough_ret`、`dd_from_peak`（距当日高点回撤%）、`vol_up_down`（上涨分钟均量÷下跌分钟均量，>1=涨放跌缩）。**同名不同义、不得互相覆盖**：日线 `regime` 的「弱转强」看**跨日位置**（前5日≤10% + 今日涨>2%），分时 `weak_to_strong` 看**当日盘中换手**（VWAP 收复）；两者并列印证——双向都弱转强=最强，日线弱转强 + 分时 `strong_to_weak` = 日内已走坏（降权），日线强 + 分时 `weak_to_divergence` = 日内转分歧（等确认再买）
- **`cross` = 日线 × 分时叠加判定（抓假强/假弱，优先级高于任何单侧读数）**：`fake_strong` = 位置已高（高位/高位分歧）却走出分时强形态（该格 86% 是涨停封死）⇒ **高波动高赔率档，不是排除令**：无强确认的次日开盘接力禁止（深亏主力：133 笔 −3.02%，全样本 67 只深亏有 45 只在此格）；**主线龙头 + 强确认**（封板厚实/题材核心 + 次日弱转强或放量突破确认）才给接力条件单——仓位上限、宽止损、失败即走；`fake_weak` = 跨日刚转强但当日盘中回踩 ⇒ **别杀**，是洗盘不是走坏（51 笔 +1.70%、胜率 65%、深亏仅 1 只）；`double_strong` = 两边都强（+0.82%）；`oversold_rebound` = 低位走弱后盘中拉强（超跌反弹 +2.50%，**不算假强**）；`high_weak` = 高位且日内也弱（−1.88%）。缺 `cross` = 无叠加结论（两侧不构成冲突或数据缺），按单侧读。**与单侧结论冲突时以 `cross` 为准**
- **三轴校准（价格/量能/资金流）**：`rs_d0`/`rs_5d`=个股−上证同期超额（%）（参考数据，rs_d0≥-1.5 拆分见跳水回踩）、`vr_rel`=量比÷大盘量比、`flow_rel`=净占比−大盘净占比（百分点，参考数据）。**大盘暴跌、个股横盘（rs_d0 明显为正）=有支撑**（跳水回踩拆分即此义，带崩≠个股弱）。庄股例外：与大盘恒反向、量能自锁（放量缩量不随大盘）的票按独立行情读。**买前量能确认项（重要评估条件、非准入闸）**：有 `intraday` 块（盘中）看 `vr_rel_st`，无（收盘后）看 `vr_rel`；≥2 为放量确认，<2 提示需资金与支撑补证、不得单独否决；两者口径不同（一个截至此刻、一个是全天含昨日），别混用
- **资金微观结构（`fund_trend` 的细化判读，全是确认项、非准入闸、非独立买入信号，不作加分、不单独判强）**：① **时间窗（只认开盘后分段）**——仅 10:00 之后分段净额转正/净占比放大（`after_net_wan`/`points`）可作偏强确认，四段方向一致为正但逐日配对不显著（t=1.05），只作确认不加分；开盘窗（09:30~10:00，`intraday.open_net_wan`）净流入不作偏强解读（近两段翻负、样本外 −0.494），须与「开盘脉冲后撤」风险线索合读；② **位置×资金（须净额为正）**——资金承接落在 `sup.px` 最近关键位附近是独立确认项（`k` 决定类型，不写死 MA5、不写死「站上/回踩」），同样资金为正时贴近明显优于远离（+0.192 vs +0.002，控制涨幅后 +0.149 vs −0.126），弱资金档内增量更大；位置不替代资金方向判断、不因靠近关键位上调买入结论，10~11 月段曾翻负，只作确认不加分。**仅上述两项，不作命中计数、不加权、禁止写「命中越多越强」**
- `inspect_stock` 结果带 **`same_t`（同时刻横向比对）**：`vr_same_t`=今日截至 T 的累计量 ÷ 前几日**同一时刻**累计量均值、`rs_same_t`=个股与上证「昨收→T」的同期超额——盘中判断「现在这一刻谁真强」直接看它，不要拿全天口径倒推；盘后调用 T≈15:00 退化为全天对比（无害）。**同刻三轴校准**：`fp_same_t`=同刻量价方向净占比%、`vr_rel_same_t`/`flow_rel_same_t`=个股对大盘的同刻相对值；`mkt_vr`/`mkt_fp_pct`/`mkt_fp_prev_pct`=大盘同刻量比与净占比（今日 vs 前几日**同一时刻**，大盘强弱两轴：量比+资金流，资金流和前几日同刻比对，用户 9:50 口径）
- **盘后给条件单**：弱市回踩企稳后买，需突破确认的票先放量突破再回踩企稳；其他环境的突破条件单需突破 `hi_today`、早盘成交明显放大且强于大盘。观察窗口内条件不成立当天放弃，不追价。买点列写触发条件及成交价上限。
- **盘中反之：给「追击单」**（2026-11-24）：用户盘中问「现在追什么/能不能追」时，涨停概率大（放量突破/加速/主线/封板趋势）+ 同刻强确认就**直接给现价/突破单**，不等回踩、不套盘后「等次日突破」的壳；止损写当日结构位下方，出场写「次日冲高即走」（T+1：当日买入卖不出，禁止写当日出场）——快进快出
- `analyzed` = 前 N 只**满卡**（按交付预算裁剪，`analyzed_note` 写明 N），与 `analyzed_rank` **同序、非涨停优先再按位置透支升序**（贴近均线 / 20 日偏低位 / 近期未大涨者在前）；满卡之外的票只使用已交付的证据，缺失不能猜测。本技能的 `run_skill` 入口不开放 `inspect_stock`。满卡已瘦身：不含 `evidence_dims`、空容器与 None 键；盘中另有 **`intraday`（同刻校准块）**：`t` 截断时刻 / `day` 目标日 / `vr_same_t` 个股同刻量比 / `vr_rel_st` / `fp_same_t` 个股同刻净占比% / `flow_rel_st` / `ret_same_t` 昨收→`t` 涨幅% / `idx_ret_same_t` 上证同期涨跌% / `rs_same_t` 超额 / `mkt_vr`·`mkt_fp_pct` 大盘同刻基准 / `mkt_fp_prev_pct` 前5日同刻净占比均值（大盘两轴 = 量比 + 资金流，且都和前几日**同一时刻**比）
- `seal` = 封板结构的**客观事实 + 硬标签**，`{tag, seal_tier, open_count, seal_ratio_pct(封单÷成交额 %), zt_days, turnover_pct}`。**两个正交事实，必须合起来读**：`tag` 只切开板次数（`none` 未封板 / `one_word` 一字·全天封死 / `open0` 0 开板非一字 / `open1_2` / `open3_5` / `open6p` ≥6 次 / `unknown` 缺实时或池里无该票）；`seal_tier` 只切封单厚薄（`thin` ≤5% / `mid` ≤15% / `thick` ≤40% / `vthick` >40%）。**不打分、不排序**——买不到不是决策问题（盘后次日按涨停价挂单即可），它回答的是「今天封得怎么样」。**开板越多越差；封单越厚越强**；连板 2 板最弱、4+ 板最强。**组合要看**：`open0` + `thin`（0 开板但封单极薄，如 000568）与 `open6p` 同为最可疑，别因为「没开板」就当强；有厚封单支撑（`one_word`/`vthick`/`thick`）才是真强封。标签边界可用 `QD_SCREENER_SEAL_TAG`（JSON）覆盖
- **`limit_up=true` / `buyable=false` 只是事实，不是排除令**：封板票可进名单（盘中此刻买不进，盘后/次日是另一回事），接不接由你的逻辑决定，但进「可买」列表要写清凭什么
- `report_guide` 判定规则摘要（支撑≫涨跌幅、周期、禁止重验）——**写结论时直接照它落笔，不必 read_skill**
- `rt` 实时快照（价格 / 涨跌幅 / 涨停价 / 跌停价 / `limit_band` / 涨跌停）；`stale_bar=True` 时 `tech` 的收盘/涨跌停已按 rt 修正（MA/RSI 仍基于日线）。**有 rt 就不要在主对话重拉实时行情**；`stale_bar` 时**不要用 `close_pos_in_day` 下结论**。**ST/新股信 rt 价**：`limit_band=no_limit`（新股无涨跌幅）两价为空，禁止用公式回退；ST 的 quote 带可能按板规则而非 ±5%（见 `limit-rules.md`）
- `theme.hit` 题材是否落在当日主线；`hard` 客观障碍清单；`missing` 数据缺口
- `flow` = 资金证据卡：`net_wan`/`net_pct_of_amount`（当日）+ **`recent`（近5/20日累计、连续方向、逐日符号、剔除最大单日、上一交易日）** + **`intraday`（开盘窗 vs 其后净额、open_share_pct）**。**资金看多日总体，单日大额流入 ≠ 趋势——这是盘后选股口径**。**窗口权重（超短线，2026-11-24 定）**：
当日（同刻抢筹/10:00 后分段吸筹）= 时机主窗口 ＞ 3~5 日埋伏（吸筹打标/连续方向）= 资格主窗口 ＞
20 日 = 语境（脉冲识别/拉高出货检测/持有周期），**不作独立否决或降权**——20 日流出但 5 日埋伏+
当日抢筹齐 = 只压持有周期不压资格；20 日大额流入反而是迟到信号（S4 全样本：该组负 alpha）。**盘中口径相反**：同刻资金持续流入（`intraday` 分段 10:00 后连续转正）+ 放量 + 强于大盘 = 趋势进行时，该快买就快买（现价/突破单直接上，不等回踩不等次日），此话术只降仓位档、**不拖出手速度**——分钟级进出是本打法核心优势（设计方案 v2 §1.1）；唯一例外是开盘窗（09:30-10:00）脉冲不作偏强解读（拉高出货高发，须 10:00 后分段确认）。**口径看 `caliber`**：恒为 `price_direction`（量价方向净额，按分钟涨跌方向累计成交额派生），**不是东财四档主力净额**，量级不同、不可换算 ⇒ 正文只能写「量价净流入/资金净额」，**禁止写「主力净流入」**；`recent`/`intraday` 各自带 ok，缺失看 missing
- `warnings` 可能含**拉高出货线索**（「开盘脉冲」「疑似拉高出货」「趋势背离」，deep 层在 `flow_risks` 键）：开盘窗大额净流入后转流出/冲高回落/今日脉冲与近5日净流出背离 —— 经验型判断，可否决但要写理由
- `warnings` 经验型软提示（如「弱势市涨停活跃源无题材支撑」）——你可以采纳也可以否决
- `hints` 是历史经验门槛（建议值），**不是硬规则**
- `funnel` 是 `run()` 返回的漏斗统计键：`pipeline=topdown` / `verdict`（L1 大盘档） / `pool_raw`（闸前收集只数）/ `baseline`（截断入选只数 = 全部入 deep）/ `limit`（截断额定上限，默认 35）/ `dup_max`（入选票最大重复板块数，重复=多板块资金共识）/ `short_of_limit`（不足额定额、不凑数）/ `deep_n`（真正进 deep 的非涨停只数）/ `zt_ref_n`（只列参考的涨停只数）/ `flow_invalid_n`（资金流通比落在低区无效区间的只数）/ `streak_surge_tagged`/`early_accum_tagged`（闸门打标保留的票，挂 `flags` 不放弃）/ `streak_surge_unknown`/`early_accum_unknown`（数据不足未打标数），用于复盘「漏斗各层过了多少、最后进 deep 几只」

## 报告交付安全口径

- 普通 A 股新买入股份买入当日不可卖出，最早下一交易日处置；跳空或跌停可能无法按触发价成交，不保证最大损失。
- 每个分支按实际成交价计算风险，计划时先用买价上限计算 `(买入价-止损触发价)/买入价`。条件买价变化后重新判断支撑和压力，旧压力不自动变成支撑；回踩分支不满足条件当天放弃。
- 前一交易日量比不代表次日已确认；次日量能须与历史同刻比较，量比倍数不是涨幅倍数。
- 盘前区分 `selection_snapshot` 选人数据日和时刻与 `run_started_at` 运行时刻，明确执行日；缺失不猜。选人时点不代表其后获取的所有证据具有相同时刻。
- 历史资金日线与当日资金分开读：`flow_data_day` 是最近资金日线数据的对应日期，`flow_last_day_wan` 是该日净额，`flow_today_wan` 是当日净额（盘中=realtime 量价、盘后=kline_1m 15:00 定格，口径见 `flow.caliber_note`）；盘中日线可能停在前一交易日，不能当作当日。**净额口径速查（引用任何净额前先对表）**：`net5d_wan`=近 5 个交易日累计、`net20d_wan`=近 20 个交易日累计——引用净额必须写明 N 日口径且能逐字对应到字段（实测有报告把 20 日净流出误读成「近 5 日」、方向反了；也有把 5 日净额当「当日」的）。**涨幅/乖离类同理**：`ret5_pct`=近 5 日涨幅、`chg_pct`=当日涨跌、`dist_ma20_pct`=现价距 MA20 乖离——乖离≠跌幅，引用任何百分比必须写明口径（实测有报告把乖离 -9.48% 写成「跌 -9.48%」，实际当日仅 -0.72%）。`sign_5d` 的 `+` 包含零，最新日是否流入须核对净额；即使与选人快照同日，也不能证明取数同刻。关键证据缺失或冲突时说明不确定性，不得编造。
- `buyable=unknown` 是行情缺失，不能推断可买；累计净额为负需结合归一化资金指标判断，不能仅凭负号自动降权。
- 检查 `preview_note` 和候选行数；若 `analyzed_rank` 被裁剪、行数少于 `funnel.deep_n` 或 `candidate_integrity.ok=false`，必须说明候选不完整，不得据此生成买入推荐。
- 技能会按交付预算先减少满卡，再压缩可选信息；`delivery_note` 说明省略内容。重复的板块分组可能改从 `boards.picked` 的 `tier` 读取；省略的空资金字段是未知，不是零。选人明细可能合并到对应的候选行或涨停参考。若仍超预算，`analyzed_rank` 的重复字段名可能缩为短键：`analyzed_rank_keymap` 按「短键 → 原字段名」对照，未列出的字段名不变，值及缺失语义不变；`code` 和 `name` 不缩写。证据或解释未交付时不得猜测；若返回 `error` 表示完整候选无法交付，不得推荐或加入自选。
- 买入表格每行必须有 8 列，买点写「不高于 X」、止损写「跌破 X（盘中触价）」或「跌破 X（收盘确认）」，目标写具体价格。

```python
st = market_state()                       # 先看环境
result = run()                            # 三层漏斗选人 → deep 一次完成

# 对漏斗选出的票继续追问（自查证据）：
rank = result["analyzed_rank"]            # 全部票的横向可比字段
codes = ",".join(x["code"] for x in rank[:8])
deep = deep_analyze(codes=codes)                     # 拉齐证据，再自己加权（默认无 mtf）
pats = detect_patterns(codes=codes, params='{"platform_range_pct": 10}')  # 换个定义看结论稳不稳
detail = inspect_stock(rank[0]["code"], deep=True)  # 对最想确认的票追问
```

- 证据不足就继续追数据：调大 `limit`、`deep=True`、或用 finance 工具查板块/资金/消息面
- 同一批票可以用不同口径重试；不必一次定型
- 六维里有任何一维答不上来，就把它写进「数据缺口」，别装作没这个问题

- **`limit_up_ref` = 涨停参考清单（不进 deep 分析）**：仅作板块情绪旁证与**封板资金判强弱**（承接位框架 4.2：`seal_ratio_pct`/`seal_tier`/`open_count` 三事实——盘中=实时池口径、此刻封着才有值，炸板票缺键=未知不是 0；盘后=收盘池定格），不是可买清单；未进入 deep 的票证据不足，不得给买入单。
- **资金流通比 `fund_circ_ratio`（净额÷流通市值%）**：已按盘子归一、可跨票比；`flow_valid=false` 表示流通市值低于有效下限或数据缺失，该指标不可用，不要当 0 读。**跨票比量级必须归一**（2026-11-24 定）：绝对净额（`net*_wan`）只读方向/连续性；量级影响力用 `net_pct_of_amount`（净额÷成交额 = 当日**边际压力**，换手率进这个口径）与 `fund_circ_ratio`（净额÷流通市值 = 多日**火力**）——同样 1000 万，对换手 10% 的中盘 ≈ 成交额 1%（噪音级），对换手 1% 的 20 亿小盘 ≈ 50%（半个盘口单向走）；低换手小盘的高净占比是双刃剑：边际强但出口窄（换手 <2% 流动性警示），进出速度优势会反转。

## 分析框架（六维交叉验证 + 短窗周期）

对每只候选至少回答前四维，第五六维决定组合层面；结论优先落在 **T+1 / T+3 / T+5**：

1. **题材与主线**：是否落在当日 `themes`？同一题材已被你推了几只（同题材堆 3 只不是分散——集中打法：聚焦龙头一只，或别推）；涨停参考票兼作接力候选（走 limit_up_ref 接力分层）：早盘板/无强确认接力默认不接，主线龙头+强确认给条件单，午后/尾盘板可谨慎给
2. **量价结构**：量比、收盘在日内位置、是否 20 日高位、振幅；放量突破 vs 放量滞涨要区分；**日内 MACD 红绿柱变化**作涨/跌压力参考；当日涨 2~8% 的温和追高是负 alpha（212 日全样本配对 2~5% t=-3.33、5~8% t=-3.04），别当强势加分、要结合破位风险控仓；≥8% 大阳未涨停子集已复测可成交正 alpha（§7.2：+0.477%/胜率 49.83%），高波动档、非主力方向；跳变后收跌则观察反包确认；中段（10:00-11:30）或尾盘（≥13:30）启动不因「盘中启动」本身加分，需确认承接。**早盘信号振幅和回撤风险较高，但不代表触板率更高**；尤其弱市早盘，先确认支撑、回踩承接和量价延续，再决定是否收紧推荐口袋，不能仅按信号时间加分或排除
3. **资金**：资金流入流出是选股、排序和买卖判断的核心证据，不因新增维度或回测提示而降权；量价净额方向与占成交额比（`caliber=price_direction`，**不是主力净额，正文禁止写「主力」**）；**近5/20日总体（flow.recent：累计、连续方向、逐日符号）优先于当日单格**（盘后口径；盘中改用同刻分段持续性，见 trading-logic §0.4）；形态好但资金流出 → 减配或放弃；**开盘脉冲后回落/单日脉冲与多日趋势背离 → 拉高出货嫌疑（flow_risks）**；缺失时明确数据不足，不能当成零或净流入；结合个股流通市值比较相对规模，但量价方向净额不能证明控盘；弱市长样本切片中，流通市值 <80 亿候选深亏率较高、≥80 亿候选深亏率较低，但大市值触板率也较低，故只作风险与目标权衡，不做硬筛或自动排序；市值取值/历史成分有偏差；**龙虎榜席位**：是否有主力席位、是否有游资席位、是否有机构席位
4. **位置与空间**：距 MA20 乖离、20 日位置、连板高度、**支撑位是否清晰**、**支撑–压力间距**（`sr_gap_pct` 过窄 → 操作性弱、排序下调）；近 5 日超跌（`ret5<0`）**只作位置背景**（全样本：超跌不能单独称洗盘/买点），无弱转强确认的超跌反抽=接刀，不进「买什么」
5. **市场状态**：**两档情绪分开读**——大盘情绪 `market_mood`/`market_mood_score`（指数+资金，决定姿态与只数）、个股情绪 `stock_mood`/`stock_mood_score`（涨跌停比/炸板率，决定敢不敢追高）；另看涨停 / 跌停家数、炸板率、**指数相对开盘强弱（早盘主信号）与大盘资金近5日方向**——弱势市/`cautious` 应自动提高门槛、减少只数；**两档背离（大盘强、个股难做）时按收紧执行**
6. **可执行性**：`hard` 全集（ST/退市、换手不足、**价格 <2 或 >300**、涨停买不进、停牌）；次日干扰

### 核心判定原则（摘要）

**盘中是红是绿不决定安全，有没有支撑才决定安全。** 可怕的是「没有支撑位的一直下跌」。

- 先按**涨跌停带**归一（主板 ±10% / 创业科创 ±20% / 北交 ±30%；ST/新股以 `rt.limit_*_price` 为准），再看红绿与结构
- **-8% 弱转强 + 有支撑** 可以比 **+8% 转分歧/转弱** 更安全；禁止按涨跌幅排序
- **日线标签 ≠ 盘中信号**；三时段（盘中/尾盘/盘后）落法不同

## 评分与方向语义

- **无预测分**：任何票都不要再写「次日上涨参考」（见上方「本技能不输出预测分」）
- 报告不写预测分/概率。`analyzed_rank` 里确实**没有** `p_up`/`direction` 列（别去找）；模型参考分只在满卡的 `score`（已标定 T+1，不参与排序），`confidence` 是证据完整度——都只作内部参考，不进报告、不写成概率
- **主表不另设「方向」列**；方向写在 **T+1/T+3/T+5** 列（看多/中性/看空/未知）：
  - 每个周期独立判断：**中性是证据充分支持的明确结论**，不是缺省值；数据不足、无法相互验证或证据矛盾且无法消解时写**未知**，简述缺口或冲突
  - T+1、T+3、T+5 各用自身证据写方向；**禁止**编造概率、把未知写成中性或把单一周期结论外推成多周期；**三个周期全「中性」还进「买什么」= 把未知包装成中性凑数**（全中性 = 没有看多证据，没有资格进表）
- 市场及其他综合判断同样区分中性与未知，不把数据缺失或未消解的矛盾写成中性
- **置信度分层**：T+1~T+5 可正常给；T+10/T+20 默认低一档，证据不足直接「不适用」。**行动表内只写 T+1/T+3/T+5**
- `hints` 的门槛/只数是经验值，不强制：题材共振且证据扎实可放宽；数据缺口多就应下调置信度
- 你可以不认同模型分，但要写明理由（例：模型不知道今天这条新主线）

回测经验是六维分析中的辅助证据，不是独立分析项或排除规则。`monitor` 字段只作为内部提示：
结合当日支撑、资金、题材和市场状态，分别融入对应维度；仅在确实影响结论时，把具体风险、
确认条件或反制动作写入「一句话理由」/「风险」，不要单独罗列监控格名称或提示清单。
这些经验来自 2026-10-21~10-29 回测（来源 tmp/OPTIMIZATION_plan_5m_20261107.md），样本小，
可以被当日证据否决，不得机械服从。

同理，深亏率/触板率是**护栏先验（定仓位/触发/止损），不是排除规则**——用深亏率清场最强批次，
等于拿别人的记分牌否定尾部捕捉打法（2026-11-23 小资金复利对齐）。

## 拉升定性与承接位（承接位选股框架 2026-11-26）

**总纲**：拉升图形判断不了「意图」，站在意图的必经之路上——找承接位（钱的真实成本位），
在承接位挂单，看见承接证据才成交，承接位失守就走。出货和换庄都有承接，区别在接完之后
价格守不守得住；出货是单票行为、真启动是板块现象。

**买点 = 承接位挂单**（三词退休、一锚上岗）：买点从 rank `anchor.primary` 取锚位（写明类型：
封板价 seal / 涨停起点 zt / 成交密集区 poc / 缺口 gap / 前低 lo20），挂单价 = 锚位 ± 带宽
（带宽参考 `amp_avg5`，默认 ±1.5%）。**承接证据在位才成交**：`anchor_evidence.level` =
confirmed（厚封 / 带宽内资金为正）才成交，partial 只给试仓，none 不买。「回踩」「突破」
不再是三种买法——回踩只是价格回到锚位的动作名；突破是价格离开锚位后的确认（此时买点
上移到新锚）。primary 由 `QD_ANCHOR_PRIMARY_RULE` 规则合成（默认 R1：seal>zt>poc>gap>lo20），
**不许手调**（回测校准后由回测改默认值）；`dist_pct` 负 = 锚在现价下方（挂单可达），
锚距拉大 = 不追。**锚位滚动 + 失守即弃锚**：换庄后旧锚失守自动降级到下一锚、旧锚变压力；
二进宫不带历史成见。

**止损 = 承接位外侧一档**：锚位下沿再退一个缓冲（≥ 1×噪声带），`stop = 锚位 − max(缓冲,
min(amp_avg5, 8%))`——主力建仓位失守 = 逻辑破，不是噪声；不得窄于噪声带、不得越过 -8%
深亏线（旧止损三条继续有效，见下）；已持仓止损只紧不松（棘轮）。

**拉升定性四问（定案表，替换盘感；四问全答，① 一票否决）**：

| 问 | 真启动倾向 | 出货/孤立倾向 | 数据来源 |
|---|---|---|---|
| ① 钱：拉升段的钱在进还是在出？ | 分段持续流入（10:00 后）、`divergence` 未命中 | **`divergence=价升钱出`/脉冲背离 → 一票否决** | `flow.up_net_wan/down_net_wan`、`flow.intraday`、`flow_risks` |
| ② 生态：前 5 天有人在场吗？ | `tier_ctx` 领涨四中有 T-1 事件、跟随资金正 | `lone_surge=true`、跟风资金全负 | `tier_ctx` |
| ③ 位置+承接：在哪、有人接吗？ | 锚位=建仓/成本位（zt/poc/seal），承接证据 confirmed | 高位锚远、`anchor_evidence.level=none`、`loc=hot` 无确认 | `anchor`、`anchor_evidence`、`loc` |
| ④ 盘口：涨得住吗？ | 回踩锚位不破、厚封少开板、`vol_up_down`>1 | 冲高回落（`strong_to_weak`）、`dd_from_peak` 扩大、薄封反复开板 | `shape`、`cross`、`seal` |

**定案**：①出货指纹 → 不进表；②③④ 同向 → 买点=锚位挂单；混合 → 试仓/写未知
（「不判断」永远合法）。

**龙头/换龙头裁决（资金说了算）**：「谁是龙头」是**结论不是输入**：持续承接 + 埋伏在身 +
封单厚 + 生态在场 = 龙头。**换龙头信号**：领涨四中旧龙头承接衰竭（封单变薄/资金转负）+ 新面孔
资金初启（5 日转正 + 锚位承接）→ 按新面孔的锚位重排买点，旧龙回避。涨停票强弱用封板资金：
`seal_ratio_pct` 高 + `open_count` 少 = 真强；薄封 + 反复开板 = 假板（不接力）。

**周期状态机（角色是状态不是身份）**：同一票会反复走「跟随→拉升→变龙头→出货→换庄→
再拉升」多个周期，判定输出永远是「它现在处于哪个阶段」。转换检测看「变化」不看「水平」
（承接证据 none→confirmed、资金对比翻转），必须带 T-5~T-1 前后文。时间基：换手 10-30%/日
的票换庄是 1-2 天的换手率事件，循环以天计——高换手 + 价格横盘 + `above_ratio` 高
（下午 13:30 后仍在均价上 = 确认）= 建仓日签名，下午即建仓窗口；下午翻车 = 试探/分歧日，
不建仓。

## 输出契约（行动清单）

用户只关心：**买什么 / 什么价位买 / T+N 能不能赚 / 走坏了能不能全身而退**。

```
## 买什么（N 只，N=实际符合条件数；可空，0 只是常态输出）
| 代码 | 现价 | 买点价位 | 止损价(触发口径) | 目标价/止盈条件 | 仓位 | T+1/T+3/T+5 | 一句话理由 |

## 空仓卡（仅 N=0 时写）
今日无符合标的，空仓等待：<一行「今天别打」的证据>

## 风险与证伪（≤3 行）
```

- **进表资格**：三类强信号（主线龙头 / 弱转强确认 / 放量突破）至少一类 + 加分项 ≥2；依据原始资金等证据判断资格；**无确认超跌反抽（接刀）无资格**，没有 A+ 宁可空仓
- **买点 = 承接位挂单**（承接位框架，见上章）：从 rank `anchor.primary` 取锚位（写明类型），挂单价 = 锚位 ± 带宽（默认 ±1.5%）；**承接证据在位才成交**：confirmed 才成交、partial 只给试仓、none 不买；无 anchor 缺键时回退 sup/res 关键位并写明位置名；买点列写「<锚类型> <锚价>±带宽，承接<confirmed/partial>」（例：「涨停起点 9.31±1.5%，承接 confirmed」）；**不许自创价位**——自查：买点/止损锚必须落在 rank `anchor` 字段上，不在字段上的价位不许出现
- **止损 = 承接位外侧一档**（承接位框架）：锚位 − max(缓冲, min(amp_avg5, 8%))，缓冲 ≥ 1×噪声带；双锚取宽（不得窄于噪声带、不得越过 -8% 深亏线）；无 anchor 时按下方三条旧规则
- **止损三条**（详见 `strategy-rules.md` §六）：① 宽度取 **min(amp_avg5, 8%)**：≥振幅量级防噪声（1.3% 止损配 8% 振幅是白送），但**止损不得越过 -8% 深亏线**——amp≥8% 的高波动票封顶 8% 并靠仓位控风险（回测 §6.2：止损深过深亏线会反噬，8~10% 档深亏 7.53%→11.25%）；② 落点在结构位外侧 + 噪声缓冲，**避开当日已被穿过的价位**；③ 写明触发口径「盘中触价」或「收盘确认」（动量/接力仓默认盘中触价）。止损写「跌破 X」/「不跌破 X」；无合格止损价不得进「买什么」；④ **棘轮**（2026-11-24）：已持仓者的止损以入场计划为准、**只紧不松**——本表止损是新开仓视角，不得拿来放宽旧单止损
- **必须有止盈**：目标价（上方压力位/涨幅预期）或止盈条件（触板/冲高滞涨/破均价）；只有止损没有目标的票不进表——**复利靠兑现滚出来，不靠拿着**
- **仓位档**：空仓 / 试仓（≤1成） / 标准（2~3成） / 重仓（3~5成，仅 A+：三类强信号齐 + 无证据冲突）。小仓试错不写——B 级机会赚了没意义、亏了照样磨损
- **空仓是常态输出**：N=0 就写空仓卡 + 一行「今天别打」的证据（如资金 5 日净流出、cautious、涨停参考清单为空）；弱市空仓等待本身就是复利，禁止硬凑
- **报告长度预算**：全文 ≤1000 汉字，先结论卡、再风险与证伪，必须以完整段落收尾（截断=交付失败）
- 表格行数随推荐数浮动，正文保持精简；指标罗列、长篇分析不进正文；**尾注固定一行抄模板**（「market-screener ｜ 漏斗 A→B→C+D ｜ 快照 日 时刻 ｜ 资金=量价方向净额」）
- **不写排除举例/不买/观察栏目**——候选证据全在交付载荷（analyzed_rank）与快照里，追责走快照 diff；涉及推荐票的资金风险仍写在理由或风险中；报告目标=简单直观方便识别、省 token
- **中文白话**：不写 near_support / rank_cut 等字段名
- 保留 6 位代码、股票名称、看多看空、「跌破 X」（喂 claims 追责）
- 今天没得选时写**空仓卡**（「今日无符合标的，空仓等待」+ 一行理由），不要硬凑

## 常见错误清单

- 按涨跌幅排前几只直接推；忽视涨跌停带（主板 -8% ≠ 创业板 -8%）
- 把盘中下跌一概当利空，或把盘中上涨一概当安全——错在忽视支撑与弱转强/强转弱
- 把日线 `weak_to_strong` 当成「此刻盘中弱转强」；盘中用 `close_pos_in_day` 说「尾盘承接」
- 把中长线逻辑（基本面、月线、长持）混进短中线结论
- 强行凑满 T+10/T+20——后两档证据不足就写「不适用」；给 3 板以上票硬写 T+3/T+5
- 编造概率，或把某一个周期的胜率外推到多周期；理由里重复写方向
- 忽视 `hard`：涨停买不进、**低价/高价带**、停牌、换手不足
- 弱势情绪（weak）下仍把高位连板当 A+ 满配——弱市高波动档只给条件单/试仓
- **只看量比≥2 就当可买，或因 `vr_rel`<2 一律否决**：量能是重要评估条件、不是闸；冲突时以资金为准（独立回测 ≥2 组 T+3 超额系统性为负、峰值在 1.5~2.0）
- **只看当日资金流向就下结论（不看近5/20日总体）**；把单日大额流入当趋势反转
- **接盘「开盘几千万拉升后抛盘」**：忽视 flow_risks 的开盘脉冲/冲高回落/趋势背离线索
- **早盘只看涨停家数下结论**（封板未成熟，应看指数相对开盘+大盘资金方向）；大盘走弱（cautious）仍按强市门槛推票
- 多只票同一题材却当成分散配置
- 把 missing 当作「没有风险」
- **接刀进表**：无确认超跌反抽当「回调充分」推——下跌趋势里的均值回归胜率天然低，不是本打法
- **拿「位置已充分回调」当买入理由**——超跌只是位置背景（§11.4 已降级），资格看弱转强/放量/主线确认
- **全中性凑数**：三个周期全「中性」还进「买什么」——把未知包装成中性；证据不够写未知，没得选写空仓卡
- **止损贴身或落在噪声区**：距买点 < 日均振幅、或设在当日已被穿过的价位——被扫=白付成本
- **只有止损没有止盈**：无目标价/止盈条件就进表——复利靠兑现滚出来
- **矮子里拔将军 + 小仓试错**：B 级机会凑数进表——赚了没意义、亏了照样磨损，宁空仓
- **弱市证据全在说「别打」还硬给票**：资金多日净流出、cautious、涨停参考清单为空却凑 2 只——空仓是择时的一部分
- **把盘中快打的浮盈拖成波段仓**：追击单赚了十几个点不走、改口「等 T+5」——快打的钱快拿，拖回去就回到接刀数学

## 回测先验校准（2026-11-08 增补）

1m 全样本重放（2026-04-15~11-02，134 交易日、deep 可成交 1862 笔）已用于校准旧短窗经验。
`monitor` 只携带分组风险线索，不是选人闸或独立结论；使用时以个股支撑、分时承接、可执行性和多日资金
连续性为先。与分组统计冲突时，先指出冲突与口径差异，不得让总体胜率覆盖个股事实。

- 早盘信号不等于更高触板率：全样本早盘触板 6.4% / 深亏 3.1%，午盘触板 9.6% / 深亏 2.7%；
  早盘的上冲和大回撤风险都较大，先核支撑与承接。

  大市值深亏较少但触板也较少。均只作风险/机会权衡，不作硬过滤或自动排序。
