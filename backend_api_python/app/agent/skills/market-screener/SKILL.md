# 全市场短中线选股 (market-screener)

## 何时用 / 何时不用

- **用**：用户问「今天买什么」「有什么好股票」「短线/短中线选什么」这类**全市场筛选**问题
- **不用**：用户指定了具体股票代码/个股分析——那是单票分析链路，不要走本技能
## 选股目标

**短线小风险、大涨幅。**

- **小风险**：有清晰支撑（可写「跌破 X」止损）、非追高、非无支撑下跌
- **大涨幅**：主线题材 + 资金/趋势确认 + 有上行空间 + `p_up` 尽量高
- **现价优先入场**：信号明确时且现价有足够上行空间时买优于等回踩；**追高 ≠ 现价买**
  （追高=无信号/无支撑/连板接力；现价买=信号+支撑+资金/主线）

## 分析周期（短中线，不是中长线）

| 周期 | 定位 | 一句话 |
| --- | --- | --- |
| **T+1 / T+3 / T+5** | **核心（必写）** | 情绪接力、分歧转一致、短线趋势；现有逻辑下最好分析 |
| **T+10 / T+20** | 可选（不进主表） | 证据够才写，置信度默认低一档；不够写「不适用」 |

- 不做基本面尽调、不按月度/季度持股下结论；也不是纯隔日超短
- `p_up` 是**唯一经标定的数字**，且只覆盖 T+1；其余周期禁止编造概率

详细落笔表见 `references/analysis-framework.md`「周期怎么落笔」。

## 你的角色与自由度

你是短中线选股分析师。**代码只提供客观事实，规则由你解读**：形态/来源/口径在 `references/strategy-rules.md`，交易判定真源在 `references/trading-logic.md` §0，六维读法在 `references/analysis-framework.md`。

三条原则：

1. **代码不做取舍**（`pre_screen` / `profile_candidates` 层）：候选池不排序、不截断、不过滤；`hard` 只是客观障碍，如何处置由你决定。`run()` 内部 = **基线保底 + 加法改进**；加法层（p_up 硬闸 + 排名截断 + 弱转强/缺分/保底回捞）只在基线之外做改进、填充至 29。淘汰计数在 `funnel.excluded_score`（只含加法层）——被砍的票未进 `analyzed_rank`
2. **你可以自己写代码**：在沙箱里对画像结果自由排序、过滤、分组、加权——这比套模板更接近真实盘感
3. **结论必须可复盘**：每只推荐的票要说清「靠哪条证据入选」+「什么情况下这条证据失效」

规则文档里的条目有三档性质，看清标记再用：

- 【定义】形态/指标的几何定义 → 可以用 `detect_patterns(params=...)` 改，但改了就是另一种形态
- 【历史】2026-09-29 前写死在代码里的旧口径 → 供你对照「旧版为什么这么选」，**没被验证过，可以推翻**
- 【提示】经验值与常见误区 → 结合当日证据判断

禁止：

- 把技术形态当成功概率（形态只能解释方向，不能直接加成胜率或编造 xx%）
- 把数据缺口当成「无信号」（画像里的 missing 与调用失败要看）
- 编造数据：工具没给出的数值，不允许出现在结论里

## 工具面（`run.py` 公开函数，docstring 首行即描述）

> 经 `run_skill` 派活时入口是 `run()`（无入参，一次性跑完整流程）；其余函数是它的内部阶段，
> 用于理解 `run()` 的取数与口径。
>
> ⚠️ **`run()` 不接受任何参数**——尤其没有 `date` / `for_date` / `trade_date` / `strategy`。
> 「分析哪一天」由服务端按交易日历决定（`current_data_day()`：交易日 ∧ >09:15 取今日，
> 否则上一交易日）。问「明天 / 下周买什么」时**照常直接调 `run()`**，日期差异在答案里说明即可；
> 传日期参数会**直接失败并浪费一次往返**（实测 2026-10-31 两次踩到）。

| 函数（真实签名） | 作用 | 何时用 |
| --- | --- | --- |
| `run()` | 一次性跑完整流程：**① 基线**（池序画像、`hard` 只拦 ST/停牌/价格越界/低换手，**涨停封板放行**，恒入 deep ≤25）→ **② 加法层** `pre_screen(search_top_n=100)` → `objective_preexclude` → `score_pool`（双保险软门槛 + 缺分保送，Round0 存活<4 自动 Round1 放宽，最多 2 轮，reserved=基线去重）→ **③ deep_analyze(基线+加法，合计 29)**。**无入参** | 主对话派活（经 `run_skill` 暴露的入口） |
| `market_state()` | 市场事实：资金流 / 涨跌停家数 / 炸板率 / 板块强弱 / 情绪标签 / **指数日内强弱（index_intraday/intraday_bias）** / **大盘资金近5日方向（fund_flow_days）** / **cautious（走弱环境，收紧选股）** | 起手，判断大环境 |
| `pre_screen(sources=None, queries=None, search_top_n=50, min_turnover=None, limit=None)` | 候选池：自选来源（连板/尾盘封板/龙回头/热点/条件搜索/近期涨停），不做取舍与排序 | 起手取池 |
| `profile_candidates(prescreen_result, limit=20, with_flow=True, with_pred=True)` | 每只候选的证据卡：位置 / 量能 / 资金 / 题材 / 模型分 / 硬障碍。**入参是上一步的 dict** | 核心，几乎所有场景都要跑 |
| `deep_analyze(codes, limit=8, with_flow=True, with_patterns=True, with_mtf=False, budget=None)` | 批量拉齐证据（形态 / 技术 / 资金 / 多周期 / p_up / **实时行情对账**），无任何主观评分。返回 **两档同序（p_up 降序）**：`analyzed_rank`=全部票的横向可比字段（不截断）+ `analyzed`=最强 N 只满卡（按交付预算裁剪） | 对你挑出的少数票做证据汇总 |
| `detect_patterns(codes, days=60, params=None)` | 六种 K 线形态识别，回答「是不是」不回答「好不好」；`params` 是 JSON 几何定义覆盖 | 想验证形态 / 做阈值敏感性检查 |
| `multitimeframe(code, daily_days=60, minute_days=5)` | 日线 + 15m + 5m 的结构量与速记标签 | 判断多日结构与日内强弱时用（注意标签是日线几何，见下） |
| `inspect_stock(code, deep=False)` | 单票深挖：题材归属、资金、涨停史、龙虎榜席位、客观风险点；`deep=True` 追加快源 | 想验证某只票 / 证据互相矛盾时 |
| `filter_candidates(prescreen_result)` | 便捷形式（旧流程兼容）：保守剔除有硬障碍的候选，返回逗号分隔 codes | 只要 codes 清单时（要看证据用 `profile_candidates`） |

> ⚠️ 除 `run()` 外，其余函数都是 `run()` 的**内部阶段**，当前**未经 `run_skill` 暴露**
> （`skill_run.EXECUTABLE_SKILLS["market-screener"]` 只登记了 `run`）。其中
> `profile_candidates` / `filter_candidates` 的入参是上一步的返回值，独立子进程间无法传递。

### 三条数据硬约束

- **分钟源只有 `1m`**：`15m` / `5m` / `30m` / `60m` 查表恒为 0 行。`multitimeframe()` 内部取 1m 后本地聚合，别自己去查其它周期
- `confidence` 在 `deep_analyze` 里是**证据完整度**（tech / patterns / flow / prediction 拿到几维），不是模型对判断的把握
- **`weak_to_strong` / `strong_to_weak` 是日线 MA5 计数标签，不是盘中即时信号**；「分时均线 / 低点不移」无现成字段，需自算 1m

`profile_candidates` 返回的每行字段含义：

- `p_up` 模型给出的 **T+1** 上涨概率（仅此一档）；`tech` 收盘 / 涨跌 / 量比 / RSI / MA 乖离 / 20 日位置 / 连板数 / **`support.supports`·`support.resists`（现价下方/上方最近的关键位置候选）**
- `seal` 封板结构（画像层用日线末根判封板、无 rt ⇒ `one_word` 判不出，深挖层才用实时 high/low 判一字）

`run()` / `deep_analyze` 的双档交付怎么读：

- `analyzed_rank` = **全部票**的横向可比字段（`p_up` / 涨跌 / **`chg_prev_pct`（昨日涨跌%，弱转强三关「昨跌≤2%」用）** / **`cpos`（收盘位 0~100，三关「尾盘不追高」用 cpos<70）** / **`ma5`/`ma10`/`ma20`/`hi20`/`lo20` 价位绝对值** / **`hi_today`=当日最高价（次日突破基准）** / **`sup`/`res`=`{k,px,d}`（关键位置的两侧：`sup`=现价**下方**最近、`res`=现价**上方**最近；`k` 是类型、`px` 是价位、`d` 是距离%）** / **强度四件套 `ret5_pct`（前5日涨幅%）`zt10`（近10日涨停次数）`zt_streak`（当前连板数）`vol_ratio`（今日量比）`dist_ma5_pct`** / **`vr_rel`（量比÷大盘量比；★≥2=校准确认方可买，`vr_rel`<2 不买；绝对量比≥2 但 `vr_rel`<2=跟风放量（大盘同放）；<1=放量不及大盘）`flow_rel`（净占比−大盘净占比，百分点；>0=资金强于大盘）** / `seal` 标签 / `seal_pct` / 近5·20日净额；**20 日位置要自己算 `(price-lo20)÷(hi20-lo20)`**），**不截断** —— 「谁更强」看这张表；**买点/止损/压力直接写 rank 里的价位，不需要再拉 K 线（禁止 `agent_get_kline`）**
- **强度是加减分项，不是准入闸**（实测 101 笔：不筛封板率 11.9%，`ret5_pct≥15%` + `vol_ratio≥1.5` 达 44.4%，再加相对强度 57.1%）。加分：前期已有强度（`ret5_pct` 15%+）、D0 放量（`vol_ratio` 1.5+）、10 日涨停少（`zt10`≤2）、乖离温和。减分：`zt10`≥3（高位反复透支，实测封板率仅 9.1%）、`ret5_pct` 个位数或为负（最弱那批，80% 连板边都碰不到）、`vol_ratio`<1（缩量却给强度结论）。**缩量回踩是减分不是加分**——封板组 D0 量比 3.11 对炸板组 1.24。加分项不足 2 条就别进「买什么」
- **`sup.k` 可能不是均线**（`ma5|ma10|ma20|ma60` 均线 / `lo10|lo20|lo60` 近端低点 / `gap` 跳空缺口下沿 / `poc` 成交密集区 / `zt` 涨停起点 / `hi20` 是压力侧），**不要一律写成「回踩 MA5」**——它给的就是「离现价最近的那个位置」。要更多候选看满卡的 `tech.support.supports`（下方 ≤3 条）/ `resists`（上方 ≤2 条），已按现价分成支撑与压力（同一价位在上方是压力，不是支撑）
- **买点禁止直接抄 `sup.px`**：`sup` 恒在现价下方，照抄的结果是全部「等回踩」、当天一只也买不到（实测 3/3 命中）。强环境用 `res` 给「突破 X 追 / 不破 sup 持有」，弱环境才把买点压到 `sup` 下方一档
- **`analyzed_rank` 缺键即正常**：无 `limit_up`=未涨停、无 `buyable`=可买、无 `stale_bar`=日线未滞后、无 `risks`=无风险、无 `sup`/`res`=该侧无关键位置、无 `seal`=今日未封板、无 `zt_streak`=今日没连板、无 `confidence`=证据满维、无 `regime`=低位蓄势（中性默认，不占字符）、无 `chg_prev_pct`/`cpos`=日线不足（弱转强三关缺数据即不过关，只给回踩支撑）、无 `vr_rel`/`flow_rel`=大盘基准缺失（未校准，按绝对值读）
- **`regime` 形态标签 = 动作分流的依据**（2026-10-31 漏斗实测：触及10% 最高的是「转强|高位」56%，最差「分歧|高位」T+3 −6.4%；朴素弱转强 6 笔均收 −5.4% ⇒ 弱转强真伪看三关，见下）：**一鼓作气**（前5日>10% 且当日>2%，唯一可给「突破追」的档）/**高位分歧**（高位横盘，量比≥0.9 且收盘位≥40% 才可等回踩，否则按再而竭处理）/**再而竭**（高位滞涨+缩量或收在日内低位，**禁追**，进不买）/**跳水回踩**（高位大跌但 rs_d0≥-1.5=跌主要来自大盘带崩、非个股弱；关键位企稳即可按回踩接，当日反抽不追）/**三而衰**（高位大跌且 rs_d0<-1.5=显著跑输大盘，个股真转弱，禁追、进不买；真正的三而衰=反弹波高度/力度递减，需盘中波段确认）/**弱转强**（前5日≤10% 且昨日跌今日涨>2%，真伪三关：**量比≥2** ∧ **昨跌≤2%**（`chg_prev_pct`≥-2，深坑反弹不算）∧ **尾盘不追高**（`cpos`<70；贴日高收盘=追高盘禁追——旧「尾盘强才可追」已证伪反向），三关全过才可追，否则只给回踩支撑（2026-11-01 全市场回测样本内口径 n=99 +1.19%/触10% 31%，待滚动复验）；★校准确认闸（2026-11-01 升级）：买（追/回踩接/三关过）须 `vr_rel`≥2——`vr_rel`<2 一律不买（无确认；含跟风放量=绝对量比≥2 但 `vr_rel`<2，大样本最差档）；加分项不写死：三关已过再看价效高（涨幅÷量比高=价升量稳/惜售）可上调置信，单看惜售不加分——「一鼓作气，再而竭，三而衰」，弱转强是真强的前提不是充分条件）/低位启动（昨未跌，看支撑）/低位走弱（不买）
- **三轴校准（价格/量能/资金流）**：`rs_d0`/`rs_5d`=个股−上证同期超额（%）、`vr_rel`=量比÷大盘量比、`flow_rel`=净占比−大盘净占比（百分点）。**大盘弱个股强=真强**——rs_d0 明显为正 **且** vr_rel≥2 **且** flow_rel>0 三轴同向才可确认，单轴强只算加分；**大盘强个股弱=真弱**（涨是跟风，指数一走弱就回吐）。**大盘暴跌、个股横盘（rs_d0 明显为正）=有支撑**（跳水回踩/三而衰拆分即此义，带崩≠个股弱）；三轴全弱=真弱不接。庄股例外：与大盘恒反向、量能自锁（放量缩量不随大盘）的票按独立行情读，不套三轴。`rs_d0`/`flow_rel` 是加减分项不设闸；**`vr_rel`≥2 是买前确认闸**（2026-11-01 升级为闸）
- `inspect_stock` 结果带 **`same_t`（同时刻横向比对）**：`vr_same_t`=今日截至 T 的累计量 ÷ 前几日**同一时刻**累计量均值、`rs_same_t`=个股与上证「昨收→T」的同期超额——盘中判断「现在这一刻谁真强」直接看它，不要拿全天口径倒推；盘后调用 T≈15:00 退化为全天对比（无害）。**同刻三轴校准**：`fp_same_t`=同刻量价方向净占比%、`vr_rel_same_t`/`flow_rel_same_t`=个股对大盘的同刻相对值；`mkt_vr`/`mkt_fp_pct`/`mkt_fp_prev_pct`=大盘同刻量比与净占比（今日 vs 前几日**同一时刻**，大盘强弱两轴：量比+资金流，资金流和前几日同刻比对，用户 9:50 口径）
- **盘后默认给「条件单」而不是一口价**：次日 09:30-10:00 观察，**突破 `hi_today` + 早盘成交明显放大 + 强于大盘** 三条同时成立才买，任一不成立当天放弃。实测「早盘涨了才追」单看涨幅无效（T+1 +0.06%），要的是**放量突破**。买点列写「触发条件 + 触发后成交价上限」
- `analyzed` = 前 N 只**满卡**（按交付预算裁剪，`analyzed_note` 写明 N），与 `analyzed_rank` **同序、均按 `p_up` 降序**（无预测的沉底）；满卡之外的票用 `inspect_stock(code)` 定点取。满卡已瘦身：不含 `evidence_dims`、空容器与 None 键
- `src` = 该票来源：`baseline`（8.1.0 基线保底，规则与旧版一致）或 `additive`（加法层新增）。**排序只影响先看谁，不影响名单有谁**
- `seal` = 封板结构的**客观事实 + 硬标签**，`{tag, seal_tier, open_count, seal_ratio_pct(封单÷成交额 %), zt_days, turnover_pct}`。**两个正交事实，必须合起来读**：`tag` 只切开板次数（`none` 未封板 / `one_word` 一字·全天封死 / `open0` 0 开板非一字 / `open1_2` / `open3_5` / `open6p` ≥6 次 / `unknown` 缺实时或池里无该票）；`seal_tier` 只切封单厚薄（`thin` ≤5% / `mid` ≤15% / `thick` ≤40% / `vthick` >40%）。**不打分、不排序**——买不到不是决策问题（盘后次日按涨停价挂单即可），它回答的是「今天封得怎么样」。**实证方向（近 8 交易日 426 只，次日收盘均值）**：开板 0 次 +1.79% / 1-2 次 +1.11% / 3-5 次 +0.82% / 6+ 次 −0.57% ⇒ **开板越多越差**；封单÷成交额 ≤5% −0.62% / 5-15% +1.20% / 15-40% +1.84% / 40%+ +3.51% ⇒ **封单越厚越强**；连板 2 板最弱（中位 −1.69%）、4+ 板最强（中位 +7.56%，样本仅 16 只）。**组合要看**：`open0` + `thin`（0 开板但封单极薄，实测 000568 式）与 `open6p` 同为最可疑，别因为「没开板」就当强；有厚封单支撑（`one_word`/`vthick`/`thick`）才是真强封。标签边界可用 `QD_SCREENER_SEAL_TAG`（JSON）覆盖
- **`limit_up=true` / `buyable=false` 只是事实，不是排除令**：封板票可进名单（盘中此刻买不进，盘后/次日是另一回事），接不接由你的逻辑决定，但进「可买」列表要写清凭什么
- `report_guide` 判定规则摘要（支撑≫涨跌幅、周期、禁止重验）——**写结论时直接照它落笔，不必 read_skill**
- `rt` 实时快照（价格 / 涨跌幅 / 涨停价 / 跌停价 / `limit_band` / 涨跌停）；`stale_bar=True` 时 `tech` 的收盘/涨跌停已按 rt 修正（MA/RSI 仍基于日线）。**有 rt 就不要在主对话重拉实时行情**；`stale_bar` 时**不要用 `close_pos_in_day` 下结论**。**ST/新股信 rt 价**：`limit_band=no_limit`（新股无涨跌幅）两价为空，禁止用公式回退；ST 的 quote 带可能按板规则而非 ±5%（见 `limit-rules.md`）
- `theme.hit` 题材是否落在当日主线；`hard` 客观障碍清单；`missing` 数据缺口
- `flow` = 资金证据卡：`net_wan`/`net_pct_of_amount`（当日）+ **`recent`（近5/20日累计、连续方向、逐日符号、剔除最大单日、上一交易日）** + **`intraday`（开盘窗 vs 其后净额、open_share_pct）**。**资金看多日总体，单日大额流入 ≠ 趋势**。**口径看 `caliber`**：恒为 `price_direction`（量价方向净额，按分钟涨跌方向累计成交额派生），**不是东财四档主力净额**，量级不同、不可换算 ⇒ 正文只能写「量价净流入/资金净额」，**禁止写「主力净流入」**；`recent`/`intraday` 各自带 ok，缺失看 missing
- `warnings` 可能含**拉高出货线索**（「开盘脉冲」「疑似拉高出货」「趋势背离」，deep 层在 `flow_risks` 键）：开盘窗大额净流入后转流出/冲高回落/今日脉冲与近5日净流出背离 —— 经验型判断，可否决但要写理由
- `warnings` 经验型软提示（如「弱势市涨停活跃源无题材支撑」）——你可以采纳也可以否决
- `hints` 是历史经验门槛（建议值），**不是硬规则**
- `funnel` 是 `run()` 返回的漏斗统计键，包含：`rounds` / `pool_raw` / `excluded_obj` / `scored`（加法层被打分只数）/ `baseline`（基线保底只数，恒入 deep）/ `baseline_hard`（基线窗口内被 hard 拦掉的只数）/ `excluded_score` / `deep_n` / `eastmoney_ok`，用于复盘每一步筛掉了多少候选；`excluded_score` 内 `no_pred_kept`=缺分保送只数（模型盲区票）、`score_skipped`=超打分预算被让位只数（均只计加法层）
- `filter_candidates` 保守地把 hard 与 warnings 一并剔除；走 `profile_candidates` 你能看到全部候选

## 工作流（`run()` 内部阶段示意，不必线性）

> 下面用内部阶段函数展示 `run()` 的取数顺序与口径；实际派活只调 `run()`（无入参）。

```python
st = market_state()                       # 先看环境
result = pre_screen(sources="zt,dragon,search",
                    queries="放量突破 站上20日均线")   # 来源与查询词都由你定
bundle = profile_candidates(result, limit=20)

# 之后完全由你决定，例如：
profiles = bundle["profiles"]
picks = [p for p in profiles
         if not p["hard"]
         and (p.get("p_up") or 0) >= bundle["hints"]["p_up_floor_suggest"]
         and (p["tech"] or {}).get("pos_in_20d_pct", 0) <= 95]
codes = ",".join(p["code"] for p in picks[:8])

deep = deep_analyze(codes=codes)                     # 拉齐证据，再自己加权（默认无 mtf）
pats = detect_patterns(codes=codes, params='{"platform_range_pct": 10}')  # 换个定义看结论稳不稳
detail = inspect_stock(picks[0]["code"], deep=True)  # 对最想确认的票追问
```

- 证据不足就继续追数据：调大 `limit`、`deep=True`、或用 finance 工具查板块/资金/消息面
- 同一批票可以用不同口径重试；不必一次定型
- 六维里有任何一维答不上来，就把它写进「数据缺口」，别装作没这个问题
- 想知道旧版会怎么选、那些 +/- 分是怎么来的：看 `references/strategy-rules.md` 第八节（已标注为【历史】，不要照抄）

## 分析框架（六维交叉验证 + 短窗周期）

对每只候选至少回答前四维，第五六维决定组合层面；结论优先落在 **T+1 / T+3 / T+5**：

1. **题材与主线**：是否落在当日 `themes`？同一题材已被你推了几只（过度集中 = 单点风险）
2. **量价结构**：量比、收盘在日内位置、是否 20 日高位、振幅；放量突破 vs 放量滞涨要区分；**日内 MACD 红绿柱变化**作涨/跌压力参考
3. **资金**：量价净额方向与占成交额比（`caliber=price_direction`，**不是主力净额，正文禁止写「主力」**）；**近5/20日总体（flow.recent：累计、连续方向、逐日符号）优先于当日单格**；形态好但资金流出 → 减配或放弃；**开盘脉冲后回落/单日脉冲与多日趋势背离 → 拉高出货嫌疑（flow_risks）**；**结合个股流通市值看控盘**（同额资金在流通市值小的票上控制力更强）；**流通市值越大趋势越连续、变盘越慢，流通市值小的票容易被资金带动，趋势更快更短**；**龙虎榜席位**：是否有主力席位、是否有游资席位、是否有机构席位
4. **位置与空间**：距 MA20 乖离、20 日位置、连板高度、**支撑位是否清晰**、**支撑–压力间距**（`sr_gap_pct` 过窄 → 操作性弱、排序下调）
5. **市场状态**：情绪分桶、涨停 / 跌停家数、炸板率、**指数相对开盘强弱（早盘主信号）与大盘资金近5日方向**——弱势市/`cautious` 应自动提高门槛、减少只数
6. **可执行性**：`hard` 全集（ST/退市、换手不足、**价格 <2 或 >300**、涨停买不进、停牌）；次日干扰

### 核心判定原则（摘要）

**盘中是红是绿不决定安全，有没有支撑才决定安全。** 可怕的是「没有支撑位的一直下跌」。

- 先按**涨跌停带**归一（主板 ±10% / 创业科创 ±20% / 北交 ±30%；ST/新股以 `rt.limit_*_price` 为准），再看红绿与结构
- **-8% 弱转强 + 有支撑** 可以比 **+8% 转分歧/转弱** 更安全；禁止按涨跌幅排序
- **日线标签 ≠ 盘中信号**；三时段（盘中/尾盘/盘后）落法不同

完整矩阵、字段对齐、三时段表 → **`references/trading-logic.md` §0（真源）**。

## 评分与方向语义

- `p_up` = 标定模型给出的 P(**T+1** 上涨)，0~1；可折成「次日上涨参考 NN」写进理由，**不是表内独立列**
- **缺分不是低分**：标 `no_pred_kept` 的票是打分模型盲区（p_up 缺失），理由写「暂无历史参考分」，六维照常给，别当低分排序垫底；模型盲区要在末行「数据」里点名
- **主表不另设「方向」列**；方向写在 **T+1/T+3/T+5** 列（看多/中性/看空）：
  - T+1：可用 `p_up` 映射（≥0.55 看多 / ≤0.45 看空 / 其余中性），也可因证据推翻并写理由
  - T+3 / T+5：无标定概率，用证据写方向；**禁止**把 `p_up` 外推成多周期胜率
- **置信度分层**：T+1~T+5 可正常给；T+10/T+20 默认低一档，证据不足直接「不适用」。**行动表内只写 T+1/T+3/T+5**
- `hints` 的门槛/只数是经验值，不强制：题材共振且证据扎实可放宽；数据缺口多就应下调置信度
- 你可以不认同模型分，但要写明理由（例：模型不知道今天这条新主线）

## 输出契约（行动清单）

用户只关心：**买什么 / 什么价位买 / T+N 能不能赚 / 走坏了能不能全身而退**。

```
## 买什么（N 只，N=实际符合条件数；可空）
| 代码 | 现价 | 买点价位 | 止损价 | T+1/T+3/T+5 | 一句话理由 |

## 不买/观察（每只一行：代码+拒因≤20字）
## 风险（≤3 行）
```

- **买点两种落法**：加分项少/弱环境 → 写「回踩 X」（日线 MA、前高前低、密集区、缺口下沿）；加分项多 → 写条件单「突破 `hi_today` X 后买入，上限 Y」，**不许全名单都用同一种**
- 无明确止损价不得进「买什么」；止损写「跌破 X」/「不跌破 X」
- 表格行数随推荐数浮动，正文保持精简；指标罗列、漏斗数字、长篇分析不进正文
- **中文白话**：不写 p_up / w2s_kept / t1_bias 等字段名；「次日上涨参考」「今日弱转强」「暂无历史参考分」
- 保留 6 位代码、股票名称、看多看空、「跌破 X」（喂 claims 追责）
- 今天没得选时写「今日无符合标的」+ 一行理由，不要硬凑

## 常见错误清单

- 按涨跌幅排前几只直接推；忽视涨跌停带（主板 -8% ≠ 创业板 -8%）
- 把盘中下跌一概当利空，或把盘中上涨一概当安全——错在忽视支撑与弱转强/强转弱
- 把日线 `weak_to_strong` 当成「此刻盘中弱转强」；盘中用 `close_pos_in_day` 说「尾盘承接」
- 把中长线逻辑（基本面、月线、长持）混进短中线结论
- 强行凑满 T+10/T+20——后两档证据不足就写「不适用」；给 3 板以上票硬写 T+3/T+5
- 把 `p_up`（仅 T+1）外推成 T+3/T+5 的胜率；理由里重复写方向
- 忽视 `hard`：涨停买不进、**低价/高价带**、停牌、换手不足
- 弱势情绪（weak）下仍推一堆高位连板
- **只看当日资金流向就下结论（不看近5/20日总体）**；把单日大额流入当趋势反转
- **接盘「开盘几千万拉升后抛盘」**：忽视 flow_risks 的开盘脉冲/冲高回落/趋势背离线索
- **早盘只看涨停家数下结论**（封板未成熟，应看指数相对开盘+大盘资金方向）；大盘走弱（cautious）仍按强市门槛推票
- 多只票同一题材却当成分散配置
- 把 missing 当作「没有风险」
