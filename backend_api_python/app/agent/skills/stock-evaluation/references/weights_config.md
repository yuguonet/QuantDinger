# 评分权重配置参考

## 默认权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 技术面 | 0.40 | 趋势+指标+量价+形态+筹码 |
| 资金面 | 0.20 | 主力资金流向 |
| 资本结构 | 0.15 | 融资融券+股东结构 |
| 新闻舆情 | 0.10 | 新闻情绪+市场情绪 |
| 估值 | 0.10 | PE/PB/ROE |
| 流动性 | 0.05 | 换手率+成交量 |

## 数据库配置

权重存储在 `qd_skill_weights` 表中：

```sql
CREATE TABLE qd_skill_weights (
    id SERIAL PRIMARY KEY,
    skill_name VARCHAR(100) NOT NULL,
    weight_key VARCHAR(50) NOT NULL,
    weight_value FLOAT NOT NULL,
    updated_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(skill_name, weight_key)
);

-- 示例
INSERT INTO qd_skill_weights (skill_name, weight_key, weight_value) VALUES
('stock_scoring', 'technical', 0.40),
('stock_scoring', 'fund_flow', 0.20),
('stock_scoring', 'capital', 0.15),
('stock_scoring', 'news', 0.10),
('stock_scoring', 'valuation', 0.10),
('stock_scoring', 'liquidity', 0.05);
```

## 交叉验证加星规则

| 验证组合 | 条件 | 加分 |
|----------|------|------|
| 技术面+资金面 | 两者评分均 > 60 | +3分 |
| 技术面+资金面 | 两者评分均 < 40 | +3分 |
| 资金面+新闻面 | 两者方向一致 | +3分 |
| 趋势+指标 | 双重金叉/死叉 | +3分 |

## 深度级别说明

| 级别 | 工具数 | 耗时 | 适用场景 |
|------|--------|------|----------|
| L1 简单 | 1个 | ~5s | 快速筛选、批量扫描 |
| L2 标准 | 3个 | ~15s | 日常分析、盘中监控 |
| L3 深度 | 5个 | ~30s | 详细研究、决策支持 |
| L4 完整 | 7个 | ~60s | 深度研究、回测验证 |
