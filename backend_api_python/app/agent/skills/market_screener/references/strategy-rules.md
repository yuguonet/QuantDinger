# 选股规则手册（rules live here, not in code）

> 这份文档是 **market_screener 唯一存放规则的地方**。
> `_facts.py` / `_helpers.py` / `run.py` 只提供客观事实，**不含任何取舍**。
> 下面所有条目的性质不同，请注意区分三档：

| 标记 | 含义 | 你能不能推翻 |
| --- | --- | --- |
| 【定义】 | 某个形态/指标的几何定义，代码里实现就是照这个写的 | 可以通过 `detect_patterns(params=...)` 覆盖，但改了就等于换了另一种形态 |
| 【历史】 | 2026-09-29 前写在代码里的旧口径，**当你想看旧版为什么这么选时查阅** | 完全可以推翻，它们没有被标定验证过 |
| 【提示】 | 经验值 / 常见误区 | 应当结合当日证据判断 |

## 一、数据源硬事实（先记住，否则会踩空）

- **分钟源只有 `1m`。** 实测 `15m` / `5m` / `30m` / `60m` 查表恒返回 **0 行**（历史裁定：kline_15m 已回填进 kline_1m 并标 void）。
  `_facts.multitimeframe()` 因此统一取 1m 后本地聚合成 15m / 5m。
  后果：任何依赖「15m 单独成表」的旧结论都不成立。
- 【历史】旧 `intraday.analyze_code` 里的「15m 共振 +5」「5m+15m 共振 +5」「5m MACD 强弱 ±8/-5」在旧代码里**从未真正生效过**
  （因为 m15 / m5 永远取不到值）——这是旧版「分析深度不够」的一个实证来源。
- 日线 (`fetch_kline`) 正常；`search_stocks` 走东方财富，偶发失败，失败会进 `missing`。

## 三、候选池默认行为（现在 vs 从前）

| 项目 | 旧版（写死） | 现在 |
| --- | --- | --- |
| 换手率过滤 | < 2% 直接剔除（`turnover_pct` 缺失时不剔） | 默认**不过滤**，换手不足在画像的 `hard` 里标记，你决定是否排除；要过滤就传 `min_turnover=` |

## 四、形态：六种几何定义【定义】

`detect_patterns()` 用下面的参数识别。改它们 = 换一种形态，不是调松紧。

| 参数 | 默认 | 属于哪个形态 |
| --- | --- | --- |
| `platform_range_pct` | 8.0 | 平台突破：前 5 根高低区间的振幅上限 |
| `breakout_vol_ratio` | 1.3 | 平台突破 / 突破前高：当日量 / 前 5 根均量下限 |
| `surge_vol_ratio` | 1.8 | 底部放量启动：当日量 / 前 5 根均量下限 |
| `flat_change_pct` | 5.0 | 底部放量启动：区间涨跌幅绝对值上限（超过说明不是横盘） |
| `ma_touch_pct` | 1.5 | 均线支撑回踩：最低价距 MA10 的距离上限 |
| `min_pullback_pct` / `max_pullback_pct` | 3.0 / 12.0 | 缩量回调放量突破：回调幅度区间 |
| `shrink_ratio` | 0.7 | 缩量回调放量突破：回调段均量 / 前段均量上限 |
| `rebreak_vol_ratio` | 1.5 | 缩量回调放量突破：再突破当日 / 回调段均量下限 |

返回值**没有 score** —— 旧版每个形态自带一个 60~75 的分，那是没有标定依据的手拍值，
已在本次重构中全部删除。

【提示】形态只能解释「发生了什么」，不能直接加成胜率。
形态 + 题材 + 资金同向才值得写进结论；三者缺二，把它写进「数据缺口」。

## 五、多周期标签怎么读【提示】

`multitimeframe()` 返回三类**速记标签**，它们描述几何关系，不含方向评价：

- `weak_to_strong` = 最近 5 根有 ≥4 根站上 MA5，且之前 5 根有 ≥3 根未站稳 MA5（或 MACD 绿柱期仍站稳 MA5）
- `strong_to_weak` = 反向
- `volume_pattern` = {放量上涨, 缩量上涨, 放量下跌, 缩量下跌, 平量整理}
- `m5.macd_strength` = {sell_pressure_low, sell_pressure_high, even}
  看的是最近 20 根 5 分钟 K 线里：绿柱段的平均振幅 vs 红柱段的平均振幅。
  绿柱段振幅更小 = 卖压打不下去；更大 = 抛压重。
- `daily.ma5_slope_pct` / `ma60_slope_pct` = 均线斜率（%），比二进制的「金叉/死叉」更早给出强弱变化

工具会给出 `missing` —— 分钟线缺失时（例如长期停牌 / 1m 源无覆盖）这些标签会是空值，
**别把「拿不到」当成「中性」，也别当成有 alpha**。

## 六、仓位 / 入场 / 止损（旧代码里的公式，全盘移交给你）

【历史】旧 `post_market.analyze_code` 的介入点算法，现在不再自动算：

```
entry_low  = close * 0.995
entry_high = close * 1.005
stop_loss  = MA10（无 MA10 时用 close * 0.97）
target_1   = close + (close - stop_loss) * 1.5
target_2   = close + (close - stop_loss) * 2.5
```

这套「1:1.5 / 1:2.5」没有任何标定依据，别默认它是对的。
要给出入场/止损，请结合 `tech.dist_ma20_pct`（乖离大就别把止损设在贴身位置）和当日 `amplitude_pct`。

## 七、情绪分数是怎么算的【历史】

`market_state()` 的 `mood_score` 沿用旧口径（**描述性标签，非入场规则**）：

```
base 50
+ min(20, 上证净流入 // 1e7)        净流出则 max(-20, ...)
+ 10  若涨停家数 > 30；- 10 若 < 15
- 15  若跌停家数 > 20
- 10  若炸板率 > 40%；+ 5 若 < 20
mood: >=70 偏强 / >=50 中性 / >=30 偏弱 / 否则 弱势
```

`_helpers._mood_regime` 把它映射成 strong / neutral / weak，只用于给预测模型传上下文 + 生成 `hints` 建议门槛。

## 八、【历史】旧评分梯形存档（仅供参考，**不要直接照抄**）

旧 `intraday.analyze_code` 基础分 55，然后：

| 事件 | 加减 |
| --- | --- |
| 弱转强 / 强转弱 | +15 / -15 |
| 放量上涨 / 缩量上涨 / 放量下跌 | +12 / +10 / -10 |
| 站上 MA5 / MA20 | +5 / +5 |
| MA5 斜率 > 0.5% / < -0.5% | +5 / -3 |
| MACD 红柱 / 绿柱但价稳 MA5 上 | +3 / +5 |
| RSI 在 40-60 / > 75 | +3 / -5 |
| 日线+15m 共振 / 15m+5m 共振 | +5 / +5（**从未生效，见第一节**） |
| 5m MACD 强势 / 弱势 | +8 / -5（**从未生效**） |
| 资金净流入 | +5 |

方向：>=60 看多，<45 看空；confidence = 0.4 + 命中信号数 × 0.05（上限 0.9）。

旧 `eod.analyze_code` 基础分 55（prescreen 阶段基础分 50）：收盘位置 +10/+7/+3，量能 +8/+5/+2，
日内高位 +5/+2，题材 +10/+3，RSI>80 -10，MA5>MA10 +5，**信号少于 2 条直接淘汰**。
尾盘封板固定给 90 分。

旧 `post_market.analyze_code`：形态分累加后，RSI>80 -10、>70 -3、40-60 +3；KDJ 金叉 +5；
MA 多头 +5；MACD 金叉/死叉 +5/-5；主力净流入/流出 +5/-3；
**没有任何形态命中就直接返回 None（等于静默落选）**。

> 这些数字是「某个工程师某天觉得合理」的产物，没有回测或标定支撑。
> 当前唯一的、经过标定的数字是 `predict_one()` 给的 `p_up`（见 SKILL.md 评分语义）。

## 九、已验证策略参考（从旧 notes 合并）

- **BB 超卖**：价格触 BB 下轨 + MA60 斜率 >= 0 + 振幅 > 8%；次日 9:50 左右确认在日均线上方再买
- **4IN1 涨停**：V1 首板次日放量涨停 → D+1 开盘买；龙回头 A 涨停后回调 3-5 天缩量小阴 → 买；
  龙回头 B 回调 6-11 天缩量企稳 → 买；断板（连板>=2 后断）→ 次日开盘买
- **选股不应只从涨停池 / 热榜取**（本质追高）：先看大盘资金与板块强弱，再用 `search` 按条件搜

## 十一、做敏感性检查的建议

规则写在 md 里的一个实际好处是可以做对照实验。建议至少验证这几项：

1. `detect_patterns` 的 params 上下浮动 20%，看入选名单是否剧烈变化 —— 剧烈 = 结论依赖阈值而非事实
2. `pre_screen(sources=...)` 单开某个来源，看结论是否只由单一来源支撑
3. `multitimeframe` 的 `minute_days` 调大，确认日内标签是否稳定
4. 把 `p_up` 单独排序 vs「p_up + 题材共振」排序，比较名单差异并记录为什么更信后者
