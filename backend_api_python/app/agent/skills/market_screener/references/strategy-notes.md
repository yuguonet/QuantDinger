# 已验证策略参考

以下策略经过历史回测验证,供代码实现时查阅。

## BB 超卖策略

- 入场:价格触及 BB 下轨 + MA60 斜率 >= 0 + 振幅 > 8%
- 买入时点:次日 9:50 左右,确认价格在日均线上方、有大单买入
- 出场:跟踪止损 10%、RSI > 75 + 量比 > 2、RSI > 85 极端超买

## 4IN1 涨停策略

- V1:首板次日放量涨停 → D+1 开盘买入
- 龙回头 A:涨停后短回调 3-5 天 → 缩量小阴 → 买入
- 龙回头 B:涨停后长回调 6-11 天 → 缩量企稳 → 买入
- 断板:连板 >= 2 断板 → 次日开盘买入
