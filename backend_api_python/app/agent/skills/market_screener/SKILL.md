# 全市场短线选股 (market-screener)

## 描述

根据当前交易时间自动切换策略,从A股全市场筛选短线标的。

## 使用场景

- 用户询问"今天买什么股""有什么好股票""短线选什么"等全市场选股问题
- 用户要求盘后复盘、尾盘隔夜选股、盘中热点追踪选股
- 需要对全市场做系统性筛选,而非分析单只股票

注意:如果用户指定了具体股票代码,请使用其他个股分析技能,不要调用本技能。

## 策略调度

本技能根据交易时间自动选择策略:

| 时间窗口 | 策略 | 核心逻辑 |
|---|---|---|
| 09:15-09:25 | 集合竞价 | 竞价抢筹信号（当前间接推断） |
| 09:25-10:00 | 盘中关键窗口 | 集合竞价+开盘30分钟定基调，10点前基本能看出一天走势 |
| 09:30-14:29 | 盘中短线 | 根据大盘/板块/概念状态，用 search_stocks 搜索符合条件标的 |
| 14:30-15:00 | 尾盘隔夜 | 条件初筛 + 尾盘特征验证 + 尾盘封板 |
| 15:00+ / 非交易日 | 盘后复盘 | 全市场技术形态扫描 + 介入点计算 + 次日计划 |

### 关键时间窗口

- **9:15-9:25**:集合竞价阶段。竞价抢筹信号:高开幅度 + 竞价量 + 开盘后 1m 放量延续(当前无专用竞价数据源,用开盘价 vs 昨收 + 第一根 1m bar 间接推断)
- **9:25-9:30**:竞价结束,观察高开/低开幅度、竞价量
- **9:30-10:00**:开盘半小时,判断板块强弱、资金流向、个股分时走势。此时段用 1m/5m 线分析
- **10:00 前**:基本确定当天走势方向,是盘中选股的截止点
- **9:50 左右**:BB 超卖策略建议的买入时点(确认价格在日均线上方 + 大单买入)

### 数据层次

盘中分析需要结合多个时间维度:

| 周期 | 用途 |
|------|------|
| 日线 | 大趋势、弱转强/强转弱、MACD 柱、均线关系 |
| 15m | 日内趋势转折、量价配合(10:00后使用) |
| 5m | 9:30-10:00 关键窗口趋势 + 入场点 + 放量缩量节奏 |
| 1m | 9:30-10:00 盘口细节、拉升/打压力度、大单方向 |

### 已验证策略参考

以下策略经过历史回测验证,可作为选股和评分参考:

**BB 超卖策略**(test_bb_indicator.py):
- 入场:价格触及 BB 下轨 + MA60 斜率 >= 0 + 振幅 > 8%
- 买入时点:次日 9:50 左右,确认价格在日均线上方、有大单买入
- 出场:跟踪止损 10%、RSI > 75 + 量比 > 2、RSI > 85 极端超买

**4IN1 涨停策略**(test_dragon.py):
- V1:首板次日放量涨停 → D+1 开盘买入
- 龙回头 A:涨停后短回调 3-5 天 → 缩量小阴 → 买入
- 龙回头 B:涨停后长回调 6-11 天 → 缩量企稳 → 买入
- 断板:连板 >= 2 断板 → 次日开盘买入

### 选股策略调整原则

不要仅从涨停池/热榜选股(本质是追高)。应根据市场状态调整策略:

1. 先判断大盘强弱(资金流向)和板块/概念状况
2. 板块强 + 个股弱转强 → 重点关注(真强)
3. 大盘弱 + 个股逆势走强 → 独立强势股
4. 用 `search_stocks` 按条件搜索,而非只从热门列表取
5. 结合 BB 超卖、龙回头等已验证形态做二次筛选

## 执行流程

### Phase 1 - 市场状态评估 + 条件选股

Phase 1 的核心是先判断市场状态,再根据状态调整选股策略:

1. **市场状态评估**:资金流向、板块强弱、概念热度
2. **策略调整**:根据市场状态决定搜索条件
3. **条件选股**:用 `search_stocks` 按条件搜索全市场
4. **候选池构建**:涨停池连板/龙回头 + 条件搜索结果合并

```python
from app.agent.skills.market_screener.run import pre_screen
result = pre_screen()  # 无参数,自动根据当前时间选择策略
# result["market"] → 市场状态(资金流向、板块强弱)
# result["main_themes"] → 主线题材
# result["candidates"] → 候选股列表
```

> ⚠️ `pre_screen()` 不接受任何参数。不要传入 filters、kwargs 或其他参数。

### Phase 2 - 逐只深入分析

对 Phase 1 的候选股逐只调用工具获取实时数据,计算综合评分并生成操作建议。

```python
from app.agent.skills.market_screener.run import deep_analyze
final = deep_analyze(result)
# final["output_data"]["analyzed"] → 深入分析结果
# final["score"] → 综合评分
# final["analysis"] → Markdown 报告
```

调用的工具(Phase 2 内部自动调用,无需手动):
- `get_fund_flow` - 实时资金流向
- `get_indicator_snapshot` - 技术指标快照(MACD/KDJ/BOLL等)
- `search_stocks` - 条件选股(尾盘/盘后策略使用)


### 失败处理

- Phase 1 执行失败 → 不重试,直接告知用户"选股执行失败"
- Phase 2 单只分析失败 → 跳过该股,继续下一只
- 不要重复调用 read_skill,读一次就够

## 市场情绪判断标准

涨跌停家数仅反映市场分歧程度,不能直接判断强弱。市场强弱应以资金流向为主要依据:

| 指标 | 强 | 中 | 弱 |
|------|----|----|----|
| 大盘资金流向 | 净流入 | 平衡 | 净流出 |
| 涨跌停比 | 涨停>跌停 | 持平 | 跌停>涨停 |
| 炸板率 | <20% | 20-40% | >40% |

注意:涨停100只跌停50只只代表分歧大,或某板块吸金能力太强,不代表整体强势。

当资金流向显示市场弱势时,盘中策略仍会执行选股,但输出附带警告,降低置信度。

## 核心交易逻辑

以下逻辑贯穿选股和评分全过程:

### 1. 个股强弱的判断

大盘强或板块强、个股弱 → 真弱,回避。
大盘弱或板块弱、个股强 → 真强,重点关注。

### 2. 弱转强(最佳买点)

- 价格在日均线附近震荡一段时间后,转为站稳日均线之上
- 即使某一时间点跌破日均线,也能很快收复
- MACD 日线绿柱阶段,价格仍能稳定在日均线上方
- 此阶段股票尚未大幅拉升,盈亏比最优

### 3. 强转弱(最佳卖点)

- 价格从日均线上方跌破后无法收复
- 此阶段股票尚未大幅跳水

### 4. 一鼓作气再而衰三而竭

- 连续 3 次拉升,一次比一次低 → 上升无力
- 连续 3 次下跌,一次比一次低 → 下跌动能耗尽
- 用于判断盘中分时走势的转折点

### 5. 放量的意义

- 买卖都会放量,放量代表热度
- 连续放量代表个股热度在持续
- 缩量上涨 → 拉升(抛压轻,主力控盘)
- 放量下跌 → 抛盘(真实抛压)

### 6. MACD 红绿柱与价格波动(5m/15m 级别)

早盘 9:30-10:00 期间,5 分钟 MACD 能看出承压和拉升强度:

- **绿柱**:对比同期价格波动范围,判断卖压强度
- **红柱**:对比同期价格波动范围,判断拉升强度
- **强势判断**:红绿柱高度相近 + 绿柱价格波动 < 红柱价格波动 → 强势(绿柱时卖压打不下去)
- **强势股特征**:绿柱本身就小,说明抛压轻
- **例外**:大盘波动很大时此规则不适用

### 7. 换手率过滤

- 换手率 < 2% 的个股活跃度不够,应排除
- 即使涨停,低换手率个股往往由消息催生,持续性差
- 盘中换手率需预估全天值(当前成交量 / 近5日平均全天成交量)

### 8. 盘中数据的局限性

- 换手率只能预估全天换手率
- 成交量呈锅底形态(早盘和尾盘大,中间小)
- 部分参数需对比前一天数据才有意义

## 涨跌停规则

| 板块 | 涨跌停幅度 | 代码特征 |
|------|-----------|----------|
| 主板/中小板 | ±10% | 60xxxx / 00xxxx |
| ST 股 | ±5% | 名称含 ST |
| 创业板 | ±20% | 300xxx / 301xxx |
| 科创板 | ±20% | 688xxx |
| 北交所 | ±30% | 8xxxxx / 4xxxxx |

## 过滤规则

- **涨停封板股自动排除**:涨幅接近涨停的股票买不进去,不纳入候选
- **低换手率排除**:换手率 < 2% 的个股活跃度不够,排除
- **Phase 2 低分淘汰**:评分 < 60 或方向为 bearish/neutral 的候选股自动抛弃
- **最终排序**:通过的候选股按评分从高到低排列

## 注意事项

- 市场弱势时选股结果附带警告,置信度降低
- 尾盘策略关注"收盘=最高价"的强势特征
- 盘后策略会计算具体介入点(入场价、止损、目标价)
- 弱转强是最佳买点,强转弱是最佳卖点--转折点尚未大幅波动时介入
- 大盘弱+个股强 > 大盘强+个股强,前者是真强
