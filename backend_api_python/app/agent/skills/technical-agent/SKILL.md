# 技术面/动量分析

当需要分析股票技术面、趋势、动量时，用此技能。

## 用法

```bash
python {baseDir}/run.py <stock_code> [--name <stock_name>]
```

## 评分规则

五维加权评分（0-100）+ 流通盘修正：

### 基础维度

- 趋势 40%：MA排列、偏离度、趋势方向
- 动量 25%：RSI、MACD、KDJ 综合
- 量价 20%：量价关系、量比
- 形态 10%：K线形态识别
- 筹码 5%：获利盘比例修正

### 流通盘修正（核心）

不同流通盘的信号可靠性完全不同：

| 流通盘 | 趋势可靠性 | 量价可靠性 | 形态可靠性 |
|--------|-----------|-----------|-----------|
| 超小盘 <30亿 | 0.6 | 0.5 | 0.4 |
| 小盘 30-100亿 | 0.8 | 0.7 | 0.6 |
| 中盘 100-500亿 | 1.0 | 1.0 | 1.0 |
| 大盘 500-2000亿 | 1.05 | 1.1 | 1.1 |
| 超大盘 >2000亿 | 1.1 | 1.2 | 1.15 |

**修正公式**：`score = 50 + (原始score - 50) × reliability`

小盘股信号不可靠时分数向50收缩，大盘股信号更可靠时分数放大。

## 方向判定

- score >= 60 → bullish
- score <= 40 → bearish
- 其他 → neutral

## 输出格式

标准 SkillReport + float_mcap_yi（流通市值）+ float_size_tier（盘子分类）。
