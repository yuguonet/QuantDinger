# 核心交易逻辑

以下逻辑贯穿选股和评分全过程。

## 1. 个股强弱的判断

大盘强或板块强、个股弱 → 真弱,回避。
大盘弱或板块弱、个股强 → 真强,重点关注。

## 2. 弱转强(最佳买点)

- 价格在日均线附近震荡一段时间后,转为站稳日均线之上
- 即使某一时间点跌破日均线,也能很快收复
- MACD 日线绿柱阶段,价格仍能稳定在日均线上方
- 此阶段股票尚未大幅拉升,盈亏比最优

## 3. 强转弱(最佳卖点)

- 价格从日均线上方跌破后无法收复
- 此阶段股票尚未大幅跳水

## 4. 一鼓作气再而衰三而竭

- 连续 3 次拉升,一次比一次低 → 上升无力
- 连续 3 次下跌,一次比一次低 → 下跌动能耗尽
- 用于判断盘中分时走势的转折点

## 5. 放量的意义

- 买卖都会放量,放量代表热度
- 连续放量代表个股热度在持续
- 缩量上涨 → 拉升(抛压轻,主力控盘)
- 放量下跌 → 抛盘(真实抛压)

## 6. MACD 红绿柱与价格波动(5m/15m 级别)

早盘 9:30-10:00 期间,5 分钟 MACD 能看出承压和拉升强度:

- **绿柱**:对比同期价格波动范围,判断卖压强度
- **红柱**:对比同期价格波动范围,判断拉升强度
- **强势判断**:红绿柱高度相近 + 绿柱价格波动 < 红柱价格波动 → 强势(绿柱时卖压打不下去)
- **强势股特征**:绿柱本身就小,说明抛压轻
- **例外**:大盘波动很大时此规则不适用

## 7. 换手率过滤

- 换手率 < 2% 的个股活跃度不够,应排除
- 即使涨停,低换手率个股往往由消息催生,持续性差
- 盘中换手率需预估全天值(当前成交量 / 近5日平均全天成交量)

## 8. 盘中数据的局限性

- 换手率只能预估全天换手率
- 成交量呈锅底形态(早盘和尾盘大,中间小)
- 部分参数需对比前一天数据才有意义
